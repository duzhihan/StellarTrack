# 理论深化 · 谛听为什么这样设计

> 本文档展开 README「理论支撑」章节的论证细节。面向想深入理解设计哲学的研究者与开发者。

---

## 1. 从"答案"到"助产术"：定位的哲学翻转

传统 AI 交互的隐含模型是**信息传递**：用户缺答案，AI 给答案。但当我们面对的是"一个模糊而焦虑、尚未成形的重大关切"这类问题时，信息传递模型失效——因为**用户缺的不是答案，而是对自己真实偏好的可见性**。

谛听翻转了这一模型：它不假设"答案在模型里"，而假设"答案在用户心里、但处于前语言状态"。AI 的角色从**供给者**变为**助产士**（maieutic midwife）——通过结构化追问，帮助用户把自己已有的、说不出的东西"生出来"。

## 2. 五条理论支柱

### 2.1 波兰尼 · 默会知识（Tacit Knowledge）
"我们知道的，比我们能说出来的更多。"（We know more than we can tell.）
真实偏好常处于默会状态——直到被合适的追问逼到言说层面。这正是"确认点反馈环"的哲学根据：用户做出选择的那一刻，偏好第一次被言说、被看见。

### 2.2 Slovic · 偏好建构理论（Preference Construction）
Slovic 等的研究表明：人的偏好不是预先存在的稳定数据库，而是在决策情境中**被当场建构**的。推论：
- 七确认点不是"收集信息"，而是**偏好出生的脚手架**；
- 用户的回答会改变用户自己——这是"决策即认知"的深意；
- 因此系统必须"一次一问"——批量问询会破坏建构过程的自然性。

### 2.3 苏格拉底助产术（Maieutics）
苏格拉底不自称教师，而称自己为"助产士"——他帮助对话者把内心已有的知识"生出来"。
谛听把苏格拉底纪律规模化：全环节追问化、95% 信心即停、一次只问一个问题。

### 2.4 决策后悔理论（Decision Regret）
研究表明：决策满意度不只取决于结果好坏，还取决于**过程是否自我认同**。
当用户被推着走完一个决策，即使结果好，也可能后悔（"这不是我的选择"）；反之，自己全程拍板的决策，即使结果不佳，也较少落入后悔。七确认点把"这是我自己选的"写进决策的每一环——这是对用户未来的心理保护。

### 2.5 视角主义（Perspectivism）
扩展视角的价值不在于逼近唯一正确答案（尼采意义上不存在），而在于**看见自己的盲区**。
"视角银行"让用户跨问题积累视角——第一次只能看到"成本收益"，第十次能看到"时间结构""利益相关者""长期再生产"。

## 3. 设计推论的完整链条

```
默会知识 → 追问能把偏好带进言说
偏好建构 → 确认点不是收集，是共同建构
助产术   → 全环节追问化的哲学根据
后悔理论 → 每环拍板 = 未来的心理保护
视角主义 → 视角银行 = 盲区的持续显影
      ↓
设计结论：交付"想清楚的清晰度 + 选择的自我认同度"，
而非"答案的正确性"。
```

## 4. 与"最佳答案崇拜"的边界

谛听不承诺"最佳答案"，因为它诚实地承认：
1. 复杂人生决策没有可计算的"最优解"——约束在变、偏好在建；
2. "最佳"本身是一个评价，评价标准只能来自用户自己；
3. 承诺"最佳"的工具，实际是把判断权从用户手里拿走。

因此谛听的不确定宣言不是谦辞，而是**认识论上的诚实**。

## 5. 对 AI 产品趋势的意义

大模型的能力重心正从"会回答"转向"会倾听、会唤起"。当模型可以轻易给出任何答案时，**稀缺的不再是答案，而是好的问题**。思考协议类 Skill 将成为这一转变的接口层——谛听是这个方向的一个具体实现。
