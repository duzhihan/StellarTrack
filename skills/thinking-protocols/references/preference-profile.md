# ③ 偏好画像积累 · 规则

> 目的：跨多次思考形成个人认知画像——它只影响"排序与推荐权重"，**不固化判断、不替用户决定**。

## 画像数据文件

`data/profiles/profile.md`。结构：

```markdown
# 认知偏好画像（v{版本号}）

> 声明：本画像仅用于调整推荐排序，任何一次思考的最终判断仍由使用者拍板。

## 稳定偏好（P 级：P1 长期稳定 / P2 阶段性 / P3 情境性）
- P1 {偏好描述}（证据：轨迹#N、#M；回显确认次数 ≥2）
- P2 {偏好描述}（证据：轨迹#N）

## 修正记录
- YYYY-MM-DD：{原偏好} → 用户修正为 {新偏好}（原因：{一句话}）

## 近 5 次轨迹索引
- YYYY-MM-DD #N 主题
```

## 更新时机

1. **每次确认点回显后**（增量）：回显=一条证据；同一偏好证据 ≥2 次 → 升级为稳定偏好（P1）。
2. **用户对回显提出异议时**：以修正为准，写入修正记录。
3. **季度复盘时**：合并、降级、退役过时偏好。

## 使用方式（元层推荐时）

- 模式推荐：画像显示"偏好可复利路径"→ 推荐含"积累/复利"心智模型的模式（如毛泽东式+求是式），并说明理由。
- 表达推荐：画像记录"选过简洁干货风"→ ④表达环默认把 C 档放第一位（仍三选一，不跳过）。
- 交付推荐：画像显示"成品偏好"→ C1 交付类型默认推荐 B（仍可改）。

## 纪律

1. **画像只增不改用户说过的话**——修正必须显式记录。
2. **不因画像跳过确认点**——画像只调排序，永远保留选择权。
3. **隐私**：画像数据默认存本地；未经同意不上传、不外传。
