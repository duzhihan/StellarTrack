# 模式库索引（modes/）

## 定位

思考模式是"逻辑框架"，不是"角色扮演"。模式库与思考协议库解耦：**新增模式只需在此加一张模式卡，五环结构零改动。**

## 模式卡字段

```
【模式卡】
- 名称 / 来源 / 触发信号（求本质？求策略？求学习？求风险？）
- 核心心智模型（≤5 个）
- 五环适配（每环如何在该模式下运转，一句话/环）
- 终点判断（"想清楚"的标志）
- 关联 skill / 状态（已装 / 待装 / 预留）
```

## 三态选择（由元层判定）

| 态 | 含义 | 处理 |
|---|---|---|
| 选模式 | 加载该模式引擎驱动五环 | 按模式卡的五环适配运转 |
| 不选（默认） | 走通用六环基线 | ①流式追问②双向钢人③四象限④三选一⑤双粒度⑥轻量验证 |
| 混合 | 叠加两种模式 | 元层指定顺序（如"先毛定矛盾，再李挖本质"） |

## 模式卡（首批 8 张 ＋ 元卡 1 张）

> 元卡＝生产模式卡的卡。它不直接回答问题，而是为模式库造新卡；造出的卡登记入册后即成为用户可选项。

### 1. 李继刚 · 追本之箭（纵向深潜）
- **触发**：求本质 / 求根因 / "为什么" / 追本
- **核心模型**：表象→机理→原理→公理；每次下钻切换更基础的解释框架；纵向不横向
- **五环适配**：①锚定核心表象 ②本质判断对抗 ③层级路径拆解 ④结论锋利层层剥开 ⑤本质判断→极简行动指南
- **终点**：触及不可再分（人性结构/物理定律/逻辑/存在悖论）
- **关联**：`ljg-think`｜✅ 已装

### 2. 毛泽东 · 矛盾分析（系统辩证）
- **触发**：求策略 / 求权衡 / "怎么办" / 竞争 / 组织
- **核心模型**：抓主要矛盾；矛盾两面对立统一；矛盾转化；实践认识循环（两次飞跃）
- **五环适配**：①锚定核心矛盾系统 ②矛盾/策略对抗 ③矛盾运动阶段与条件 ④辩证有力系统周全 ⑤矛盾分析→系统战略方案
- **终点**：形成对矛盾运动规律的判断 + 行动策略（含转折条件）
- **关联**：`mao-mode`（轻量）+ `maoxuan-skill`（完整，经适配层）｜✅ 已装

### 3. 求是 · 实事求是（调查先行）
- **触发**：信息不足 / 复杂问题 / 决策前 / 需要验证
- **核心模型**：实事求是（事实规定判断）；调查研究（没有调查就没有发言权）；实践认识论；批评与自我批评
- **五环适配**：①锚定"事实缺口" ②假设 vs 事实对抗 ③事实链拆解 ④据实表达 ⑤基于调查的行动方案
- **终点**：结论有事实支撑，验证才算完成
- **关联**：`qiushi-skill`｜✅ 已装

### 4. 费曼 · 以教促学（反自欺）
- **触发**：学习 / 检验理解 / 识别形式主义（cargo cult）
- **核心模型**：命名≠理解；反自欺；不确定性是力量；具象化思考；深度游戏
- **五环适配**：①锚定"真懂了吗" ②自欺 vs 实证对抗 ③理解层级拆解 ④简单类比表达 ⑤以"教得懂"为验收的行动
- **终点**：能用简单语言向门外汉讲清
- **关联**：`feynman-skill`｜✅ 已装

### 5. 芒格 · 多元格栅（逆向思考）
- **触发**：决策审视 / 认知偏误 / 跨学科 / 逆向思考
- **核心模型**：逆向思考（先列失败路径再避开）；多元思维模型；激励机制诊断；能力圈+意见资格；Lollapalooza 效应
- **五环适配**：①锚定"不做什么" ②偏误 vs 理性对抗 ③多学科维度拆解 ④短句直给 ⑤避开灾难路径的行动
- **终点**：识别出系统性盲区与偏误叠加
- **关联**：`munger-skill`｜✅ 已装

### 6. 纳瓦尔 · 杠杆与第一性（重新定义）
- **触发**：财富 / 职业 / 欲望 / 杠杆 / 特定知识
- **核心模型**：杠杆思维；特定知识；欲望即合同；重新定义术（先重定义关键词）；痛苦→系统重构
- **五环适配**：①锚定"问题被如何定义" ②定义 vs 传统对抗 ③杠杆结构拆解 ④对称短句 ⑤加杠杆 or 重构系统的行动
- **终点**：判断该加杠杆还是重构系统
- **关联**：`naval-skill`｜✅ 已装

### 7. 见路不走 · 循规律（预留概念卡）
- **触发**：路径依赖 / "大家都这么做" / 从众焦虑
- **核心模型**：不唯经验、不唯教条；实事求是按客观规律行事；"见路不走"（《天幕红尘》）
- **五环适配**：①锚定"正在走哪条路" ②跟随 vs 自证对抗 ③规律条件拆解 ④平实直陈 ⑤基于规律的自有路径
- **终点**：说清"为什么这条路在此刻成立/不成立"
- **关联**：无现成 skill（可用女娲蒸馏）｜🔲 预留

### 8. 塔勒布 · 反脆弱（预留）
- **触发**：风险 / 不确定性 / 黑天鹅 / 杠铃策略
- **核心模型**：反脆弱；杠铃策略；否定法（知道不做什么）；凸性偏好
- **五环适配**：①锚定"最坏情形" ②脆弱 vs 反脆弱对抗 ③风险敞口拆解 ④克制直陈 ⑤先不亏后求进的行动
- **终点**：判断方案在波动中受益还是受损
- **关联**：`taleb-skill`｜🔲 预留

### 9. 女娲 · 蒸馏思维（元卡 · 模式工厂）
- **来源**：花叔 `alchaincyf/nuwa-skill`（MIT）｜2026-08-25 正式入库，安装前已过安全审计（SKILL.md＋scripts 全量扫描，无危险指令）
- **功能定位**：**蒸馏思维**——输入人名/主题，自动完成「六路并行采集（著作/播客访谈/社媒/批评者/决策记录/时间线，40+ 一手来源）→ 三重验证提炼 → 生成可运行视角 Skill → 盲测保真度评分」全流程。本卡是模式库的**生产入口**
- **触发**：「蒸馏XX」「造skill」「女娲」「XX的思维方式」「做个XX视角」；模糊需求如「我需要一个能帮我看透商业本质的思维顾问」（诊断路径→推荐人物→再蒸馏）
- **核心模型**：认知架构提取非角色扮演（HOW they think ≠ WHAT they said）；三重验证（跨2+领域复现／对新问题有预测力／具排他性）；五层蒸馏（表达DNA／心智模型／决策启发式／反模式／诚实边界）；保真度评分卡盲测（B级以上才收录）
- **五环适配**：①锚定"要谁的哪种判断力、用于什么场景" ②候选人物与真实需求的匹配对抗 ③采集与验证路径拆解 ④产出模式卡并按八字段登记本索引 ⑤新卡入册即用户可选，元层立即可分诊
- **终点**：新蒸馏的模式卡通过保真度验证并正式登记入册
- **边界**：借心智模型不角色扮演（红线照旧）；学术交付禁用人物表达 DNA；上游 SKILL.md 本体不接受本地改动（维护者条款），改进走 issue
- **关联**：`nuwa-skill`｜✅ 已装
