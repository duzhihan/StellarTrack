# 验证层 · 第六环

## 目的

方案产出后，确认"想对了没有"。轻量默认，重量级按需开启，避免日常思考被拖慢。

## 轻量级（默认）三检验

1. **逻辑自洽**：方案内部有无矛盾（找反驳性推理）。
2. **韧性检验 · 林奇假设扫描（G3 升级）**：
   - 第 1 步：找出**林奇假设**——"如果为假，整个方案崩塌"的那一个关键假设（通常 1-2 个，不在多）。
   - 第 2 步：检验——若该假设不成立，方案表现如何（1-2 句话描述）。
   - 第 3 步：标注——该假设的"可验证信号"是什么（什么信息能确认它成立）。
3. **可证伪性**：预设一个"失败信号"——出现什么情况应放弃或切换方案。

输出：100-200 字【验证摘要】。

## 重量级（重大决策手动调取）全五检验

1. **逻辑自洽**（完整推理链检查）
2. **反事实检验**（改变一个关键假设，重新推导）
3. **韧性检验 · 林奇假设压力测试**（对林奇假设做 3 种极端条件压力测试；识别第二候选假设）
4. **利益相关者检验**（从最强反对者视角写一份"批驳书"）
5. **可证伪性检验**（预设 3 个不同阈值的失败信号）

输出：完整【验证报告】+【韧性评分（1-10）】+【风险预警清单】。

## 输出格式

```
【验证报告】
- 逻辑自洽：[通过 / 风险点]
- 韧性：[林奇假设 + 不成立时表现 + 可验证信号]
- 可证伪：[失败信号]
- 反事实：[重量级：关键假设 + 重推结论]
- 利益相关者批驳：[重量级：最强反对 + 应对]
- 韧性评分：[1-10，重量级]
→ 方案交付（附风险说明）。
```

## 红线

- ❌ 不省略轻量三检验（含林奇假设扫描）
- ❌ 林奇假设找太多（>2 个说明拆解环没收敛，退回③）
- ❌ 重量级不默认开启（避免日常拖慢）
- ❌ 未经验证环的方案不予交付
