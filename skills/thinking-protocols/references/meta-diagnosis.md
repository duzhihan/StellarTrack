# 元层 · 元思考诊断

## 目的

进入五环前，建立思考的“坐标系”：**深度档位** → 问题分类 → 交付类型 → 视角匹配 → 模式选择 → 约束+证据。**最多 1 轮交互**，输出限长（总 ≤500 token）。

## 运行方式（默认追问驱动，非表单）

- **默认**：加载 `socratic-questioning.md`（需求模糊）/ `layered-questioning.md`（需求完全不明），**一次一问**逐层收敛——目标 → 受众/场景 → 起点材料 → 偏好禁忌；每答一层，实时填入下方五维结构。
- **快捷**：仅当用户明确说“直接给方案 / 我先把信息说全”时，才一次性呈现表单供勾选。
- **映射**：目标 → 交付类型；受众/场景 → 视角；起点材料 → 证据基底；偏好禁忌 → 约束；问题性质 → 模式推荐。
- 追问保持对话感，不审问；95% 信心即停。

## 第 0 步 · 问题分类（视角匹配前置）

| 类型 | 判定信号 |
|---|---|
| 决策类 | 要不要做 / 选哪个 / 值不值 |
| 写作/传播 | 写什么 / 给谁看 / 什么效果 |
| 研究/学术 | 研究什么 / 怎么论证 / 综述 |
| 管理/组织 | 团队 / 资源 / 制度 / 执行 |
| 关系/人际 | 沟通 / 冲突 / 合作 |
| 混合 | 以上多重交织 |

## 子模块 0 · 深度档位（G1 新增 · 自适应深度）

**目的**：按问题的**复杂度 × 风险**决定本次思考走多深——避免“简单问题被过度分析、复杂问题被浅尝辄止”。

| 档位 | 判定信号（复杂度×风险） | 流程路径 | 交互预算 |
|---|---|---|---|
| 🟢 轻（直通车） | 单一明确事实查询 / 低风险 / 时间紧迫 | 元层 → ①锚定 → ④表达 → ⑤成型（跳过②③⑥） | ≤2 问 |
| 🟡 标准（默认） | 需求模糊或一般复杂 / 中风险 | 全六环（默认路径） | ≤7 问（七确认点） |
| 🔴 深度 | 高复杂度 × 高风险 / 重大决策 / 用户显式要“想透” | 全六环 + 重量级验证 + 多假设竞争（G6 就绪时启用） | ≤10 问 |

**判定输入**：问题分类 + 用户提及的约束（时间/风险/信息量）+ 用户语气（“简单问下” vs “我要想透”）。

**规则**：
1. 用户显式指定档位 → 从其指定（如“快速给结论”→🟢）。
2. 系统推荐档位 → 附带一句话理由，用户可调。
3. 档位影响的是**环节数量与验证深度**，不影响“一次一问 / 不替拍板 / 95% 即停”铁律。
4. 档位可在环间动态调整（发现比预期复杂 → 升档，标注“升档：因 X”）。
5. **⑥模式训练会话强制 🟡 标准档**——训练需走全环（对抗/拆解/验证是思维肌肉），不得用轻档跳过。

## 子模块 1 · 交付类型（决定方案颗粒度）

| 类型 | 颗粒度 | 形态 |
|---|---|---|
| 决策指南 | 指南级 | 自然语言可执行行动指南（用户自己执行） |
| 成品交付 | 指令级 | 标注“可委派编排器：{skill}”的指令条目（编排器链式执行） |
| 混合 | 双粒度 | 指南为主，可自动化步骤标注委派接口 |

**问法（一句话）**：“这次要“你拿去决策/执行”的行动指南，还是“直接产出成品”的指令包？”

## 子模块 2 · 视角匹配（矩阵 + 双维评分）

### 视角-问题类型匹配矩阵

| 问题类型 | 高权重视角 |
|---|---|
| 决策类 | 利益相关者 × 时间尺度 |
| 写作/传播 | 受众 × 时间 × 抽象层级 |
| 研究/学术 | 抽象层级 × 时间 × 空间 |
| 管理/组织 | 利益相关者 × 空间 × 关系 |
| 关系/人际 | 利益相关者 × 时间 |

### 双维评分

每候选视角：**相关度(0-5) × 影响度(0-5)** = 权重 → 取 Top 3-5 深挖，其余折叠为“完整光谱”备查。

### 单一性检测

若 Top5 集中在同一视角大类 → 提示：“当前视角单一，建议补充“时间尺度”或“抽象层级”，避免单侧偏见。”

### 偏好记忆

用户确认/补充过的视角记入偏好，同类问题下次优先排序（只影响排序，不固化）。

## 子模块 3 · 模式选择（三态）

加载 `references/modes/index.md`：

- **选模式**：按模式卡驱动五环（经模式适配层借用心智模型，不角色扮演）
- **不选（默认）**：走通用六环基线（①流式追问②双向钢人③四象限④三选一⑤双粒度⑥轻量验证）
- **混合**：指定叠加顺序（如“先毛定矛盾，再李挖本质”）

**推荐逻辑**：求本质→李继刚；求策略/权衡→毛泽东/求是；求学习/验证→费曼；决策审视/偏误→芒格；财富/职业/欲望→纳瓦尔；路径依赖→见路不走；风险/不确定性→塔勒布。

## 子模块 4 · 约束枚举 + 证据基底

- **约束（≤5 条）**：资源（时间/钱/人/注意力）、规则（法律/政策/伦理/文化）、能力（当前边界）、关系（权力/利益）、信息（已知/未知/不可知）
- **证据基底（≤3 条）**：已知事实 / 文献 / 数据来源，标注可信度

## 输出模板（限长，一次呈现）

```
【元思考诊断】
- 深度档位：{🟢轻/🟡标准/🔴深度} + 一句话理由
- 问题分类：{决策/写作/研究/管理/关系/混合}
- 交付类型：{决策指南/成品交付/混合}
- 视角光谱：[Top3-5 + 一句话关切] ｜ 完整光谱：{折叠备查}
- 思考模式：{选：模式名 / 不选 / 混合：顺序} + 一句话理由
- 约束清单：[≤5 条，标注影响域]
- 证据基底：[≤3 条，标注可信度]
→ 请确认/补充，确认后进入五环。
```

## 红线

- ❌ 不轮询（一次呈现，勾选确认）
- ❌ 视角深挖不超过 5 个（防瘫痪）
- ❌ 不替用户定模式（只推荐 + 理由）
- ❌ 不替用户定档位（只推荐 + 理由，用户可调）
- ❌ 输出超 500 token（信息超载即折叠）
- ⚠️ 思考中一旦发现用户踩中反模式陷阱（见 `references/anti-patterns.md`），在该环结束时温和点出，不打断当前回答
