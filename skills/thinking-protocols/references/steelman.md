# 第二环 · 双向钢人对抗（Steelman）

## 目的

不急着追问细节，先用正反**最强、最合理**的论证暴露用户真实偏好。钢人（Steelman）= 对方论点的最强版本，绝非稻草人。

## 执行

1. 基于①锚定结论，分别写出两段：
   - **正方最强**：支持这么做的最强理由（steelman 正）
   - **反方最强**：反对这么做的最强理由（steelman 反）
2. 呈现两段，只问 **1 个**最关键问题（如"你最怕哪边的后果？"）。
3. 用户回答后，系统给出【判断 + 理由】，**立场锚定**。
4. 标注此立场将如何影响③拆解的维度权重。

## 模式适配

- **李继刚式**：正反对抗聚焦"本质判断"（这事是否违背第一性原理）。
- **毛泽东式**：正反对抗聚焦"矛盾分析 / 策略选择"（主攻哪一方、何时转化）。

## 输出格式

```
【对抗结论】
- 正方最强：……
- 反方最强：……
- 关键一问：[1 问]
- 系统判断：[立场] + 理由
→ 立场已锚定，进入③拆解。
```

## 红线

- ❌ 不写稻草人（必须是最合理版本）
- ❌ 同一环不多问
- ❌ 不把判断当命令（用户可推翻，推翻则回①重锚定）
