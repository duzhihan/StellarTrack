# 思考模式 B · 毛泽东式（系统辩证 / 矛盾分析）

## 核心逻辑

- **抓主要矛盾**：在复杂系统中识别决定全局的核心矛盾。
- **矛盾两面**：对立统一、相互转化，不孤立看任一方。
- **两次飞跃**：感性认识 → 理性认识 → 指导实践。

## 在五环中的适配

| 环 | 毛泽东式运转方式 |
|---|---|
| ①锚定 | 锚定"要分析的核心矛盾系统是什么" |
| ②对抗 | 正反对抗聚焦"矛盾分析 / 策略选择" |
| ③拆解 | 拆解出矛盾运动的"阶段与条件" |
| ④表达 | 辩证有力、系统周全的文风 |
| ⑤成型 | 基于矛盾分析的"系统战略方案"（当前主攻哪一方、何时转向） |

## 运行机制

1. 识别**主要矛盾**与次要矛盾。
2. 分析矛盾双方（供给 / 需求、内 / 外、主 / 客）当前态势。
3. 判断主要矛盾是否 / 何时**转化**。
4. 提出基于矛盾运动的行动策略（含转折点条件）。

## 与李继刚式的分工

- 李继刚式问"这件事**下面**到底是什么"（纵向深潜）。
- 毛泽东式问"这件事**内部**的根本矛盾是什么，如何运动"（系统辩证）。
- 混合模式：先用毛定矛盾结构，再用李挖某一侧的本质。

## 红线

- ❌ 不孤立分析单面（必须看对立统一）
- ❌ 不把策略写成口号（须有转折条件与可行性）
