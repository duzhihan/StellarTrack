# 文风对标

## 目的

正式文稿在动笔前，先校准文风基调——对标权威媒体文体，锚定行文规范。**先定基调，再动笔**，避免写成"四不像"。

## 四档文风基调

| 档位 | 对标 | 基调 | 适用场景 |
|------|------|------|---------|
| **A 求是体** | 《人民日报》《求是》 | 庄重严谨、政论基调 | 党建/思政/理论文章/领导讲话 |
| **B 新华社体** | 《新华社》评论 | 实字当头、简短有力、数据说话 | 新闻稿/评论/工作通讯 |
| **C 先锋体** | 《先锋》党刊 | 观点鲜明、思想性强、有锐度 | 政论/时评/深度报道 |
| **D 文汇体** | 《文汇报》 | 文化视角、学理深度、人文温度 | 文化评论/学术随笔/人文文章 |

## 执行步骤

1. **定档**：根据文体与场合，从 A/B/C/D 选一档（或组合，如"求是+春秋"）
2. **加载规范**：按所选档位套用四条规范（见下）
3. **校准后交还**：输出文风基调卡，供写作阶段作为硬约束

## 四条通用规范（所有档位共用）

### 1. 语句打磨
- 优化句式结构，替换模糊笼统词汇
- 剔除口语化、模板化、AI 化表述
- 行文通顺严谨、用词精准凝练，兼具庄重平实与鲜活有力

### 2. 逻辑架构
- 梳理全文内在逻辑脉络
- 调整段落排布顺序，清晰划分内容层级
- 理顺内容主次关系，搭建条理清晰、层次分明、闭环完整的框架

### 3. 内容格调
- 剔除空话套话与重复冗余内容
- 修正语病及逻辑瑕疵，提升文本信息密度
- 校准专业术语，把控行文节奏

### 4. 总体基调
- 锚定主流官方文本行文基调
- 坚守正式、严谨、正统的写作准则
- 兼顾文本严谨度与文字传播质感

## 输出格式

```
【文风基调卡】
- 所选档位：A 求是体（庄重严谨）
- 核心约束：判断句开段 / 禁空话套话 / 逻辑闭环 / 术语精准
- 禁用清单：口语化表述 / AI 痕迹词 / 堆砌排比
→ 基调已定，交还总调度作为写作硬约束。
```

## 红线

- ❌ 不混用档位（一篇一个基调）
- ❌ 不为"文采"牺牲严谨性
- ❌ 不套用与文体不符的档位（如写论文套新华社体）
