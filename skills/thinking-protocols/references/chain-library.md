# 思维链配方库（v1.0 · 2026-08-23 开库）

> 链＝经验证的卡序列配方。三通道来源：青龙预制／用户选择时增删（改动版即时生效）／临场组合事后沉淀。
> 格式：链名｜绑定场景｜序列｜适用条件｜失效信号

## 预制配方（首批六条）

**C1 选题链**｜星躔 C1 定题
苏格拉底追问 → 横纵分析 → 矛盾分析 → 哲学观三问
适用：任何新题起步。失效信号：题目本身已极清晰，直接过三问即可。

**建构链**｜模型建构类子问题（C3 高发，殿下点名的场景）
第一性原理 → 专家会诊 → 矛盾分析 → 四象限（仅作收尾整理件）
适用：理论框架怎么搭、机制模型怎么立。失效信号：子问题实为用词/表达类——立即换用词链。

**核查链**｜结论可信度检验（C5 主用）
事实核查 → 双向钢人 → 最小实验
适用：命题已成、疑其不真。失效信号：无可试错域则去第三环。

**评审链**｜C5 审稿
双向钢人 → 事实核查 → 专家会诊
适用：全稿或整节评审。失效信号：时间只够一卡时，单用钢人。

**用词链**｜表达与措辞争议（C4/C6）
双层解释 → 用词对照 → 文风四档
适用：具体词句的学术语域之争。失效信号：争议实为立场问题→转哲学观三问。

**方向收敛链**｜S 层长程助产态主流程
分诊 → 苏格拉底追问循环 → 哲学观三问 → 基础方向卡（出口按守门①）

## 生活域预制配方（2026-09-12 入册，来源：人间世 `renjianshi` v1.0 首建）

> 四场景各一条。铁律：一题一线；确需复合先定主场景，次线只取一张卡。
> 详细逐环操作与交付模板见 `~/.workbuddy/skills/renjianshi/references/场景路由与配方.md`。

**恋爱结构链**｜恋爱与亲密关系
接住 →（L1 情绪命名）→ 五层结构扫描 → 必要时移情探测 → 综合诊断图
适用：冲突可指认、情绪可控。失效信号：情绪浓度过高（先只做 L1）；扫描中出现强阻抗（停止扫描，标记阻抗点，转模式线）。

**边界修复链**｜家人朋友与社交
接住 → 交换层 ＋ 边界层（两页，不满五层）→ L3 课题分离 → L2 边界设定 → L4 非暴力沟通（出话术）
适用：矛盾长期、强度中等、关系不宜切断。失效信号：对方掌握实际控制权且无法承受后果（改走权力解析链）；出现自伤／家暴（走红线转介）。

**权力解析链**｜职场导师与同事
接住 → 矛盾分析卡（先定主要矛盾）→ 权力层 → L4 非暴力沟通（出话术）→ 三动作对比（含“暂不动”选项）
适用：存在结构性权力差或“说不出口”的压抑。失效信号：主要矛盾实为制度问题（人际工具全部失效）；用户只想听“我没错”（先芒格卡自省）。

**方向收敛链（生活域版）**｜自我与人生方向
接住 → 认知演进引擎自我码（天赋挖掘／人生设计）→ 重大抉择加五重审视 → 最小实验 → 复评日期
适用：议题指向自己、时间尺度一年以上。失效信号：实为具体关系情绪外溢（退回对应场景线）；用户要立刻要答案（高耗时长程链，先明说代价）。
