# 阶段六：撰写与迭代

**目标**：将上述要素整合为流畅的引言/综述段落，完成格式规范。

## 6.1 建议撰写顺序

1. 先写阶段一的"引言漏斗"（1 段）
2. 再写阶段五的"模型建构与操作化"（1-2 段）——最难但最重要
3. 然后写阶段二的"理论框架定位"和阶段三的"文献分类与评述"（2-3 段）
4. 最后写阶段四的"研究缺口定位与述评展望"（1-2 段）

**原则**：如果发现逻辑不顺畅，调整段落顺序，不强制按阶段次序呈现。

## 6.2 字数分配指导

| 模块 | 占文献综述总字数比例 |
|------|-------------------|
| 引言 | 约 20% |
| 主体 | 约 50% |
| 述评与展望 | 约 30% |

**注意**：此比例为通用参考，可根据目标期刊体例和实际论述需要做 ±5% 调整。

## 6.3 结语段的结构功能清单（替代模板句）

结语按功能组句，**禁止套用固定句式模板**——"综上所述""概言之""换言之"等开头词在多数目标文体中属禁用项，以研究者文体规则为准。四个功能各司其职：

| 功能 | 要做的事 | 自查 |
|---|---|---|
| 收束共识 | 一两句概括领域已确立的判断，主语是"研究/学界"而非罗列人名 | 是否压缩到两句内 |
| 锐化缺口 | 把缺口写成一句可反驳的判断句，而非"仍显不足"式弱陈述 | 能否被反例攻击 |
| 立起本文 | 一句话说明本文接住哪个缺口、给出什么新解释 | 是否与前文承诺一致 |
| 指明去向 | 给出一到两个具体方向，落到对象或机制，不落"未来值得研究"套话 | 是否具体可做 |

**文风红线**：成稿后按研究者文体规则全文扫描（禁用词表、判断句开头密度、破折号频次等）。嵌入毕方体系时，加载 `duzhihan-paper-editor/references/style-rules.md` 作为最高优先级文风约束；独立模式按研究者自定文体规则执行。

## 6.4 防流水账专项自检（写完每段后自查）

- [ ] 如果删掉这段，逻辑是否断裂？
- [ ] 读者记住的是知识点，还是人名和年份？
- [ ] 是否指出了明确的空白或矛盾？
- [ ] 是否自然引出了自己的研究切入点？
- [ ] 复杂对比是否考虑用图表呈现而非文字堆砌？

## 6.5 收尾钩子：獬豸联动（成稿后建议执行）

综述成稿后，建议自动衔接 **獬豸（reference-check / claim-audit）** 做引用核验：

1. 将综述中的引文标注与参考文献清单交给 `reference-check` → 逐笔核验书目是否存在、编号对应是否正确
2. 对综述中的关键主张（贡献判断/缺口表述）跑 `claim-audit` → 回源核验是否被原文支持
3. 核验结果反馈后，据实修订综述（宁缺毋滥，不保留无法回源的引用）

> 分工：**离朱负责"看透"（写作中的评述定位），獬豸负责"查证"（写作后的引用核验）**——一前一后，闭环完整。
