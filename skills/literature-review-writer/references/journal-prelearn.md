# 期刊画像预学习协议（引言/摘要/文风/图表五区）

> **定位**：与 title-assessor 轨道B同构的动态预学习机制——标题层之外，为引言定稿、摘要撰写、文风校准、图表制作提供实证对照依据。
> **原则**：画像先于写作——无画像不写引言（档案存在则消费，缺失则按本协议补建）。

## 一、取样规则

1. 取目标刊**近两年**同域文章 **5-8 篇**（优先：同研究主题 > 同方法类型 > 同栏目）
2. 来源：知网/刊官网真实目录与全文；每篇记录 作者+题名+年期，留痕可回查
3. 取样不足 3 篇时如实标注「样本不足，结论降级为参考」，不得冒充规律

## 二、五区分析维度

| 区 | 分析维度 | 产出 |
|---|---|---|
| 标题区 | （已有 title-assessor 轨道B档案，引用即可） | 概念对举/热点词/结构/字数规律 |
| 引言区 | 结构模式统计（漏斗形态/段落数）、首句类型分布、核心问题句位置、政策引用习惯、字数区间 | 引言区画像 |
| 摘要区 | 句式模式（目的-方法-结论 vs 单句式）、字数、关键词数量与构词 | 摘要区画像 |
| 文风区 | 判断句开头密度、辩证转折频率、破折号/套话使用、段落节奏 | 文风区画像 |
| 图表区 | 图表密度、类型偏好（理论论证图 vs 流程图）、标注风格 | 图表区画像 |

## 三、画像档案模板

存档路径：`references/目标刊档案/{刊名}_画像.md`

```markdown
# {刊名} 画像档案
> 建档日期：{YYYY-MM-DD}｜取样：n 篇（列表附后）｜复用记录：{}
## 一、标题区（可引用既有 title-assessor 档案结论）
## 二、引言区
- 结构模式：{如"政策开路型 x/n 篇"}｜段落数中位：{}｜问题句位置：{}
- 首句类型：{判断句 x/n…}｜政策引用习惯：{}
- 字数区间：{}
## 三、摘要区 {句式模式/字数/关键词}
## 四、文风区 {判断句密度/转折频率/红线词使用观察}
## 五、图表区 {密度/类型/标注}
## 附：取样清单
```

## 四、复用规则

1. 跨稿件复用：同一目标刊的论文共用一份画像，用一次在「复用记录」追加一行
2. 增量充实：某区缺失时只补该区，不推翻已建档区域；新证据与旧结论冲突时走 ADR 记录改判
3. 时效：档案超过 2 年或刊物改版（栏目/体例大变）须重新取样校准
4. 消费时点：C4 引言定向与摘要初拟、C6 语言校准、C8 格式核验四处强制对照画像

## 五、降级说明

无法获取足够全文样本时：仅据目录与摘要页建「标题区+摘要区」两级画像，引言/文风区标注「待补」，并在决策流水登记限制——不得凭通用方法论冒充实证画像。
