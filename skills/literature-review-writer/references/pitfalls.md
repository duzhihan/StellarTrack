# 常见误区与防坑指南

## 一、五大常见误区

| 误区 | 表现 | 修正方法 |
|------|------|---------|
| **照搬照抄** | 直接搬用他人综述，不看原始文献 | 每篇核心文献必须亲自阅读摘要或全文 |
| **罗列堆砌** | "XX 认为…XX 提出…"流水账 | 按"问题维度"重新分类，每类有主题句 |
| **选择随意** | 把知识性背景资料和研究性文献混为一谈 | 严格按文献类型筛选，只纳入 C 刊论文 + 经典专著 |
| **与主题脱节** | 综述写完就扔，后续章节完全不回应 | 写作中随时反问"这段与我的核心问题何关？" |
| **泛泛而谈** | 覆盖面面俱到，读者抓不住核心 | 聚焦 1-2 个最关键的缺口，余者提及即可 |

## 二、常见问题排查指南

| 问题现象 | 可能原因 | 解决方法 | 对应阶段 |
|---------|---------|---------|---------|
| 综述像"资料汇编" | 以作者为中心组织 | 按"问题维度"重新分类文献 | 阶段三 |
| 看不出创新点 | 缺少"研究缺口"段落 | 在每类文献后添加"局限"评述，汇总为缺口 | 阶段四 |
| 理论与案例脱节 | 理论框架与核心问题无关 | 返回阶段二，重新选择"贴身"的理论 | 阶段二 |
| 假设无法检验 | 概念未操作化 | 将抽象概念分解为可观察的变量 | 阶段五 |
| 逻辑不连贯 | 跳跃式写作 | 按阶段六推荐的撰写顺序重写 | 阶段六 |
| AI 综述内容空洞 | 未提供足够的文献信息或核心问题不清晰 | 补充核心文献的核心观点，重新生成 | 阶段三 |
