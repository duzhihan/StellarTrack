# 前置四象限分析

**此步骤不写入最终论文，仅用于确认任务边界与风险。耗时约 15-30 分钟。**

## 2.1 共同已知（确认任务边界）

| 维度 | 需明确内容 | 自检问题 |
|------|-----------|---------|
| 论文类型 | 期刊论文/学位论文 | 目标期刊的影响因子区间？CSSCI 来源刊/扩展版？ |
| 目标期刊/学科 | 具体期刊名称或学科方向 | 该期刊近三年是否发表过相似理论取向的论文？ |
| 预计字数 | 全文总字数 | 引言/综述部分所占比例（通常 15%-20%） |
| 交付时间 | 具体日期 | 可分配给各阶段的大致时间 |
| 核心研究问题 | 一句可陈述的问题 | 是否具备“理论可回答性”？ |

## 2.2 我的已知、你的未知（默认偏好）

如以下默认偏好不适用，请调整对应环节；否则按默认执行。

- **默认偏好一：理论纵深优先** —— 选取单一核心理论框架深入对话，而非多理论铺陈
- **默认偏好二：问题驱动** —— 文献引入必须服务于核心问题推进，非展示阅读量
- **默认偏好三：学理深度** —— 追问“何以可能、何以发生”，不止于现象描述
- **默认偏好四：可操作化** —— 理论建构必须落脚于可检验的命题（H）或研究问题（RQ）
- **默认偏好五：辩证平衡** —— 对正面效应与负面影响保持双向审视

## 2.3 我的未知、你的已知（本 Skill 已内置的判断逻辑）

本 Skill 已内置以下判断逻辑，可直接使用，无需额外说明：

- **新概念的来源**：不是凭空创造，而是从既有文献中识别“未被充分揭示的机制”，再赋予概念
- **三层模型建构方式**：批判既有理论 → 提出补充机制 → 操作化为假设/RQ
- **综述结构的实质**：不是“一个整体”，而是“一个问题推进链”——每段回应前段的遗留疑问
- **核心概念分层的必要性**：当一个核心概念具有多义性时，需做概念分层（如“游戏式传播/游戏化设计/游戏性体验”的三层区分）

## 2.4 共同未知（需要后续验证的边界）

- **新兴领域适应**：当缺乏清晰理论对话对象时，阶段二如何调整？
- **理论迁移适应性**：当研究的核心概念不来自“媒介研究”领域时，本 Skill 的模型建构逻辑是否通用？

**最小实验建议**：首次使用本 Skill 后，记录阶段二与阶段四之间的逻辑转化是否流畅；如不流畅，需补充的数据是“对应文献中是否有可直接引用的机制描述”。
