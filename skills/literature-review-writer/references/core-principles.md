# 核心理念（六原则）· 全流程 AI 介入总览 · 核心经验总结

## 一、核心理念（六原则）

**第一原则：问题驱动优先。** 文献的引入必须回答“这对推进我的核心问题有何贡献”，而非展示阅读量。

**第二原则：理论纵深优先。** 选取单一核心理论框架深入对话，而非罗列多个理论平行铺开。

**第三原则：评述结合。** “述”（概括观点）与“评”（判断价值与局限）的比例约为 4:6，每篇文献都要追问贡献与局限。

**第四原则：可操作化。** 理论建构必须落脚于可检验的命题（H）或可回答的研究问题（RQ）。

**第五原则：辩证平衡。** 不单向度拥抱技术乐观或文化悲观，对正面效应与负面影响保持同等清醒。

**第六原则：人机协同。** AI 完成可标准化的工作（检索、生成、测评），研究者完成不可替代的判断（评述、建构、决策）。

## 二、全流程 AI 介入总览

| 环节 | AI 用途 | AI 提示词模板 | 人工必须介入的判断 |
|------|---------|--------------|-------------------|
| 阶段〇-1 | 选题推荐 | “研究领域[XX]，关键词[词1][词2]，推荐 5-8 个选题方向” | 选题决策 |
| 阶段〇-2 | 定题测评 | 系统自带功能，无需提示词 | 选题可行性判断 |
| 阶段〇-3 | 标题打磨 | “标题草稿[草稿]，核心问题[问题]，提供 3-5 个优化版本” | 标题确认 |
| 阶段一 | AI 问答辅助 | “请梳理[现象]与[理论]之间的关联性” | 核心问题凝练 |

## 三、核心经验总结（DO / DON'T）

| 应做（DO） | 应避免（DON'T） |
|-----------|----------------|
| 单一理论纵深推进 | 多理论并列铺开 |
| 问题驱动（“关于 X，学界形成了什么观点”） | 作者驱动（“A 说…B 说…”） |
| 每段都在回应核心问题 | 文献成为独立的“研究现状”板块 |
| 贡献与局限均衡评述（述4评6） | 只述不评或仅批判不承认贡献 |
| 新概念必须与既有理论区分 | 随意命名新概念 |
| 假设/RQ 必须可检验 | 假设止于概念表述 |
| 辩证平衡 | 单向度技术乐观或文化悲观 |
| AI 作为辅助工具 | AI 作为作者替代 |
| C 刊论文 + 经典专著为主（学术序列）；政策与权威案例走 D 区通道入引言 | 政策/网页/学位论文混入学术文献序列 |
| 近 3-5 年文献 ≥70% | 过度依赖老文献 |
| 外文文献 ≥1/3 | 缺乏国际视野 |
| 成稿过文体规则扫描（禁用词/句式密度/模板句） | 套用“综上所述”类模板句开场 |
| 引言前两段内明示空白 | 引言泛泛而谈，迟迟不进入问题 |
