# 迭代自检清单

**写作完成后逐项核查：**

| 检查项 | 标准 | 通过/不通过 |
|-------|------|------------|
| 问题锚定 | 核心问题是否为理论问题而非现象问题？ | |
| 理论框架 | 是否有且仅有一个核心理论作为对话对象？ | |
| 文献分类 | 分类维度是否为"问题维度"而非"作者维度"？ | |
| 评述均衡 | 每类文献的"述"与"评"比例是否≈4:6？ | |
| 研究缺口 | 缺口表述是否为"从 A 和 B 均未回答 Y"而非"没人研究过"？ | |
| 模型建构 | 核心概念是否命名且与既有理论区分？ | |
| 操作化 | 假设/研究问题是否可观察、可判定？ | |
| 语言风格 | 是否"问题驱动"而非"作者驱动"？ | |
| 逻辑连贯 | 整体是否为"问题推进链"——每段都在回应核心问题？ | |
| 文献类型 | 学术序列是否以 C 刊论文和经典专著为主？政策/案例是否走 D 区通道（引言背景论证，标注来源）而非混入学术文献序列？ | |
| 时效性 | 近 3-5 年文献占比是否≥70%？ | |
| 国际视野 | 是否以本土理论为主框架并纳入必要的国际理论对话？（计入口径：含中译专著、引文内夹注的外文文献、综述正文引用的国际学者理论；不设固定比例，无为凑比例引入的无关外文文献） | |
| 引言前两段 | 是否在前两段内明确了研究空白？ | |
| 防流水账 | 是否通过了防流水账专项自检？ | |
| 标题复评 | 开写前是否已完成无条件复评并登记于总成卡 A 区？ | |
| 文风红线 | 是否通过文体规则扫描（禁用词/模板句/句式密度）？ | |

**判定规则**：任一关键项（问题锚定/理论框架/研究缺口/操作化）不通过 → 返回对应阶段修订；其余项不通过 → 局部修订后复检。
