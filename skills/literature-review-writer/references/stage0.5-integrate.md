# 阶段〇·五：前置整合（综述总成卡）

**目标**：把分散在前序各环节的材料，整合为一份《综述总成卡》，作为全部后续阶段的唯一输入。综述质量的上限在动笔前的整合。

## 铁律

1. **无总成卡不开写。** 嵌入模式下调用方未提供总成卡时，按本文件规格生成草稿交研究者确认后使用，不得跳过。
2. **整合只做客观的事。** 备料、提醒、确定、补料四件事；按综述段落预设分类是观点行为，属阶段三——本阶段产出的是素材索引（地图），不是归类方案（路线）。
3. **标题复评无条件执行。** 补检达标后一律重测，不因“没看出问题”而跳过。条件触发的守门依赖主观觉察，觉察不到就永远不评——这是系统性漏洞，用无条件闸口堵死。
4. **补检宁缺毋滥。** 找不足额时如实报告短缺，不得用低层级文件或无信源内容凑数。

## 一、总成卡六区结构

### A 区 · 定稿口径与 O 层档案（能确定的确定）

| 项 | 内容 | 来源 |
|---|---|---|
| 标题 + 复评结果登记 | 当前定稿与最近一次复评等级 | 目标定向层 |
| 核心研究问题 | 一句可陈述 | S 层锚定卡 |
| 投向期刊 / 字数 / 体例 | 决定综述篇幅占比与栏目气质 | 目标定向层 |
| 档位与深度预算 | 决定语言密度与理论浓度 | 深度预算表 |
| 读者画像 | 决定术语铺垫程度 | 目标定向层 |
| 偏好红线 | 既往被拒表述、文体禁令 | 偏好回显记录 |

### B 区 · 客观素材索引（地图，不是路线）

按主题列清单，每条四字段：

```
asset_id | 一句话内容注记 | 强度(S/A/B) | 缺口类型(对象/方法/机制/情境)
```

不做段落级分配、不预设“第几类文献”。上游精读矩阵（如 literature-analysis 的四栏笔记与对话地图）直接转写为此格式。

### C 区 · 重点提醒栏

前序环节凸显的关键概念、裁决结论、理论桥、风险点，逐条列出（≥5 条）。写作中易忘的，全放这里。

### D 区 · 补充资料任务单

#### D1 政策文件（引言政策层锚点）

- **数量**：4-5 个
- **层级口径**：国家层面优先，至少省级政府以上
- **排序**：时间从前往后 + 权威性递进（顶层规划表述 → 纲要/意见 → 部委文件 → 省级落实文件）
- **每条留痕**：文件名 / 发文机关 / 文号 / 发布日期 / 关键表述原文摘录 / 链接
- **关键表述**必须是可直接引入引言的原文句，不得转述造假
- **用途边界**：用于引言背景论证，标注文号日期；不入学术参考文献序列

#### D2 案例与数据（引言现象层证据）

- **数量**：7-10 个
- **口径**：近、新、权威、热点
- **来源优先级**：官方统计 > 权威媒体报道 > 行业权威报告 > 标志性个案
- **每条留痕**：名称 / 来源 / 日期 / 链接 / 关键数字或事实 / 统计口径与时间截面
- **排除**：自媒体内容、无信源转述；关键数字入正文前须回源核验

### E 区 · 悬而未决清单

不阻塞写作但影响后续的事项，注明影响面与清零时机。

### F 区 · 风险与红线

文体禁令、自造术语警戒、概念操作化缺口、敏感边界。

## 二、标题复评（无条件闸口）

1. **时点**：A-F 五区就位且 D 区补检达标（或有如实短缺报告）后、开写之前。
2. **动作**：将当前标题 + 核心研究问题 + 目标刊交定题评估重测（如 title-assessor 双轨预学习版）。
3. **判定处理**：
   - 维持原判（等级不变或更高）→ 登记复评结果于 A 区，放行；
   - 出现更优候选或原题降级 → 出候选对照表交研究者拍板；变更走决策记录（ADR），同步回写 A 区与 B 区索引措辞。
4. **违规后果**：未复评即开写 = 流程违规，产物退回。

## 三、出口判据（守门）

- A 区经研究者签字确认；
- B 区每条有 asset_id 可回指源文件；
- C 区 ≥5 条且含全部前序裁决要点；
- D1 达 4-5 个、D2 达 7-10 个（或有如实短缺报告）；
- 标题复评已完成并登记。
