# 综述引擎 · 文献综述撰写引擎

> **适用**：CSSCI期刊论文、学位论文的引言/文献综述写作
> **核心理念**：问题驱动 · 理论纵深 · 评述结合 · 人机协同
> **定位**：综述引擎——明察每篇文献的贡献与局限、看穿分歧根源、定位研究缺口。

---

## 一、定位与核心立场

文献综述的本质**不是“整理别人做了什么”，而是“通过评述既有研究，确立自己研究的必要性、合法性与创新性”**。

本 Skill 提炼自：
- 已发表的 CSSCI 论文《传统戏曲与新媒体交互的冲突与融合：共创中的文化调适研究》完整写作过程
- 多篇 CSSCI 论文引言的方法论特征分析
- 国社科基金申报书“文献综述”撰写规范
- C 刊写作公开课的系统性方法论

## 二、核心理念（六原则）

| 原则 | 内容 |
|------|------|
| **① 问题驱动优先** | 文献引入必须回答“这对推进我的核心问题有何贡献”，而非展示阅读量 |
| **② 理论纵深优先** | 选取单一核心理论框架深入对话，而非罗列多个理论平行铺开 |
| **③ 评述结合** | “述”与“评”比例约 4:6，每篇文献都要追问贡献与局限 |
| **④ 可操作化** | 理论建构必须落脚于可检验的命题（H）或可回答的研究问题（RQ） |
| **⑤ 辩证平衡** | 不单向度拥抱技术乐观或文化悲观，对正负效应保持同等清醒 |
| **⑥ 人机协同** | AI 完成可标准化工作（检索、生成、测评），研究者完成不可替代判断（评述、建构、决策） |

## 三、适用场景与边界

| 场景 | 适用性 | 说明 |
|------|--------|------|
| CSSCI 期刊论文的引言/文献综述 | ✅ 高度适用 | 本 Skill 基于此场景提炼 |
| 学位论文的理论框架与文献综述 | ✅ 适用 | 需增加“文献回顾章节完整性”检查 |
| 需要建构理论模型的研究论文 | ✅ 高度适用 | 阶段五“模型建构”为核心产出 |
| 纯综述类论文（非研究论文） | ⚠️ 部分适用 | 可参考框架，但需补充系统性检索方法 |
| 书评或评论文章 | ❌ 不适用 | 不需要理论建构与假设检验 |
| 技术报告或研究报告 | ❌ 不适用 | 理论深度要求与设计目标不匹配 |

## 四、使用方式

### 独立模式（用户直接调用）

说“写文献综述”“帮我综述一下”“写引言”等，按六阶段工作流执行。首次使用建议完整走六阶段；再次使用可跳过部分环节，但**保留“前置四象限分析”和“迭代自检清单”**。

### 嵌入模式（被论文工厂等调用）

当被其他 skill 调用时，识别调用方传入的标记，**跳过交互询问，直接加载对应规则文件执行**：

```
[嵌入模式：文献综述][输入：综述总成卡（必选，规格见 references/stage0.5-integrate.md）+核心问题][上下文：前序产物]
```

执行规则：
0. 加载 `references/stage0.5-integrate.md`（前置整合：校验《综述总成卡》——缺卡则基于调用方传入的前序产物生成总成卡草稿，交调用方确认后生效；卡内含 D 区补检任务单与无条件标题复评闸口，均须执行完星躔可进入阶段一）
0.5 加载 `references/journal-prelearn.md`（期刊画像预学习：目标刊的引言/摘要/文风五区画像——档案存在直接消费，缺失按协议取样补建后消费；引言定稿与文风校准须对照画像）
1. 加载 `references/stage1-intro.md`（引言漏斗：问题锚定；§1.0 先做素材就位检查——背景层消费总成卡 D1 政策文件、现状层消费 D2 权威案例，未达标退回阶段〇·五。**星躔嵌入时本阶段产物定性为“引言素材稿”，移交 C4 作框架确认输入，正式引言在 C4 定向、C6 成文**）
2. 加载 `references/stage2-theory.md`（理论框架定位；星躔嵌入时产物移交 C4）
3. 加载 `references/stage3-classify.md`（文献分类与评述；§3.0 涌现式归类两遍法——第一遍问题打标不预设框架、第二遍自然聚合、框架收敛三问、归类方案卡 GATE 由研究者选定后才进入正式分类）
4. 加载 `references/stage4-gap.md`（研究缺口定位；缺口是论证结论而非检索转写）
5. 加载 `references/stage5-model.md`（模型建构与操作化；星躔嵌入时产物移交 C4）
6. 按 `references/stage6-writing.md` 整合成稿（含结语段结构功能清单与文风红线扫描；星躔嵌入时加载 style-rules.md 为最高优先级文风约束）
7. 产出返回调用方：综述稿+**缺口卡**（接口件契约模板），并按 6.5 收尾钩子建议引用核验联动（引用查核+主张审计），不要求用户介入
8. **过关门（嵌入模式）**：产出须经星躔评分维度库六维打分留痕，加权 ≥7.0 放行；产物命名按 `{论文号}_C3-{序号}_{产物名}` 编码，版本 v0.x=过程稿、v1.0=过门生效版

## 五、六阶段工作流速查

| 阶段 | 目标 | 规则文件 | 交付物 |
|------|------|---------|--------|
| **阶段〇** | AI 辅助选题与定题（新增前置） | `stage0-topic.md` | 候选选题 + 定题测评 + 打磨标题 |
| **阶段〇·五** | 前置整合：综述总成卡（嵌入模式必经入口） | `stage0.5-integrate.md` | 《综述总成卡》六区 + D 区补检 + 标题复评登记 |
| **阶段一** | 引言漏斗（问题锚定） | `stage1-intro.md` | 引言初稿（约300字），核心问题前两段内出现 |
| **阶段二** | 理论框架定位 | `stage2-theory.md` | 核心理论 + 1-2 补充理论，逻辑链条 |
| **阶段三** | 文献分类与评述 | `stage3-classify.md` | 2-3 类文献“贡献+局限”辨析 |
| **阶段四** | 研究缺口定位与述评展望 | `stage4-gap.md` | 述评与展望段落（约400字） |
| **阶段五** | 模型建构与操作化 | `stage5-model.md` | ≤3 核心概念 + 机制模型 + 2-3 假设/研究问题 |
| **阶段六** | 撰写与迭代 | `stage6-writing.md` | 流畅的引言/综述段落 + 格式规范 |

> **撰写顺序建议**（v2.2.0 修订，与星躔 v11.0 对齐）：归类（阶段三 §3.0）→ 理论框架（阶段二）→ 评述成文（阶段三）→ 模型建构（阶段五）→ 缺口收束（阶段四）→ **引言最后成稿**（阶段一：初稿可先行供对照，定稿必后置于模型与结构之后，并经期刊画像校准）。

## 八、使用说明

- **首次使用**：完整执行六阶段，按“迭代自检清单”逐项核查。某阶段不顺畅时记录问题点并调整对应操作，无需从头开始。
- **再次使用**：可跳过部分环节，但保留“前置四象限分析”和“迭代自检清单”。
- **迁移适应**：应用于不同学科时，阶段二“理论框架定位”需按学科差异调整。验证方式：检查“理论的价值与不足”判断是否符合该学科问题语境。
