# GB/T 7714-2025 格式引擎

> 参考文献著录规则全量手册
> 标准：GB/T 7714-2025（顺序编码制）
> 适用范围：论文模式输出、课题申报模式输出

---

## 一、总则

### 1.1 引用方式：顺序编码制

正文中引用的文献按其出现的先后顺序连续编码，将序号置于方括号中。

- 单篇引用：`[1]`
- 多篇连续引用：`[1-3]`
- 多篇不连续引用：`[1,3,5]`
- 引用具体页码：`[1]25` 或 `[1]25-26`
- 多次引用同一文献：使用首次出现的序号

### 1.2 著录项目

每个参考文献条目必须包含以下项目（依文献类型不同，部分项目可为可选）：

| 项目 | 说明 | 必选 |
|------|------|:--:|
| 主要责任者 | 作者/编者/译者等 | ✅ |
| 题名 | 文献标题 | ✅ |
| 文献类型标识 | [M]/[J]/[D]/[C]/[N]等 | ✅ |
| 其他责任者 | 译者、校者等 | 可选 |
| 版本 | 第X版 | 可选 |
| 出版项 | 出版地、出版者、出版年 | ✅ |
| 卷期号 | 期刊的卷、期 | 期刊必选 |
| 页码 | 引用页码或总页码 | ✅ |
| 获取和访问路径 | DOI/URL | 电子资源必选 |
| 数字对象唯一标识符 | DOI | 如有则必选 |

### 1.3 标点符号规范

- 责任者之间用逗号分隔（中文文献）
- 责任者之间用逗号分隔（英文文献姓全大写，名缩写）
- 题名后用文献类型标识，如 `. [J].`
- 出版项中用冒号、逗号分隔
- 参考文献末尾不用句号

## 二、各类文献的格式规范

### 2.1 期刊论文 [J]

**格式**：
```
[序号] 主要责任者. 文献题名[J]. 刊名, 出版年份.
```

**中文示例**：
```
[1] 喻国明, 陈雪娇. 生成式AI浪潮下内容生产的模件化转向[J]. 编辑之友, 2024.
```

**英文示例**：
```
[2] VAN DIJCK J, POELL T, DE WAAL M. The platform society: public values in a connective world[J]. Information, Communication & Society, 2018.
```

**殿主项目格式要求**（仅保留年份，删除期号和页码）：
```
[1] 喻国明, 陈雪娇. 生成式AI浪潮下内容生产的模件化转向[J]. 编辑之友, 2024.
[2] VAN DIJCK J, POELL T, DE WAAL M. The platform society: public values in a connective world[J]. Information, Communication & Society, 2018.
```

**责任人著录规则**：
- 中文责任者：姓在前，名在后，责任者之间用逗号分隔（不用分号）
- 英文责任者：姓全大写，名缩写（首字母大写 + 点号），责任者之间用逗号分隔
- 3人以内全著录；超过3人，著录前3人后加", 等"或", et al"

### 2.2 专著/图书 [M]

**格式**：
```
[序号] 主要责任者. 书名[M]. 版本(第1版可省略). 出版地: 出版者, 出版年.
```

**示例**：
```
[3] 雷德侯. 万物: 中国艺术中的模件化和规模化生产[M]. 张总, 等译. 北京: 生活·读书·新知三联书店, 2005.
[4] WILLIAMS R. Marxism and literature[M]. Oxford: Oxford University Press, 1977.
```

### 2.3 学位论文 [D]

**格式**：
```
[序号] 责任者. 论文题名[D]. 保存地: 保存单位, 年份.
```

**示例**：
```
[5] 张三. 新媒体环境下戏曲传播的模件化研究[D]. 北京: 中国传媒大学, 2023.
```

### 2.4 会议论文 [C]

**格式**：
```
[序号] 责任者. 论文题名[C]//会议录名称. 出版地: 出版者, 出版年: 页码.
```

**示例**：
```
[6] 李四. AIGC微短剧的文化折扣研究[C]//2024中国新媒体传播学年会论文集. 上海: 复旦大学出版社, 2024: 156-170.
```

### 2.5 报纸文章 [N]

**格式**：
```
[序号] 责任者. 文章题名[N]. 报纸名, 出版日期(版次).
```

**示例**：
```
[7] 王五. AI微短剧出海的文化挑战[N]. 人民日报, 2025-03-15(12).
```

### 2.6 电子资源 [EB/OL]

**格式**：
```
[序号] 主要责任者. 题名[EB/OL]. (发布日期)[引用日期]. 获取和访问路径.
```

**示例**：
```
[8] 国家广播电视总局. 2024年全国广播电视行业统计公报[EB/OL]. (2025-04-20)[2025-05-01]. https://www.nrta.gov.cn/xxx.
```

### 2.7 报告 [R]

**格式**：
```
[序号] 责任者. 报告题名[R]. 出版地: 出版者, 出版年.
```

**示例**：
```
[9] 中国互联网络信息中心. 第55次中国互联网络发展状况统计报告[R]. 北京: CNNIC, 2025.
```

### 2.8 标准 [S]

**格式**：
```
[序号] 标准制定机构. 标准名称: 标准编号[S]. 出版地: 出版者, 出版年.
```

### 2.9 专利 [P]

**格式**：
```
[序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

### 2.10 古籍

**格式**：
```
[序号] 作者. 书名[M]. 版本类型. 出版地: 出版者, 出版年(如果信息全).
或简化为：[序号] 作者. 书名. 卷册.
```

**示例**：
```
[10] 王夫之. 宋论[M]. 刻本. 金陵: 曾氏, 1865(清同治四年).
```

## 三、参考文献表格式

### 3.1 整体要求

- 标题："参考文献"（居中，不编号）
- 排列：按正文中引用出现的顺序连续编码
- 每条参考文献左对齐，序号置于方括号中
- 参考文献末尾不加句号

### 3.2 特殊规则

**殿主项目专属格式要求**（以下规则覆盖上述通用规则中不一致的部分）：

1. **仅保留年份**：删除期号和页码（期刊论文）
2. **作者著录**：中文作者逗号分隔（不用分号）；英文作者姓全大写，名缩写首字母；**超过3人的文献，全部著录所有作者，不使用"等"或"et al"简写**
3. **末尾不加句号**：所有参考文献条目末尾不加句号

### 3.3 格式自检清单

- [ ] 所有引用是否在正文中有对应的参考文献条目？
- [ ] 所有参考文献条目是否在正文中被引用？
- [ ] 引用序号是否连续？
- [ ] 作者姓名格式是否正确（中文：逗号分隔；英文：姓全大写）？
- [ ] 期刊年份是否都经过核实（无"未来"年份）？
- [ ] 文献类型标识是否正确（[J]/[M]/[D]/[C]/[N]等）？
- [ ] 是否按要求删除了期号和页码（殿主项目规则）？
- [ ] 英文文献的卷期号、DOI是否完整？
- [ ] 中文文献的标点符号是否为全角？

## 四、常见错误与修正

| 常见错误 | 正确做法 |
|---------|---------|
| 作者之间用分号分隔 | 用逗号分隔 |
| 英文作者名全大写 | 仅姓全大写，名缩写 |
| 期刊论文包含期号和页码 | （殿主规则）删除期号和页码 |
| 英文标题每个词首字母大写 | 仅首词首字母大写（专有名词除外） |
| 出版年后加句号 | 不加（殿主规则） |
| 文献类型标识位置错误 | 紧跟在题名之后，如 `. [J].` |
| 引用未发表/未来年份的文献 | 核实后删除或确认出版状态 |

## 五、快速校验口诀

```
顺序编码有方括，作者逗号莫用分。
中文姓名前后序，英文大写姓在前。
期刊仅留年份项，期号页码全删完。
类型标识跟题名，末尾无点清清爽。
文献须在文中引，条条对应莫虚悬。
```
