# C 环节母版适配 · 工序动词表与守门分级

> 定案：2026-08-23（殿下照准三层分离方案）｜上位文件：SKILL.md v12.x 第五节路由规则
> 命题：C 科研范式骨架不变，适配所有写作类型。
> 核心判断一句话：**C 的骨架不是"科研流程"，而是"生产流水线"；科研只是流水线上的一种装载。换文体＝换装载，不换流水线。**

## 一、三层分离架构

### 第一层 · 不变层（文体无关的操作系统）

五件永不因文体改变：**C1-C11 工序顺序、守门点位置、接口契约、带号流转、产物命名规范。**
「科研范式框架不能变」的准确含义：范式活在装载里，不在骨架里。

## 二、守门分级（框架不变边界内的弹性）

守门点**位置一个不撤**，检查项按档位标定深度：

| 档位 | 守门深度 | 每点检查项 |
|---|---|---|
| 学术档 | 全强度 | 七要素守门（现状，一字不改） |
| 规范／传播／申报档 | 轻量三项 | ①受众对不对 ②事实有无出处 ③格式合不合要求 |

## 三、固定流程 skill 嵌入三型法（殿下问：讲义/教材类已装 skill 如何发挥作用）

已装 skill 自带固定流程，嵌入星躔按覆盖范围分三型，**入库时先判型再落格**：

### 甲型 · 单工序引擎型（流程只覆盖一道工序）

- **嵌法**：直接作该工序×档位格的默认引擎或试挂位；其内部固定流程＝该格的执行标准
- **配套动作**：入库时把其流程蒸馏为六字段 M 方法卡——**卡为正身（怎么干的标准），skill 为引擎（干活的工具）**；skill 缺席时按卡人肉执行不掉链子
- 例：oh-story→C7 净化；title-assessor→C4 标题

### 乙型 · 跨工序指令包型（流程覆盖 C1-C6 多道工序）

- **嵌法**：整段流程作该档位的**指令包主体**挂在 C 骨架外层运行；C 工序动词表充当"对账单"——每过一道工序，用动词翻译表核对该 skill 流程走到哪一步，守门仍由星躔把持
- **铁律**：乙型 skill 的内部流程让位于星躔工序边界——**到守门点必须停下交验，不许一口气跑完**；其产物命名改用星躔带号制
- 例：gongwen-draft（规范档 C1-C6）、nssfc（申报档）、雕龙（传播档）、未来的教学档指令包

### 丙型 · 独立成品型（与 C 流程无接口，产出即交付）

- **嵌法**：不进管线，登记 T 注册表「外延可选项」栏，殿下点名直用；产物若需回流（如视觉件并入稿件），在 C8 合卷时以附件身份入卷
- 例：ljg-card／ljg-present（视觉输出）、lieflat-charts（图表成品）

### 判型口诀

**盖一格＝甲，盖一排＝乙，不进楼＝丙。** 新装任何 skill 先判型，判不了按甲型试挂观察。
