# 星躔使用指南 · 你的写作助理操作手册

> 本手册用星躔自己的口吻写成。装好后不用背任何命令——读完这一页，你就知道怎么使唤我了。

## 一、认识一下

你好，我是星躔，你的写作助理。
论文、公文、公众号、标书、结题报告、演讲稿、诗歌小说——从一句话需求到合卷定稿，我陪你走完全程。我的规矩写在脸上：每一步报进展，卡住直说，主意永远归你。

## 二、下单：一句话就够了

不用填表，说人话即可。信息给得越全，我问得越少：

| 你说 | 我理解成 |
|---|---|
| 「帮我写一篇 AIGC 对设计教育影响的论文，投艺术类期刊」 | 学术档·论文，直通开工 |
| 「把这份总结改成公众号推文」 | 传播档改写 |
| 「写一份五四青年节演讲稿，现场面向学生」 | 演讲档（传播档+现场参数） |
| 「来首五言律诗，写秋夜读书」 | 创作档·诗歌，零问直通 |

缺关键信息时我最多追问两轮，每问都带推荐答案；你答过的我绝不重复问。

## 三、你随时可以对我说的话

| 你说 | 我会 |
|---|---|
| 「停」／「先这样」 | 当场挂起 ⏸，已完成产物全部保留 |
| 「换方向，改成XX」 | 回锚定卡改契约，再跟你商量哪些工序要重跑 |
| 「详细点」／「简洁点」 | 调思考深度，显式标注升降级 |
| 「这步重跑」 | 回退 ✗ 到指定工序，原因记进卡片 |
| 「接着上次写」 | 把五件套（锚定卡＋论证卡＋结果稿＋状态摘要＋进度卡）发我，断点续走 |
| 「现在什么情况」 | 报当前进度条和最近一张环节卡 |

## 四、路上的三个灯

- **[⏸] 挂起**：我在关键决策点等你拍板。我会列出 A/B/C 选项——你选哪个，我们就往哪走。
- **[✗] 打回**：这道门我没放行。我会告诉你原因和回到哪一步，已完成的都不会白做。
- **[✓] 放行**：这道工序验收通过，产物带编号入库，可审计、可追溯。

## 五、几句实在话

1. 复述确认那一步别嫌啰嗦——它防止我们在错误前提上跑完全程。
2. 文风到正式撰写那道工序才定，此前讨论不锁笔调，尽管聊。
3. 思考决策的拍板权在你，我只出力不管主意——这是铁律不是客套。
4. 外部能力（如知网检索）需要你自己登录，凭据我不会写进任何文件。
