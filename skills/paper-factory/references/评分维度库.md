# 评分维度库（守门度量 · 六维固定权重）

> **用途**：每道守门打分留痕，跨工序、跨论文可比。评分不是形式——**无评分表的 GATE 视为未执行守门**。
> **来源**：2026-08-22 论文③ C3 复盘（加权 4.15/10 判定程序不合格）后确立。

## 六维权重（全工序统一）

| 维度 | 权重 | 度量要点 |
|---|---|---|
| 内容质量 | 30% | 实质产出是否成立（评述/框架/装配/校验质量随工序转义） |
| 逻辑严密性 | 20% | 推理链条完整、依赖不倒置、结论有推导过程 |
| 证据可回指性 | 15% | 每个主张可回指到 asset_id/接口件字段 |
| 规范合规性 | 15% | 工序协议+文风红线+编码规范遵守度 |
| 可读性 | 10% | 读者头栏、决策点显式、术语密度 |
| 适配度 | 10% | 期刊画像/档位要求匹配度 |

## 评分表模板（每道 GATE 必附）

```markdown
# GATE 评分表 · {工序} {产物名} {版本}
| 维度 | 得分(1-10) | 依据（可回指） |
|---|---|---|
| 内容质量 30% | | |
| 逻辑严密性 20% | | |
| 证据可回指性 15% | | |
| 规范合规性 15% | | |
| 可读性 10% | | |
| 适配度 10% | | |
| **加权合计** | | |
## 结论：通过 / 条件通过（列条件）/ 不通过（列回退目标）
## 挂起项：{显式列出，无则写"无"}
```

## 判定线

- **≥7.0**：通过放行
- **5.0-6.9**：条件通过——挂起项显式列出并登记决策流水，清零前不得进入下游两道工序
- **<5.0**：不通过，按回退矩阵重跑

## 纪律

1. 评分必须附可回指依据，空泛好评无效
2. 区分「已实测/推断/未验证」，不把推断写成事实
3. 殿主裁决（含"都同意/继续"按推荐落定）原话记入决策流水，评分表随附
4. 事后补做的守门须标注「追认」并说明原因——补做优于隐瞒
