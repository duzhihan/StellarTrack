# 评论模式 — 完整执行指南

> 本文档是论文工厂「评论模式」的详细执行手册
> 调用方：SKILL.md 中"模式三：报刊/网络评论模式"的流水线
> 核心引擎：雕龙叙事 Skill（学术化改造版）
> 执行方式：逐阶段推进，每阶段结束后检查质量

---

## 质量保障策略

评论模式采用**自检驱动 + 人工终审**的轻量级保障：

| 层级 | 方式 | 检查内容 | 性质 |
|:--:|------|---------|------|
| L1 结构质量 | 八刀自检 | 论证自洽、观点-证据平衡、切口具体、语言自然、结构完整、价值锚点、传播力、学术底线 | AI自检（八维度打分，≥5/10通过） |
| L2 学术底线 | 伦理检查 | 不造假、不误导、不编造数据 | 雕龙叙事伦理模块自动审查 |
| L3 人工终审 | 殿主判断 | 观点力度、政治敏感性、发表适宜性 | **最终决策始终属于殿主** |

**与其他模式的差异**：评论模式不使用多Agent审稿和闸门机制。原因有三：
1. 评论的字数（1000-3000字）和创作周期远短于论文，多Agent审稿的成本收益不成比例；
2. 评论的核心质量由"观点独特性"和"传播力"决定，这些维度不适合Agent打分；
3. 评论的发表容错空间较大——可以在发布后根据读者反馈调整，不像论文一旦投稿就很难撤回。

> 💡 评论模式的质量保障最终依赖殿主的判断。八刀自检和伦理检查是**辅助工具**，不是替代判断。

## 一、雕龙叙事的学术化改造

> ⚠️ **版本依赖声明**：本文档引用雕龙叙事·心法（dragoncraft-core）v3.1.0 的模块2/3/4/5/6/7。若雕龙Skill升级导致模块编号或功能发生变化，需同步更新本文档中的模块引用。当前映射关系：模块2=拉波夫公式、模块3=八刀评估、模块4=MBTI人格、模块5=探索式设计、模块6=去AI化7条、模块7=叙事伦理。

### 1.1 改造逻辑

雕龙叙事是为商业叙事/品牌叙事/个人IP设计的，核心工具是"叙事八刀评估框架"和"拉波夫最小故事公式"。要将它用于学术评论，需要做以下映射：

| 雕龙原始概念 | 学术评论映射 | 改造要点 |
|------------|------------|---------|
| **叙事八刀 — 历史**（因果链是否自洽） | **论证链是否自洽** | 检查核心论点每一步推导是否可追溯 |
| **叙事八刀 — 辩证**（叙事与事实平衡） | **观点与证据平衡** | 观点是否有学术/数据/事实支撑？是否存在过度叙事？ |
| **叙事八刀 — 现象**（起点是否真实可感） | **切口是否具体** | 评论的切入点是否是一个具体的、可感知的现象？ |
| **叙事八刀 — 语言**（是否自然有温度） | **学术底蕴+大众表达** | 专业概念是否已转化为可理解的日常语言？ |
| **叙事八刀 — 形式**（拉波夫公式完整性） | **结构完整性** | 是否有开篇钩子→论证递进→结尾升华？ |
| **叙事八刀 — 存在**（服务于自我认同/社会协作） | **价值锚点** | 这篇评论让读者"带走什么"？ |
| **叙事八刀 — 美感**（金句密度+意象质量） | **传播力** | 是否有可传播的金句/比喻/意象？ |
| **叙事八刀 — 元反思**（虚构但不自知） | **学术底线** | 是否存在"看起来很对但缺乏证据"的判断？ |

### 1.2 拉波夫公式 → 评论结构模板

雕龙的拉波夫最小故事公式：
```
（抽象）→ 定位 → 复杂化 → 评价 → 解决 → 尾声
```

学术化改造后的评论结构：
```
（标题钩子）→ 现象切入 → 张力揭示 → 学术剖析 → 观点升华 → 读者带走
```

| 拉波夫步骤 | 评论映射 | 功能 | 字数占比 |
|-----------|---------|------|---------|
| 抽象 | 标题钩子 | 一眼抓住读者（3秒决策） | 5% |
| 定位 | 现象切入 | 具体的、可感知的案例/事件/现象 | 15% |
| 复杂化 | 张力揭示 | "表面上看是A，实际上是B"——揭示矛盾/悖论 | 25% |
| 评价 | 学术剖析 | 用学术视角/理论工具深度分析 | 30% |
| 解决 | 观点升华 | 给出判断/解读/新的理解框架 | 20% |
| 尾声 | 读者带走 | 一句话让读者觉得"读完值了" | 5% |

### 1.3 MBTI人格 → 评论人设

雕龙的MBTI叙事人格映射，在学术评论中改造为"评论人设"：

| 雕龙人格 | 评论人设 | 适用场景 | 语言特征 |
|---------|---------|---------|---------|
| INTJ 冷静战略家 | **深度分析型** | 学术随笔、专业评论 | 冷静、系统、数据驱动、有框架感 |
| INFJ 隐喻疗愈 | **人文思辨型** | 文化评论、社会观察 | 隐喻丰富、哲思性强、有人文温度 |
| ENTP 颠覆者 | **反常识型** | 观点评论、争议话题 | 犀利、反直觉、直击要害 |
| ENFJ 鼓舞者 | **建设型** | 政策评论、发展建议 | 乐观、建设性、有号召力 |

**默认人设**：INTJ 深度分析型（契合殿主的学术底色）。可根据选题自动微调。

## 阶段一：选题聚焦

### 1.1 目标
从学术视角出发，找到一个适合大众传播的评论切口。核心原则：**学术是底色，传播是形式**。

### 1.1 入口条件
- **殿主指定选题**：殿主已给出具体评论方向（如"写一篇关于XX现象的评论"）→ 直接进入Step 3观点锚点确立
- **系统自主扫描**：殿主未指定方向 → 执行Step 1热点扫描 + Step 2学术切口选择
- **已有叙事骨架**：殿主已有选题和叙事结构 → 跳过阶段一~二，从阶段三评论撰稿开始

### 1.2 执行步骤

**Step 1：热点/现象扫描**
- 识别当前文化/传播/文艺领域的热点现象或争议话题
- 判断标准：
  - 该现象是否具有"张力"（表面与实质的落差/多方的争议/反直觉的发现）？
  - 该现象是否能用殿主的学术工具（文艺学/艺术学理论/传播学）做深度解读？
  - 该现象是否有"时间窗口"（正在发生或刚刚发生）？

**Step 2：学术切口选择**
- 用殿主的学术工具箱找一个"最小可行分析单位"
- 不是"写一篇关于XX的评论"（太宽泛），而是"用YY理论/概念分析XX现象中的ZZ面向"
- 切口公式：`[学术概念/理论] × [具体现象] = [评论选题]`

**示例**：
- 理论：模件化生产（雷德侯）
- 现象：AIGC微短剧批量出海
- 选题：AI短剧出海热的冷思考——模件化生产的文化折扣

**Step 3：观点锚点确立**
- 用1-2句话确定这篇评论的核心论点
- 格式："这篇评论要说的是：[一个反常识/反直觉/不同于主流看法的判断]"

**Step 4：传播潜力评估**
- 标题吸引力：3秒内读者能否理解核心关切？（1-5分）
- 共鸣度：目标读者是否会觉得"这说的就是我"？（1-5分）
- 传播力：是否有可被引用的金句/观点/框架？（1-5分）
- 时间窗口：现在发是否是最佳时机？（1-5分）

### 1.3 调用资源
| 资源 | 用途 |
|------|------|
| `references/editor-prompts.md` 模板1（评论适配版） | 选题生成 |
| `references/style-fingerprint.md` | 文风参考（评论态） |
| 雕龙叙事·心法 模块5 | 探索式叙事设计（碎片化→探索→所有权感） |

**输出产物**：评论选题方案（含现象+学术切口+核心论点+传播潜力评估）

**检查点写入**：`📁 论文输出/[项目名称]/01-评论选题.md`

## 阶段二：叙事骨架构建

### 2.1 目标
用学术化改造后的拉波夫公式，构建评论的完整叙事骨架。

### 2.2 操作步骤

**Step 1：填充六步骨架**

```

**>> 下一步**：选题确认后 -> 自动进入阶段二（叙事骨架构建）。
【标题钩子】（1句话，3秒吸引）
  → 从核心论点中提炼"最反常识的那一句"

【现象切入】（150-300字）
  → 一个具体的、读者能感知到的案例/事件/数据/场景
  → 原则：不说"近年来XX成为热点"，而是说"上周在XX上看到……"

【张力揭示】（250-400字）
  → "表面上看是A"（大众的通常理解/媒体报道的叙事）
  → "但实际上是B"（你的学术视角揭示的深层逻辑）
  → "这种张力反映了一个更大的问题：……"

【学术剖析】（300-500字）
  → 用1-2个学术概念/理论框架深度分析
  → 关键：不是"掉书袋"——每个学术概念都必须用日常语言解释一遍
  → 可以引用数据/研究/历史先例来支撑分析

【观点升华】（200-300字）
  → 从个案上升到规律/趋势
  → 给出一个清晰的判断（不是"既要…又要…"的折中论）
  → "这说明……"或"这意味着……"

【读者带走】（50-100字）
  → 一句让人记住的话（金句/比喻/意象/反问）
  → 让读者觉得"读完这篇，我看世界的方式变了那么一点点"
```

**Step 2：八刀自检**

填充骨架后，用雕龙八刀（学术化版）做自检：

| 维度 | 检查项 | 不合格时的修改方向 |
|------|--------|-----------------|
| 论证自洽 | 核心论点每一步推导是否可追溯？ | 补充缺失的推理步骤 |
| 观点-证据平衡 | 每个判断是否有事实/数据/引用支撑？ | 增加锚点，删除无支撑的判断 |
| 切口具体 | 切入点是否是一个读者能"看到"的现象？ | 增加具体场景/案例 |
| 语言自然 | 学术概念是否已转化为日常语言？ | 用"换句话说"补充解释 |
| 结构完整 | 六步骨架是否完整？有无缺失步骤？ | 补全缺失步骤 |
| 价值锚点 | 读者读完能"带走"什么？ | 强化"读者带走"这一步 |
| 传播力 | 是否有可被引用的金句/比喻？ | 在观点升华处增加金句 |
| 学术底线 | 是否存在"无证据的断言"？ | 补充证据或标注"个人判断" |

**Step 3：人设校准**
- 确认本篇的评论人设（默认INTJ深度分析型，可微调）
- 检查全文语言是否与人设一致

### 2.3 调用资源
| 资源 | 用途 |
|------|------|
| 雕龙叙事·心法 模块2（拉波夫公式） | 六步骨架生成 |
| 雕龙叙事·心法 模块3（八刀评估） | 骨架自检 |
| 雕龙叙事·心法 模块4（MBTI人格） | 人设校准 |
| 雕龙叙事·心法 模块7（叙事伦理） | 学术底线检查 |

**输出产物**：完整叙事骨架（六步框架已填充）+ 八刀自检报告

**检查点写入**：`📁 论文输出/[项目名称]/02-叙事骨架.md`

## 阶段三：评论撰稿

### 3.1 目标
按叙事骨架撰写评论正文，注入殿主的评论态文风。

### 3.2 评论态文风（与论文态的差异）

| 文风特征 | 论文态 | 评论态 |
|---------|--------|--------|
| 句长 | 40-70字长句链 | 20-40字中短句，节奏感强 |
| 判断句开段 | 严格应用 | 可用，但更灵活——允许场景描写开段 |
| 设问自答 | 每500-800字1次 | 频率更高——每300-500字1次 |
| 主语使用 | 禁用"本文""笔者" | 允许"我/我们"（建立作者与读者的亲近感） |
| 学术术语密度 | 高（每个术语有明确定义） | 低（每个术语必须附带日常语言解释） |
| 段落长度 | 300-500字 | 100-250字（适合移动端阅读） |
| 结尾方式 | 边界过渡（引出下一段） | 金句/反问/读者带走 |

### 3.3 撰稿流程

**第一步：按六步骨架逐段撰写**

对每一步，注入对应的文风约束：

```

**>> 下一步**：骨架确认后 -> 自动进入阶段三（评论撰稿）。
【标题钩子】→ 必须包含核心判断/反常识点/设问，12-20字
【现象切入】→ 以具体场景/案例/数据开头，2-3段，每段100-150字
【张力揭示】→ 判断句开段→个案展开→反常识判断→设问自答过渡，2-3段
【学术剖析】→ 学术概念→日常解释→案例应用→意义提炼，3-4段
【观点升华】→ 从个案上升到规律→给出清晰判断→限定条件，2段
【读者带走】→ 1段，金句/比喻/反问，30-50字
```

**第二步：五层清稿管线（评论态适配）**

加载 `references/ai-vocabulary-filter.md`（五层清稿管线），评论模式下执行：
- Layer 1 Quick Checks：评论模式放宽——允许每500字2-3个破折号（增加口语节奏感），其他4项同论文模式
- Layer 2 短语黑名单：与论文模式相同的严格标准，禁用全部中英文AI味词汇
- Layer 3 结构反模式：评论模式更严格——完全禁止"首先/其次""一方面/另一方面"等机械连接词，禁用Binary Contrast和Tripling
- Layer 4 虚假施动者：与论文模式同标准
- Layer 5 五维评分：评论模式软约束≥30/50（评论允许更多口语感和个人色彩）

**第三步：雕龙去AI化7条补充检查**

五层清稿管线覆盖了系统性去味，在此基础上叠加雕龙叙事·心法 模块6（去AI化检测7条）作为评论专项补充：
- 规则1：模板词检查（"在当今时代""值得注意的是"等）→ 删除
- 规则2：句句工整检查（句子长度方差过小）→ 拆分长句、插入短句
- 规则3：逻辑词过密检查 → 删除不必要的"因此""所以"
- 规则4：细节锚点检查 → 确保有具体的姓名/时间/地点/数字
- 规则5：情感抽象检查 → 将"震撼""感动"转为具体描写
- 规则6：人格一致性检查 → 确保全篇语气统一
- 规则7：过度解释检查 → 删除"这意味着/换句话说"

**第四步：传播力优化**
- 金句检查：每500字至少有1句可被单独引用的判断句
- 标题强化：确保标题能在3秒内传达核心价值
- 首段钩子：确保开篇第一段就能"抓住"读者

### 3.4 调用资源
| 资源 | 用途 |
|------|------|
| `references/style-fingerprint.md` 评论态文风 | 文风约束 |
| `references/ai-vocabulary-filter.md` | 五层清稿管线（评论态适配，L1-L5全层执行，五维评分≥30/50） |
| 雕龙叙事·心法 模块6（去AI化7条） | 评论专项去AI补充（雕龙7条：模板词/句句工整/逻辑词过密/细节锚点/情感抽象/人格一致/过度解释） |
| 雕龙叙事·心法 模块3（八刀评估） | 成稿质量终检 |

**输出产物**：评论初稿（已完成五层清稿+雕龙去AI化7条+传播力优化）

**检查点写入**：`📁 论文输出/[项目名称]/03-评论初稿.md`

## 阶段四：观点打磨与平台适配

### 4.1 观点打磨

**Step 1：观点力度校准**
- 检查核心论点是否过于中庸（"既要…又要…"）→ 如果是，强化一边
- 检查是否有"无证据断言"→ 如果是，补充证据或加限定词
- 检查是否有"过度断言"→ 如果是，增加限定条件

**Step 2：学术底线的最后确认**
- 雕龙伦理检查（原则1：不造假，但真话不全说）
- 检查是否存在：数据编造、引用造假、断章取义、偷换概念
- 如果存在"省略了关键信息"，标注[此处省略了X]

**Step 3：辩证张力终检**
- 确保评论不是"一边倒"
- 在适当位置加入"当然/不过/需要指出的是"等限定性转折

### 4.2 平台适配

评论的底层内容相同，但不同平台的呈现格式不同：

#### 公众号适配

| 维度 | 规则 |
|------|------|
| 标题 | 2-3个备选标题（含设问式、反常识式、数字式） |
| 段落 | 每段不超过3行（手机屏幕），大量使用视觉分段 |
| 配图建议 | 在每个关键转折点标注 [建议配图：XXX] |
| 结尾 | 引导互动（"你怎么看？欢迎留言讨论"） |
| 引导关注 | 末尾附加账号信息模板 |

#### 报刊适配

| 维度 | 规则 |
|------|------|
| 标题 | 庄重、概括性强（不同于公众号的"钩子式"标题） |
| 引文 | 如有引用他人观点/数据，必须注明出处 |
| 段落 | 允许更长的论证段落（200-300字） |
| 结尾 | 以学术判断收束（不引导互动） |

#### 学术随笔适配

| 维度 | 规则 |
|------|------|
| 标题 | 允许文学化的标题（可以用冒号式结构） |
| 个人色彩 | 允许更多"我"的视角和体验分享 |
| 论证结构 | 允许更松散的结构（不强制六步骨架） |
| 引用 | 可以引经据典（中外文学/哲学/历史） |

#### 网络评论适配

| 维度 | 规则 |
|------|------|
| 标题 | 最短、最抓人（10字以内为佳） |
| 开篇 | 第一句就是"暴击"（反常识/反转/设问） |
| 段落 | 极短段落（1-2句为一段），大量留白 |
| 节奏 | 快节奏，3分钟能读完 |
| 互动 | 设计"讨论点"引导评论区互动 |

### 4.3 输出格式

为四种平台分别输出适配版本：
- 标注 `[公众号版] [报刊版] [学术随笔版] [网络评论版]`
- 每个版本标注字数
- 公众号版附带标题备选和配图建议

**检查点写入**：`📁 论文输出/[项目名称]/04-发布就绪包.md`（含四个平台版本）

## 附二：雕龙叙事在论文模式中的交叉应用

雕龙叙事不仅用于评论模式，还可以注入论文模式以增强论证的"可读性"：

### 应用场景1：引言——"现象切入"法
传统的论文引言从"宏观政策/学术背景"开始。注入雕龙后，可以从一个**具体案例/现象**切入：
```

**>> 下一步**：
- [投稿] 可直接发布至目标平台
- [归档] 项目已归档，下次可"继续上次的[项目名称]"恢复

**>> 下一步**：初稿完成后 -> 自动进入阶段四（观点打磨+平台适配）。
不是："随着数字技术的发展，文化传播呈现出新的特征……"
而是："2024年，一部由AI生成的戏曲微短剧在B站获得200万播放……"
```
让读者（审稿人）在开篇就"看到"研究的意义，而不只是"被告知"。

### 应用场景2：论证——"张力揭示"法
在论文核心章的分析中，用雕龙的"表面A/实质B"结构来组织论证：
```
不是：直接输出分析结果
而是：先呈现"通常人们以为XX"（表面叙事），再揭示"但实际上YY"（深层分析）
```
这能增强论证的"说服力"和"惊喜感"。

### 应用场景3：结论——"读者带走"法
论文结论的最后1-2句不只是"有待进一步研究"，而是用一句有"带走感"的判断收束：
```
不是："未来研究可进一步深入探讨……"
而是："如果说XX是YY的答案，那么这个答案本身，还需要ZZ的追问。"
```

### 应用场景4：摘要——"八刀自检"
用雕龙八刀检查论文摘要质量：
- 论证自洽：摘要四要素（问题→方法→发现→贡献）是否完整？
- 现象具体：研究切口是否在摘要中清晰可见？
- 语言自然：摘要是否读起来像"人写的"而非"AI生成的"？
