# 课题申报模式 — 完整执行指南

> 本文档是论文工厂「课题申报模式」的详细执行手册
> 调用方：SKILL.md 中"模式一：课题申报模式"的流水线
> 顶层约束：`个人申报风格` Skill（CSSCI高分模板+四大核心优势+七要素规范+雷区自查表）
> 执行方式：逐阶段推进，每阶段结束后必须经过质量闸门判定

---

## 质量保障策略

课题申报模式采用**形式合规优先 + 学术评审兜底**的双层保障：

| 层级 | 闸门 | 检查内容 | 性质 |
|:--:|------|---------|------|
| L1 形式合规 | G1/G4 | 匿名性、文献真实性、字数合规、格式正确 | **致命性问题——不通过直接淘汰** |
| L2 学术质量 | G3 | 6维评审（含政策契合度）+ 四层分级诊断 | 模拟国社科评审标准 |

**与其他模式的差异**：申报模式的形式合规权重远高于论文模式。G1和G4涵盖了形式审查的红线（匿名性违规、文献年份造假），这些在论文模式中不是"致命"问题。G3增加了"政策契合度"维度，这是申报模式独有的。G2在申报模式中不设置为独立闸门——五维评分（≥35/50）作为阶段五修改迭代的内嵌软约束执行，核心评审仍由G3专家审稿兜底。

## 阶段一：政策解码

### 1.1 目标
将申报指南/政策文件中的宏观要求转化为可操作的选题方向，确保课题从起点就与政策需求对齐。

### 1.1 入口条件
- **已有申报指南**：殿主提供申报指南文件 → 直接进入Step 1政策文本精读
- **未提供指南**：殿主未提供 → 询问"请提供最新年度申报指南，或告知目标基金类型"后等待
- **已有选题方案**：殿主已有明确选题方向 → 跳过阶段一，从阶段二选题论证开始
- **已有活页初稿**：殿主已撰写活页 → 跳过阶段一~三，从阶段四评审模拟开始

### 1.2 执行步骤

**Step 1：政策文本精读**
- 输入：最新年度国家社科基金申报公告/指南（或殿主指定的其他基金公告）
- 提取关键要素：
  - 年度重点资助方向（关键词、优先领域）
  - 学科分类与选题范围
  - 限项规定与申报条件
  - 预期成果要求
  - 字数/格式要求

**Step 2：政策语义解码**
- 调用 `references/prompt-index.md` 中 XII-D02（政策语义解码——基金申报政策契合度分析）
- 将政策文本中的"官话"转化为"学术语言"：
  - "加强XX研究" → 该方向的学术前沿问题是什么？
  - "推动YY建设" → 可以从哪些理论视角切入？
  - "服务ZZ战略" → 可以对接哪些具体的研究问题？

**Step 3：选题方向生成**
- 调用 `references/editor-prompts.md` 中的 **模板1：选题生成器**（申报适配版）
- 申报适配版的额外约束：
  - 选题必须体现"国家需求"与"学术前沿"的交叉
  - 选题名称需符合国社科标题规范（不能过于文学化或过于技术化）
  - 每个选题附"政策契合度"说明（1-5分）

**Step 4：方向筛选与排序**
- 对生成的选题按以下权重排序：
  - 政策契合度（40%）：是否直接回应指南中的优先方向？
  - 学术创新性（30%）：是否在理论或方法上有可辨识的增量？
  - 前期基础匹配度（20%）：殿主已有成果是否支撑该方向？
  - 竞争激烈度（10%）：是否为近年申报热点（竞争激烈可能降分）？

**输出产物**：政策解码报告 + 3-5个优选选题方向（含政策契合度评分）

**检查点写入**：`📁 论文输出/[项目名称]/01-政策解码.md`

### 1.3 调用资源
| 资源 | 用途 |
|------|------|
| `references/prompt-index.md` XII-D02 | 政策语义解码 |
| `references/editor-prompts.md` 模板1 | 选题生成（申报适配版） |
| `references/prompt-index.md` I-01~I-04 | 文献检索辅助 |

## 阶段二：选题论证

### 2.1 → 闸门G1

### 2.2 执行步骤

**Step 1：深度文献调研**
- 调用 `deep-research`，以选定选题为核心方向
- 检索范围：CNKI + WOS，最近5年
- 重点关注：
  - 已立项的同类课题（避免重复申报）
  - 该方向的理论演进脉络
  - 核心学者的代表性成果
  - 研究方法的演变趋势

**Step 2：研究空白识别**
- 调用 `references/prompt-index.md` 中 I-04（研究空白识别）
- 从五个维度识别空白：方法空白、场景空白、规模空白、理论空白、交叉空白
- 对每个空白评估：新颖性(1-5)、重要性(1-5)、可行性(1-5)

**Step 3：前期基础论证**
- 梳理殿主已有的研究成果与选题的关系
- 说明前期成果如何为当前课题提供基础（不是简单罗列成果，而是建立"学术递进关系"）
- 调用 `个人申报风格` 中的研究基础撰写的规范和策略

**Step 4：创新点提炼**
- 提炼2-3个创新点
- 每个创新点的格式：
  - "在XX方面，提出/构建/揭示……"
  - 每个创新点必须可验证（评审专家能通过活页内容判断是否成立）
  - 不得使用"首次""开创性""填补空白"等无法验证的宣称
  - 创新点之间不能是同一维度的递进（必须是三个不同维度的独立贡献）

**Step 5：可行性评估**
- 方法可行性：技术路线是否清晰？数据/案例是否可获取？
- 团队可行性：团队配置是否合理？
- 周期可行性：研究周期是否匹配任务量？
- 风险评估：可能遇到的主要困难和应对预案

### 2.3 闸门G1：选题论证评审

**判定标准**：
| 维度 | 评分(1-5) | 判定 |
|------|----------|------|
| 政策契合度 | ___ | ≥3 通过 |
| 学术创新性 | ___ | ≥3 通过 |
| 前期基础支撑度 | ___ | ≥3 通过 |
| 方法可行性 | ___ | ≥3 通过 |
| 竞争差异化 | ___ | ≥3 通过 |

**判定逻辑**：
- 五项全部 ≥3 → G1通过，进入阶段三
- 任一项 <3 → G1不通过

**输出产物**：G1通过报告 + 选题论证报告（含文献地图+研究空白+创新点+可行性评估）

**检查点写入**：`📁 论文输出/[项目名称]/02-选题论证.md`

## 阶段三：活页撰写

### 3.1 顶层约束注入

在撰写之前，**必须**加载 `个人申报风格` Skill 作为顶层约束。该Skill包含：

1. **四大核心优势**：
   - 政策为逻辑起点（不是文献驱动，而是政策需求→学术回应）
   - 问题-理论-现实因果紧密（三者的推导链不能断裂）
   - 精炼精准严谨含蓄（不能用"填补空白""颠覆性"等浮夸表述）
   - 学术递进段落300-500字（每段一个完整的论证单元）

2. **七要素规范**：严格按照国社科活页模板的结构填写

3. **雷区自查表**：常见被拒原因排查

### 3.2 活页结构（标准模板）

活页必须按照以下结构撰写（不可增删章节）：

```

**>> 下一步**：G1通过 -> 自动进入阶段三（活页撰写）。

**>> 下一步**：政策解码确认后 -> 自动进入阶段二（选题论证）。
一、选题依据
  1.1 研究背景（从政策需求出发，不是从文献出发）
  1.2 国内外研究现状（分维度综述，末段定位本文的研究空间）
  1.3 学术价值与应用价值

二、研究内容
  2.1 研究对象（明确界定边界）
  2.2 总体框架（研究内容之间的逻辑关系）
  2.3 重点难点（分别说明）
  2.4 主要目标

三、思路方法
  3.1 基本思路（用箭头链表述：XX → YY → ZZ）
  3.2 研究方法（分别说明每个方法解决什么问题）
  3.3 研究计划（时间表）
  3.4 可行性分析

四、创新之处
  4.1 学术思想创新
  4.2 学术观点创新
  4.3 研究方法创新
  （每个创新点不超过200字）

五、预期成果
  5.1 成果形式（论文/专著/报告/数据库等）
  5.2 使用去向与预期社会效益

六、研究基础
  6.1 课题负责人前期成果（与本课题的关系，建立"学术递进"）
  6.2 核心团队成员介绍

七、参考文献
  （GB/T 7714-2025格式，10-20条核心文献）
```

### 3.3 各章节撰写要点

#### 一、选题依据

**1.1 研究背景**（500-800字）

从政策出发，不是从文献出发。

撰写逻辑链：
```
国家战略/政策方向（如"文化数字化""国际传播能力建设"）
  → 该方向在具体领域的现实需求（如"AIGC微短剧出海的文化折扣问题"）
    → 现有研究的不足（已有哪些研究？缺少什么？）
      → 本课题要解决的核心问题（1-2个问题，不是3-5个）
```

关键约束：
- 不要写成"XX很重要"的证明文
- 每一个"重要性"的声明必须有数据或政策文件的支撑
- 最后一句必须明确本课题的研究问题

**1.2 国内外研究现状**（1500-2000字）

分3-4个维度/主题综述，不能按作者罗列。

每个维度的内部结构：
```
维度标题（一个判断句，不是主题名）
  ├── 代表性成果（3-5个，说明做了什么+贡献）
  ├── 评述（已有研究的共同特征/趋势）
  └── 不足（已有研究的共同盲点/遗漏）
```

末段"收口"：明确指出已有研究的共同不足，自然引出本课题的研究空间。

**1.3 学术价值与应用价值**（各200-300字）

- 学术价值：对哪个理论/领域有什么推进？（具体到理论名称和研究边界的修正）
- 应用价值：对哪个实践主体有什么指导？（具体到"谁"和"做什么"）

#### 二、研究内容

**2.1 研究对象**（200-300字）
明确定义研究边界——什么在研究范围内，什么不在。

**2.2 总体框架**（800-1000字）
- 不是简单罗列"研究内容一/二/三"
- 而是说明各项研究内容之间的**逻辑关系**：
  - 是递进关系（A→B→C）？
  - 是平行关系（A和B共同支撑C）？
  - 是层次关系（宏观→中观→微观）？
- 用一段话概述框架，然后逐项展开（每项200-300字）

**2.3 重点难点**（各200-300字）
- 重点：本课题必须解决的核心问题（1-2个）
- 难点：解决的障碍是什么（技术/数据/理论/方法）？如何克服？

**2.4 主要目标**（200-300字）
- 对应研究内容，每项内容对应一个目标
- 目标描述必须是可验证的（"完成什么"而非"试图做什么"）

#### 三、思路方法

**3.1 基本思路**（300-500字）
用箭头链表述：现象观察 → 问题提炼 → 理论建构 → 实证检验 → 结论输出

**3.2 研究方法**（500-800字）
对每个方法，说明三个问题：
1. 这个方法是什么？（简洁定义）
2. 为什么选择这个方法？（匹配研究问题的理由）
3. 具体怎么操作？（操作步骤）

人文社科方法论关注点：
- 质性研究：编码逻辑、理论抽样、饱和判断
- 量化研究：统计方法、样本量计算、效应量报告
- 混合研究：整合逻辑（解释性序列/探索性序列/聚敛设计）

**3.3 研究计划**（表格）
| 阶段 | 时间 | 主要任务 | 阶段性成果 |
|------|------|---------|----------|

**3.4 可行性分析**（300-500字）
- 理论可行性（已有理论资源是否充足？）
- 方法可行性（方法是否成熟？有无技术障碍？）
- 数据可行性（数据/案例是否可获取？有何合作基础？）
- 团队可行性（团队成员的专业背景是否匹配？）

#### 四、创新之处

每个创新点不超过200字。格式：
```
[序号]. [创新维度]：[具体做了什么]
```

禁止的表述：
- "首次""开创性""填补空白"
- "在理论上有重要贡献"（空洞）
- "具有重大的学术价值和应用前景"（空洞）

允许的表述：
- "在XX方面，提出/构建/揭示YY……"
- "将ZZ理论从AA领域扩展到BB领域……"
- "通过CC方法，首次系统性地分析了DD现象……"（有"系统性"这个限定词，"首次"勉强可用）

#### 五、预期成果

成果形式必须具体：
- "CSSCI期刊论文3-5篇"（不是"发表高水平论文若干"）
- "研究报告1份"（不是"形成研究报告"）
- "XXX数据库"（如果有数据采集计划）

#### 六、研究基础

**核心原则**：不是罗列成果，而是建立"学术递进关系"。

每项前期成果必须说明：
1. 该成果做了什么（1句话概括）
2. 与本课题的学术递进关系（该成果为本课题的哪个部分提供了什么基础）

禁止：
- 罗列全部发表论文（只列与本课题直接相关的）
- 罗列与本课题无关的荣誉/奖项
- "课题负责人学术造诣深厚"（空洞评价）

#### 七、参考文献

- GB/T 7714-2025格式
- 10-20条核心文献
- 必须包含：经典理论文献 + 前沿研究文献 + 方法论文献
- 禁止：引用未发表/未来年份的文献

### 3.4 撰写顺序

不是从头写到尾，而是按以下顺序：

1. **研究内容（二）**：先写——这是活页的核心，写好后其他部分围绕它展开
2. **思路方法（三）**：第二——方法与内容必须一一对应
3. **创新之处（四）**：第三——提炼内容中的创新点
4. **选题依据（一）**：第四——写好内容和方法后，才清楚"依据"怎么写最有力
5. **预期成果（五）**：第五
6. **研究基础（六）**：第六
7. **参考文献（七）**：最后

## 阶段四：评审模拟

### 4.1 → 闸门G3

### 4.2 评审执行

**Step 1：加载评审模板**
- 加载 `references/editor-prompts.md` 中的 **模板3：审稿系统**（申报适配版）
- 申报适配版的额外约束：
  - 增加"匿名性检查"为致命性问题（形式审查红线）
  - 增加"文献年份核实"为致命性问题
  - 增加"政策契合度"为独立评审维度
  - 增加"前期基础与课题关系"为独立评审维度

**Step 2：形式审查优先**
在正式评审之前，先执行形式审查：

| 检查项 | 判定 | 不通过的后果 |
|--------|------|------------|
| 匿名性 | 无任何可推断申报人身份的信息 | 致命——直接淘汰 |
| 文献年份 | 所有引用文献年份可核实 | 致命——直接淘汰 |
| 字数合规 | 各部分字数在模板限制内 | 高优——可能退回修改 |
| 格式正确 | 章节结构符合国社科活页模板 | 高优——可能退回修改 |
| 重复申报 | 未与在研项目高度重合 | 致命——直接淘汰 |

**Step 3：六维效度评审**
在模板3的五维效度基础上，增加第六维：

维度6：政策契合度
- 选题是否直接回应了申报指南中的优先方向？
- 研究成果是否能服务于国家战略需求？
- 政策契合的论述是否有具体的政策文件支撑（不能泛泛地说"服务于XX战略"）？

**Step 4：四层分级评审**
按照模板3的四层分级格式，输出完整的评审报告。

### 4.3 闸门G3：评审通过判定

**判定标准**：
- **无致命性问题**（匿名性违规/文献造假）= 硬性条件，任何一项致命问题 = 直接不通过
- 综合评分 ≥ 6/10（含政策契合度在内的六维评审）

**不通过时的输出**：
```

**>> 下一步**：活页初稿完成后 -> 自动进入阶段四（评审模拟）。
G3不通过：综合评分 [XX]/10

致命性问题：[N]项（必须解决）
高优先级问题：[N]项（严重影响立项概率）
中优先级问题：[N]项（影响评审评价）
低优先级问题：[N]项（优化建议）

【修改路线图】
按照模板3的格式输出四层分级评审报告。
```

**输出产物**：G3通过报告（如通过）/ 四层分级评审报告（如不通过）

> ⚠️ 评审-修改循环上限为3次。第3次G3仍不通过时，系统标注为"高风险申报"，建议殿主重新审视选题方向或大幅调整研究设计。

**检查点写入**：`📁 论文输出/[项目名称]/04-评审报告.md`

**>> 下一步**：G3通过 → 进入阶段五（修改迭代）。G3不通过 → 内循环最多3轮。

## 阶段五：修改迭代

### 5.1 修改引擎

调用 `references/editor-prompts.md` 中的 **模板4：修改建议生成器**（申报适配版）。

### 5.2 修改流程

**第一轮：致命性问题清零**
- 匿名性处理：全文搜索地名、机构名、实验室名、合作单位名 → 替换为通用表述
- 具体替换示例：
  ```
  ❌ "广西国传中心" → ✅ "若干省级国际传播中心"
  ❌ "越南国家电视台VTV" → ✅ "越南多家主流媒体"
  ❌ "广西华丽播文化传媒有限公司" → ✅ "多家面向越南市场的出海企业"
  ```
- 文献核实：逐篇检索CNKI/WOS确认出版年份 → 删除未发表文献 → 补充替代文献

**第二轮：高优问题解决**
- 效度问题：概念操作化、样本量计算、方法匹配论证
- 每个修改提供"原句→修改后"对照

**第三轮：中优和低优优化**
- 表达精炼、格式统一、细节补充

### 5.3 修改质量标准

- 每个修改必须达到"可写入"标准（修改后的文本可直接复制粘贴到活页中）
- 修改前后字数变化标注
- 关联影响提示（修改A是否需同步修改B？）

**输出产物**：修改后活页

**检查点写入**：`📁 论文输出/[项目名称]/05-修改后活页.md`

**>> 下一步**：修改确认后 → 自动进入阶段六（格式审校）。

## 附二：与论文模式的关键差异

| 维度 | 论文模式 | 课题申报模式 |
|------|---------|------------|
| 逻辑起点 | 学术前沿/理论对话 | **政策需求**（不是文献驱动） |
| 语言风格 | 学术论证（允许长句链） | 学术+政策语言（更精炼、更直接） |
| 文风要求 | 七大特征全部启用 | 只启用特征2（判断句）+ 特征4（三段式）+ 特征7（辩证张力） |
| 字数范围 | 8000-12000字 | 4000-7000字 |
| 格式要求 | GB/T 7714 + 期刊模板 | 国社科活页模板（固定七部分结构） |
| 关键红线 | 论文原创性 + 论证严密性 | **匿名性** + 文献真实性 + 政策契合度 |
| 评审维度 | 5维（概念/边界/方法/逻辑/可行性） | **6维**（+政策契合度） |
| 核心竞争力 | 理论框架的原创性 | **前期基础与课题的递进关系** |
