# 接口件契约（十一道门交接件模板）

> **原则**：交接不看口头，看接口件。下一工序只认契约内字段齐全的产物；缺字段守门不放行。
> **通用头栏（每份产物必带）**：一句话结论置顶 + 决策点显式标出 + 过程证据后置（读者导向，v11.0 强制）。

## 十一道接口总表

| # | 接口 | 交接件 | 必含字段 |
|---|---|---|---|
| 1 | O2→S | 定稿契约 | 档位+十变量+Before/After 对比+冲突记录 |
| 2 | S→C1 | P0 论证锚定卡 + P0-R 结果稿 | 判断句+路径三要素+来源环+验证行 |
| 3 | C1→C2 | 选题卡 | 选题名+四环节记录+评测得分+备选题 |
| 4 | C2→C3 | 总成卡/账本 | 客观索引（只描述不归类）+提醒区+补检任务单 |
| 5 | **C3→C4** | **缺口卡** | 缺口陈述+证据链（≥2 条可回指 asset_id）+本文入位声明+承重席清单 |
| 6 | **C4→C5** | **结构定案卡+素材分配表** | 节次方案+每节任务/字数/承重素材映射+摘要结语初稿 |
| 7 | **C5→C6** | **块状粗稿+装配核对表** | 每段：主张句+证据链 ≥2 条可回指+逐段勾选记录 |
| 8 | **C6→C7** | 语言定稿稿+style-rules 自查留痕 | 逐项检查记录（非打勾了事）+状态摘要 |

| 10 | C8→C9 | 格式核验单 | 引用格式终检记录+图表编号核对 |
| 11 | C9→C10→C11 | 审稿报告 / 确稿令 / 全流程档案 | P1/P2/P3 分级可回指 / 殿主签字+修改日志 / 终稿+心得三问+看板流水封存 |

## 关键接口件详规

### 缺口卡（C3→C4）

```markdown
# 缺口卡 {论文号}
## 缺口陈述（一句话强表述，禁"研究较少"弱表述）
## 证据链
- {asset_id}｜{该文献止步处}｜{未答的问题侧面}
- （≥2 条；缺口须为四类评述合观的推导结论，非检索零命中转写）
## 本文入位声明（本文以什么概念装置进入这道缺口）
## 承重席清单（全部入文素材 id + 强度）
```

### 装配核对表（C5→C6 内容冻结门）

```markdown
| 节·段 | 主张句 | 证据链 id | 评析句 | 接榫句 | 勾选 |
|---|---|---|---|---|---|
```

全勾方可进 C6；进 C6 后内容冻结，发现内容问题须在决策流水登记后回退 C5。

### 净化报告（C7→C8）

```markdown
| 指标 | 改前 | 改后 | 判据 |
|---|---|---|---|
| 禁词命中 | n | 0 | 零命中 |
| 破折号密度 | x/千字 | y | ≤2/千字 |
| "不是X而是Y" | n | m | ≤8/篇 |
| 相邻段落字数比最大值 | x | y | ≤1:3 |
```

查重栏固定标注：「外部人工环节，未执行自动查重」。
