# Story Import | 逆向导入

## 功能
将已有小说作品导入创作系统，自动完成：
1. 章节目录提取 → 重建章节列表
2. 角色识别与提取 → 生成角色档案
3. 情节摘要生成 → 补充到01-大纲.md
4. 伏笔识别 → 填充追踪/伏笔表.md
5. 文风分析 → 生成设定/文风指南.md

## 触发
- 用户说"导入我的小说" / "续写已有作品"
- Phase 0 检测到用户有已存在的txt/md文件时询问

## 流程
1. 读取用户提供的文本文件（支持.txt / .md / .docx）
2. AI逐章分析：提取角色、关键事件、伏笔
3. 生成结构化文件到项目目录
4. 确认导入结果 → 从断点续写
