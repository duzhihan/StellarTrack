国家自然科学基金申请书自检工具

【这是什么】
这是一个用来为国家自然科学基金申请书（“本子”，尤其适用建筑学）提供自检辅助的工具。由建筑历史学者刘妍制作。它本质上是一个超长prompt（本版本6万余字），以word文档格式提供。你把写好的本子丢给AI，它会按文档里的规则逐项排查问题。规则全公开，没有黑箱。

【为什么开源】
能否中“国自然”已经成为年轻学者学术生存的鬼门关。很多朋友会定论文但不会写基金。经验和信息被当作昂贵的资源。这个工具想打破一点信息壁垒。不要让套路和格式成为有潜力的年轻学者的绊脚石。

【经验从哪来】
骨架是作者刘妍个人写本子、看本子的经验，以及对"什么是连贯的逻辑"和"什么是好本子"的判断；素材包括真实的本子以及AI从网络上检索整合的评审经验（后者分量更大）。两者整合在一起，经过多轮迭代，做成现在这个超长的 prompt，所有判断标准都写在明面上。

【怎么运行】
把这份 Word 文档和你的本子同时上传给 AI，AI会自动对照规则逐项排查，生成修改意见。适用于任何AI。
文档内部按两遍制执行：第一遍生产方向走链（从材料→方法→证据→结论→目的，逐环承重测试，判断研究能否成立），第二遍文本核验（按 0/A/B/C/D 五级清单逐项过筛，定位具体缺陷）。最后输出一份诊断表格和修改建议。

【它能做什么】
只干一件事：检查你已经写好的初稿有没有硬伤和软伤。
按严重程度分级输出：
0 级：形式审查红线（限项、代码、签字、AI 违规等）——未进评审即出局；
A 级：死穴（科学问题错位、计划空壳、敏感表述等）——大概率一票否决；
B 级：重大缺陷（体量超标、方法不可行、创新点空壳等）——不修改极难中；
C 级：结构性缺陷（概念未定义、模块接口断裂、术语混乱等）——需实质性修改；
D 级：一般缺陷（排版、错别字、关键词匹配等）——影响印象分。
每级一张表，包含"问题｜具体表现｜怎么改"，并附总体判断：一句话诊断 + 三级优先级（不改就死 / 不改就难中 / 不改就竞争力不足）。

【它不能做什么】
不能给你 idea；
不能给你材料；
不能替你写，也不能替你重写。
它不会帮你完成任何你自己没有的东西。它只是一面犀利的镜子，照出你稿子里已有的问题。

【关于保密与透明】
以 Word 文档（而非Skill）的形式发布，是为了完全透明：你打开文档就能看到每一条规则，没有任何隐藏逻辑。内部prompt有强保密原则，只记录抽象的规则，而不记录它看过的本子的任何具体信息，包括研究对象、方法、关键词，更不会偷你的idea。你的本子内容只留在你的对话里。

【关于工具的自我更新】
在可以生成word的AI中（如kimi），这个工具会在使用中自我更新迭代，生成新的版本。每次评审后，AI 会把新发现的规律整合进对应条目，版本号同步更新，提供新的下载链接。（目前公开的版本是开发者手中的第61版）
开发者欢迎使用者分享更多进化后的版本。

【关于其他基金形式】
国社科等其他基金申请书自检工具，由AI在国自然的基础上，自动搜索相关基金要求和经验生成。开发者仅做了少量调试。

【最重要的话】
AI工具只是一重机械检查。思想和最重要的判断仍然是人。
