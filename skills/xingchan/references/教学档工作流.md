## S 论证锚定复核（教学档）

叠加骨架复核四要点之上，增补教学三问：
1. **学习者**：对象是谁（本科生/研究生/在职教师/小学生）？前备知识到什么程度？（决定内容深度与术语门槛）
2. **目标**：一节课/一个单元要达成什么可测目标？（用行为动词表述——“能复述/能比较/能设计/能批判”，禁用“了解/理解”式含糊动词）
3. **评估**：怎么知道目标达成了？（随堂测/任务作品/提问回馈/课后作业——评估先于活动设计，逆向设计）

**档位特有复核项（S1 段）**：学习者 + 目标 + 评估三问确认 → 进入 C1。

## C1 课程定位·学情分析（定靶）

1. **课程定位**：本讲在课程体系中的位置（第几讲/前置是什么/后续衔接什么），一句话定位卡
2. **学情分析**：目标学习者画像 + 前备知识清单 + 可能的理解难点（概念易混点/认知冲突点）
3. **目标撰写**：2-4 条可测教学目标（行为动词 + 条件 + 标准，如“给出三组数据，能独立完成单因素方差分析并解释结果”）

产出：选题卡 C1-xxx（定位 + 学情 + 目标清单）。

**守门③（定位定稿）**：目标全部行为动词可测 + 学情有依据（课标/教材/实测）→ 放行 C2。

## C3 教学环节设计（立骨）

### 标准环节链（一节课 40-90 分钟通用）

```
导入（5-8 分钟）：情境/问题/旧知唤起——让学习者"想学"
授新（15-30 分钟）：概念建构——讲清是什么、为什么
练习（10-20 分钟）：变式练习——能做、做对、说清
巩固（5-10 分钟）：小结/检测——目标达成自检
延伸（机动）：迁移任务/预告下次
```

**环节设计原则**：
- 每个环节标注**时间 + 目标对应 + 活动形式**（讲授/提问/讨论/实操）
- 难点处设“脚手架”（分解步骤/类比/可视化），易混点设“辨析对照”
- 环节间有“过渡语”预设（课堂节奏不冷场）

**守门⑤（结构门）**：环节链完整（导入-授新-练习-巩固）+ 每环节标注时间与目标对应 → 放行 C4。

---

## C4 板书与活动编排（搭架）

1. **板书设计**：主板书结构（概念图/对比表/流程图——选择与内容结构匹配的呈现形式）
2. **活动编排**：提问序列（由易到难、追问设计）、讨论分组（议题+产出+时间）、实操步骤（指令清晰可执行）
3. **课件分镜**：每页一要点、图文比例、动画使用克制（演示类动画用于过程展示，不用装饰动画）

**守门⑥**：板书结构与内容结构匹配 + 每个活动有“指令→产出→时间”三要素 → 放行 C5。

---

## C5 讲义正文撰写（填充）

按环节链撰写讲义正文：
- **概念讲授段**：定义 → 原理 → 例证 → 反例/边界（先讲清“是什么”，再讲“为什么”）
- **例题解析段**：题干 → 思路 → 规范步骤 → 常见错误警示（“这里很多同学会…”）
- **练习设计段**：基础题 → 变式题 → 迁移题（按目标分层，标注重难点）

**写作规范**：术语首次出现给定义；公式/流程给推导或出处；引例标注来源（课标/教材/文献/案例）。

**守门⑦**：概念均有定义 + 例题有完整步骤 + 引例有出处 → 放行 C6。

---

## C6 表达通俗化（打磨）

- **术语降级**：专业词首现必解释，必要时给“大白话版”（“自变量 → 我们改变的那个东西”）
- **句子口语化**：短句为主，少嵌套从句——讲义要“读得出声、听不费劲”
- **学生视角**：预判学习者卡点，在卡点处主动设问（“你可能会问：为什么这里不直接用公式？”）
- **亲和力**：可用“我们/你”拉近距离，避免居高临下的“大家必须记住”

**守门⑧**：读出声顺口 + 术语均有解释 + 卡点处有设问 → 放行 C7。

同骨架 C7：humanizer-zh 大面扫描 → lieflat-less-ai-tone 规则检。教学档额外关注：**禁“综上所述/值得注意的是/总而言之”式书面腔**（教学场景听感优先）；破折号与模板句阈值按“文体豁免”（讲义属表达性文本，阈值可宽于成稿正文）。

## C8 格式校验与合卷（课件格式规范）

1. **格式规范**：标题层级清晰（课时/环节/要点）；表格/图示编号；引用与出处标注齐全
2. **课件适配**：若交付含课件分镜，检查每页要点数 ≤3、字号可投屏、动画仅过程演示
3. **完整性检查**：目标 ↔ 环节 ↔ 评估三列对照（每一目标都能在环节中找到对应活动、在评估中找到对应检测）——**目标-活动-评估对齐**是教学档硬检查

**守门⑩**：三列对照无孤儿项（目标无对应活动/评估即孤儿）→ 放行 **C9 试讲推演**。

---

## C9 试讲推演（会审 · 教学档独有）

| 角色 | 推演什么 | 输出 |
|---|---|---|
| 学习者推演 | 坐在课堂里的学生会怎么反应？哪里会卡壳？哪里会走神？ | 卡点清单 |
| 时间推演 | 按环节时间逐段过：够不够？哪段容易超时？ | 时间校准表 |
| 目标推演 | 如果我是学生，上完课我能做到目标吗？检测题答得出吗？ | 目标达成风险项 |

**C9b 回退**：卡点过多 → C3 环节设计；目标-评估脱节 → C8 对照重查；学情误判 → O2。

**守门⑪**：三角色推演通过 → 放行 **C11 最终精校**（骨架默认）。

## C10 课后修订（按需启用）

仅在“已上过课/有反馈”时启用：课堂实录问题（哪段学生没跟上/哪个活动时间失控）→ 对应环节修订 + 修订记录入账本；跨课复用 → 走 E 层置信程序沉淀。
