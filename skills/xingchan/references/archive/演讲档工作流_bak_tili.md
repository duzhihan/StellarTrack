# 演讲档工作流（现场讲话稿 / 演讲稿）

> **档位定位**：演讲档 = 传播档在“现场会议”这一渠道下的**参数变体**——以感染力、口语化、现场带动为质量基准的表达方式。作者身份默认 = 演讲者 / 组织者。
> **一句话**：演讲是“说给人听”——让人愿意听、听得进、记得住，最后坐不住想行动。
> **母版关系**：继承传播档（可读·感染力·信息密度），额外开启“现场参数”——口语化、节奏感、互动性。骨架（S/C1-C6）不变，非独立档位。
> **加载时机**：O2 锚定卡档位 = 演讲档时加载；**与传播档工作流配合使用**（传播档为底，本文件叠加现场特有项）。
> **学术锚点**：口述传统研究“听感优先于文感”+ 修辞学“kairos（时机）与现场氛围”+ 传播学“在场感”（co-presence）。

---

## S 论证锚定复核（演讲档）

叠加传播档 C1 四要点（传播目标/读者画像/渠道特性/转发诱饵）之上，增补现场四问：
1. **场合**：会议发言 / 典礼致辞 / 动员讲话 / 党课宣讲 / 课堂教学？（决定语气庄重程度）
2. **听众**：领导 / 师生 / 同行 / 学生家长？（决定称谓与知识门槛）
3. **时长**：5 分钟 / 10 分钟 / 30 分钟？（决定结构密度，见 C2 时长对照）
4. **现场形式**：有 PPT？脱稿还是读稿？有无互动环节？（决定 C3 写法与 C5 交付形态）

**档位特有复核项（S1 段）**：场合 + 时长 + 现场形式确认 → 进入 C1。

## C1 选题（讲话主题 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节。演讲档 转义：
> 态势分析 → **场合语境（会议主题）**；选题推荐 → **讲话题目候选**；定题评测三维 → **现场感/时长/感染力**；标题打磨 → **金句题**。

1. 从 P0 论证锚定卡提取选题关键词
2. 按四环节收敛候选 → 定题评测三维均过 → 定稿选题
3. 输出选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）

**守门③（选题定稿）**：三维均过 → 放行 C2。

## C2 材料建档（素材账本 + 口语库）

复用传播档素材账本（故事/案例/数据/金句/图片），增补两类现场素材：

| 编号 | 素材 | 类型 | 用途 |
|---|---|---|---|
| S01 | “凌晨两点画室还亮着灯” | 故事 | 开场钩子 |
| S02 | “就业率 92%，背后是 200 次模拟面试” | 数据 | 说服力 |
| S03 | “在座每一个人的名字，都写在学院的荣誉册上” | 金句 | 记忆点 |

**口语库**：演讲金句要“能念出口”——写后自读一遍，拗口处立即改；长句拆短句。

**守门⑤**：核心叙事有真实故事/数据支撑 → 放行（同传播档）。

## C3 结构设计（讲话稿结构 + 时长对照）

### 标准结构（现场版）

```
开场（30 秒）：钩子——故事/提问/反常识，让全场抬头
主体（按要点）：每点 = 故事 → 观点 → 过渡；金句锚点间隔 3-5 分钟
收尾（1 分钟）：号召 + 金句升华（让人“坐不住想行动”）
```

### 时长对照

| 时长 | 结构 |
|---|---|
| 5 分钟 | 1 钩子 + 1 核心故事 + 1 金句 |
| 10 分钟 | 1 钩子 + 2-3 要点（每点一故事）+ 2 金句 |
| 30 分钟 | 开场 + 分节（每节有论点故事金句）+ 互动 1 次 + 总结号召 |

**结构检查**：开场是否“现场感”而非“书面感”（不用“尊敬的领导、亲爱的同学们”套路开场可适度）；每 3-5 分钟是否有记忆点。

**守门⑥**：开场有钩子 + 主体有故事 + 收尾有号召 → 放行。

## C4 逐段写作（口语化话术底线）

> **撰写顺序**：先写**开场钩子**（定现场基调）→ 主体要点 → 收尾号召 → 最后回读全稿，把书面句改口语。

**话术底线（在传播档基础上叠加现场特有项）**：
- **口语化**：写“说”的话，不写“读”的话——短句为主，多用“咱们/大家”，避免“该院/此活动”；书面词换口头词（“然而”→“但是”，“颇为”→“挺”）
- **听感优先**：长句拆短句；数字要“听得懂”（“92%”→“一百个里九十二个”）；不用脚注式信息
- **金句锚点**：每 3-5 分钟一句可记可传的话，写完标亮〔金句〕
- **节奏设计**：排比用于高潮，停顿用于强调；互动节点（提问/举手）自然嵌入
- **时长控制**：每分钟约 200-250 字，全稿按 C1 时长核对字数
- **禁用 AI 腔**：同传播档；另禁“首先/其次/最后”式的书面报告腔（现场版用“第一件事/第二件事”或自然过渡）

**每节强制操作**：回顾该节在讲话链的功能（钩子/论点/号召）→ 按话术底线撰写 → 读出声自查 → 更新写作状态摘要。

**守门⑦**：读出声顺口 + 金句锚点分布合理 + 字数合时长 → 放行。

## C5 对抗评审（现场感 / 口语化 / 感染力 三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 现场感评审 | 开场 30 秒能否让全场抬头？听众会不会走神？互动是否自然？ | 现场问题清单 |
| 口语化评审 | 念出来顺不顺口？有没有“读稿感”的书面长句？ | 口语问题清单 |
| 感染力评审 | 金句是否够硬？号召是否有力？情绪曲线是否完整？ | 感染力清单 |

**C5b 回退**：口语/现场问题 → C3；结构问题 → C2；场合定错 → O2。

**守门⑧**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（讲稿卡片版）

1. **讲稿卡片**：按“开场/要点/收尾”切块，每块标〔时长〕〔金句〕，便于现场扫读
2. **口头语终校**：回读全稿，标记所有书面句并改口语
3. **时长标注**：全稿标注预计时长（字数 ÷ 220），超时提示删减段落
4. 生成发布就绪包：讲稿卡片 + 全稿 + 金句清单（可另作宣传素材）
5. 如需 PPT 版式 → 另行处理（本档只管讲稿文字）

**守门⑧**：可现场脱稿扫读 + 时长合标 → 终稿交付 → 进入 E 层。
