# 创作档·诗歌子类工作流（五言/七言/现代诗）

> **档位定位**：创作档·诗歌子类 = 面对“文学审美 / 格律传统”这一话语共同体时，以意境、形式、感染力为质量基准的表达方式。作者身份默认 = 诗人 / 创作者。
> **一句话**：诗歌写的是“用最少的字，装最多的境”——不是把话说完，是把话说空，让读者自己填上。
> **母版关系**：学术档是母版，诗歌关闭“论证/证据”权重、开启“意境·形式·感染力”权重，骨架（S/C1-C6）不变；C3 由“分析驱动”切“直觉驱动，逐句炼字”。
> **加载时机**：O2 锚定卡档位 = 创作档·诗歌子类时，S/C1-C6 每道工序按本文件执行。
> **学术锚点**：司空图《二十四诗品》“象外之象，景外之景”+ 王力《诗词格律》平仄韵脚规则 + 意象语言学。

---

## S 论证锚定复核（诗歌子类）

复核四要点：
1. **诗体**：五言律诗 / 七言律诗 / 绝句 / 古体 / 现代诗？（决定 C2 格律框架与 C5 校验）
2. **题材**：咏物 / 咏怀 / 题画 / 赠人 / 即景？（决定意象取向）
3. **格律约束**：是否严格平仄押韵？（现代诗可松，律诗须严）
4. **篇幅**：律诗 8 句 / 绝句 4 句 / 古体不限？（决定 C2 结构）

**档位特有复核项（S1 段）**：诗体 + 格律约束确认 → 进入 C1。

---

## C1 选题（题材/意象 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节。创作档·诗歌子类.md 转义：
> 态势分析 → **题材冷热（可选）**；选题推荐 → **题材/意象候选**；定题评测三维 → **意象新颖性/情感真实性/格律可行性**；标题打磨 → **题眼打磨**。

1. 从 P0 论证锚定卡提取选题关键词
2. 按四环节收敛候选 → 定题评测三维均过 → 定稿选题
3. 输出选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）

**守门③（选题定稿）**：三维均过 → 放行 C2。

## C2 材料建档（意象账本）

> 与学术档“证据账本”同构但内容不同：诗歌的“证据”是**意象、情感、出典**。

| 编号 | 意象/素材 | 情感/意味 | 出典/来源 |
|---|---|---|---|
| Y01 | 秋夜·孤灯·虫鸣 | 清寂·幽思 | 古典诗词传统 |
| Y02 | 月落·霜白 | 时光流逝·清冷 | 张继《枫桥夜泊》 |
| Y03 | 故人·远书 | 思念·未达 | 自设情境 |

**素材缺口处理**：意象不足 → 提示用户补情境（不硬凑）；出典不清 → 标注〔待核〕，发布前核对。

**守门⑤**：核心意象已建档且服务于创作意图（母版迁移表 3.2，不强制覆盖率）→ 放行。

## C3 结构设计（起承转合 + 格律框架）

### 律诗标准八句结构

```
首联（起）：点题，定境（1-2句）
颔联（承）：铺展，对仗（3-4句）
颈联（转）：深化，对仗（5-6句）
尾联（合）：收束，余韵（7-8句）
```

**格律框架预置**（以五言律诗·平起首句不入韵为例）：
- 平仄谱：平平平仄仄 / 仄仄仄平平（依《平水韵》或新韵，O2 确认）
- 押韵位：双数句末字押同韵部
- 对仗位：颔联、颈联须对仗

**结构检查**：起承转合是否完整；尾联是否有“言外之意”而非直白收束。

**守门⑥**：四联齐全 + 起承转合完整 → 放行。

## C4 逐段写作（直觉驱动 · 逐句炼字）

> **撰写顺序**：先写**首联**（定境定调），再写**颔联颈联**（对仗铺展），最后写**尾联**（余韵收束）。每写完一联，验证平仄与对仗。

**话术底线（写入时即带着）**：
- **炼字**：一字一词择其最切，宁少勿滥；虚字慎用，实字托境
- **意象密度**：避免直白抒情，以景写情（“写秋夜孤寂”→“孤灯不明思欲绝”，不写“我很孤独”）
- **对仗工整**：颔联颈联词性相对、结构相对、平仄相对
- **余韵**：尾联不点破，留白给读者
- **禁用 AI 腔**：禁用“综上所述/令人深思/仿佛在诉说”等套话；不写“这首诗表达了”

**每联强制操作**：回顾该联在起承转合中的功能 → 按格律写 → 验平仄对仗 → 更新写作状态摘要。

**守门⑦**：八句成篇 + 平仄无误（初稿可标〔待核〕）+ 无 AI 腔套话 → 放行。

## C5 对抗评审（意境 / 格律 / 表达 三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 意境评审 | 象外之象？情感真挚？尾联余韵？ | 意境问题清单 |
| 格律评审 | 平仄合规？押韵正确？对仗工整？ | 格律问题清单 |
| 表达评审 | 炼字精准？有无 AI 腔？出典得当？ | 表达问题清单 |

**C5b 回退**：格律问题 → C3（重炼该联）；意境/结构问题 → C2；诗体定错 → O2。

**守门⑧**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（文体校验）

1. **格律终校**：逐句核平仄（依 O2 确认韵部）、核押韵、核对仗（颔颈联）
2. **出典核对**：〔待核〕占位全部替换或确认无误
3. **排版**：律诗 = 八句分行，可附“创作小记”（写于何境、何感）
4. 生成发布就绪包：标题（如《五律·咏秋夜》）+ 正文 + 创作小记 + 标签(#诗词 #秋夜)

**守门⑧**：平仄韵脚对仗全合规 → 终稿交付 → 进入 E 层。
