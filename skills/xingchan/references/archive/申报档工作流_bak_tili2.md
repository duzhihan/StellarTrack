# 申报档工作流（课题申报书 / 项目活页）

> **档位定位**：申报档 = 面对“项目评审系统 / 主管部门”这一话语共同体时，以政策契合、创新价值、方案清晰为质量基准的表达方式。作者身份默认 = 项目申报人 / 骨干教师 / 科研人员。
> **一句话**：申报档写的是“让评审相信这件事值得资助、你能做成”——不是写论文，是写“为什么做、怎么做、凭什么你来做”。
> **母版关系**：学术档是母版，申报档关闭“论证完整呈现”权重、开启“政策契合·创新·可行性”权重，骨架（S/C1-C11）不变。与学术档核心差异：申报档重“问题意识 + 前期基础”，不要求已出结论。
> **加载时机**：O2 锚定卡档位 = 申报档时，S/C1-C11 中 C1–C6 段的档位转义按本文件执行，C7–C11 走骨架默认。
> **学术锚点**：课题申报的根本逻辑 = “政策导向 × 现实问题 × 研究积累”三者咬合（对应国家社科/教育部人文社科申报书通用结构）。

---

## S 论证锚定复核（申报档）

复核四要点：
1. **申报层级**：国家级（国家社科/自科）/ 省部级（教育部人文社科、省哲社）/ 厅局级 / 校级？层级决定创新点与前期基础的要求强度
2. **政策导向匹配**：本课题是否契合当年指南方向？指南条目编号？（决定 C2 立论切入点）
3. **前期基础**：已有哪些相关成果 / 数据 / 平台？能否支撑“你能做成”？
4. **经费与时间**：资助额度上限？研究周期？决定 C2 预算与进度编排

**档位特有复核项（S1 段）**：层级与政策导向确认 → 进入 C1。

---

## C1 选题（问题意识+政策契合 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节；执行顺序 **①态势 → ②推荐 → ⑤选题确认（人机对话）→ ③评测 → ④打磨**，⑤未拍板不进评测。申报档 转义：
> 态势分析 → **政策动态（指南/热点方向）**；选题推荐 → **问题意识候选**；定题评测三维 → **政策契合/创新性/可行性**；标题打磨 → **申报题目格式**。

产出：选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）。

**守门③（选题定稿）**：⑤选题确认已由用户拍板 + 三维均过 → 放行 C2。

---

## C2 材料建档（论证链素材账本）

> 与学术档“证据账本”同构，但素材类型不同：申报档的素材是**政策依据、现实问题证据、前期成果、可行性条件**。

| 编号 | 素材 | 类型 | 用途 |
|---|---|---|---|
| S01 | 当年申报指南 XX 条“数字赋能基层治理” | 政策依据 | 立论切入点 |
| S02 | 现有研究对 XX 关注不足（文献缺口） | 问题证据 | 问题意识 |
| S03 | 已发表相关论文 3 篇 / 主持厅级课题 1 项 | 前期基础 | 研究积累 |
| S04 | 已建成本科生调研数据库（N=1200） | 可行性 | 条件支撑 |

**素材缺口处理**：前期基础薄弱 → 提示用户补强或调整选题定位；政策依据不清 → 检索当年指南原文，不臆测导向。

**守门⑤**：问题意识 + 前期基础均有素材支撑，无凭空断言 → 放行。

## C3 结构设计（申报档模板）

### 标准活页 / 标书结构（七段）

```
标题：{理论前缀}：{研究对象}的{核心问题}研究
一、立项依据（问题意识：现实痛点 + 政策导向 + 文献缺口，1-2 段）
二、研究内容（核心问题拆为 2-3 个子课题，对应研究目标）
三、思路与方法（技术路线：怎么干，画得出流程图）
四、创新点（2-3 条，与已有研究明确区隔，不写“首次提出”式空话）
五、预期成果（论文/报告/数据库，可考核）
六、研究基础（前期成果 + 团队 + 平台，证明“你能做成”）
七、进度与预算（按资助额度编排，经费用途合规）
```

**结构检查**：立项依据须“政策 × 问题 × 缺口”三咬合；创新点与文献缺口呼应（缺口处即创新处）；研究基础须直接支撑研究内容（不堆无关成果）。

**守门⑥**：七段齐全 + 问题-创新-基础逻辑自洽 → 放行。

## C4 逐段写作（申报档话术底线）

> 撰写顺序（与学术档不同，申报档**按活页顺序写**，评审逐段打分）：

1. **一、立项依据**（先写，定调问题意识，引政策、点缺口）
2. **二、研究内容**（核心篇幅，子课题对应目标）
3. **三、思路与方法**（可操作，忌空泛“综合运用多学科方法”）
4. **四、创新点**（精准，每条对应一个缺口）
5. **五、预期成果** → 六、研究基础 → 七、进度预算

**话术底线（写入时即带着）**：

- **政策语言精准**：引用指南原文措辞，不擅自改写政策术语；“贯彻落实”“服务国家战略”等用语规范使用
- **问题意识前置**：开篇即点明“现有研究 / 现实实践在 XX 上的不足”，不用“具有重要意义”式空泛铺垫
- **数据化表述**：前期基础用数字说话（“主持 X 项”“样本 N=”“发表 X 篇”），不写“较为丰富”“一定基础”
- **可行性可信**：研究基础只列与本题直接相关的成果与条件，不凑数；团队分工明确
- **禁夸大禁空洞**：不用“国际领先 / 填补空白 / 首次”等不可证措辞；不写“本文拟”“本项目将试图”
- **禁用 AI 腔**：禁用“综上所述 / 众所周知 / 近年来学界广泛关注”等模型套话；不写“具有重要的理论价值与现实意义”式双空话

**每节强制操作**：回顾该节功能 → 按话术底线撰写 → 写过渡句（如“在上述问题基础上，本研究拟从三方面展开”）→ 更新写作状态摘要。

**守门⑦**：政策引用准确 + 问题意识清晰 + 创新点可证 + 研究基础相关 + AI 味禁用词 ≤3次/千字 → 放行。

## C5 对抗评审（申报档三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 政策契合评审 | 是否紧扣指南？立项依据有无政策依据？ | 契合问题清单 |
| 创新价值评审 | 创新点是否成立？与文献缺口是否呼应？前期基础是否支撑？ | 价值问题清单 |
| 可行性评审 | 方法可操作？预算合规？进度可行？团队匹配？ | 可行问题清单 |

**C5b 回退**：政策/契合问题 → 回退 O2（层级/导向定错）或 C1（依据不足）；创新/价值问题 → C2/C3；可行问题 → C3 或 C5。

**守门⑧**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（申报档）

1. **格式合规**：活页 / 标书按申报通知格式（字数上限、字体、页码、匿名要求）
2. **字数核查**：各部分占比合理（立项依据 15% / 内容方法 35% / 基础 25% / 其他 25% 为常见配比，按具体通知）
3. **附件清单**：前期成果复印件、平台证明、伦理审查（如涉）等，逐条核对
4. **生成发布就绪包**：标题备选(2-3) + 正文(合规格式) + 附件清单 + 报送清单（系统提交 / 纸质报送 / 截止时间）
5. DOCX / 系统填报调用 `docx` Skill 或对应申报系统

**守门⑧**：格式全项合规 + 附件齐备 + 字数达标 → 终稿交付 → 进入 E 层。
