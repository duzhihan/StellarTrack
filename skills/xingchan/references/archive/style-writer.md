# 类文风撰稿 — 详细实现指南

> 模块定位：论文工厂的核心差异化模块
> 关联文件：`style-fingerprint.md`（文风指纹库）、`ai-vocabulary-filter.md`（五层清稿管线）
> 调用场景：论文模式阶段二、评论模式阶段三（评论态文案）

---

## 一、设计哲学

### 1.1 为什么"类文风"不是"模仿文风"

"类文风"的意思是：**戴着殿主的语言镣铐跳舞**——不是简单复刻已发表论文的句式，而是在保持论证逻辑严谨性的前提下，让新论文的语言指纹与殿主5篇已发表论文形成一致的学术人格。

三个核心原则：
1. **论证结构优先于文学性**——长句是为了论证的层层推进，不是为了炫技
2. **特征注入而非机械复制**——七个特征是"应该努力的方向"，不是"每句都要检查的清单"
3. **底线约束高于上限追求**——禁用词表中的词绝对不能出现，这比"一定要用判断句开段"更强制

### 1.2 与其他Skill的关系

```
类文风撰稿 ≠ 替代 academic-paper
类文风撰稿 = 给 academic-paper 穿上殿主的语言外衣

执行流程：
academic-paper（生成论证框架和内容）
    ↓
类文风撰稿模块（注入文风指纹 + 过滤AI味）
    ↓
最终输出
```

## 二、七大特征的操作化指南

### 特征1：长句嵌入式从句链

**核心要求**：主句嵌入1-2层限定性从句，再嵌入1-2层解释性从句。

**操作步骤**：
1. 确定主句的核心判断（"XX是什么/不是什么"）
2. 添加第一层从句（限定条件/原因/程度——"因为在YY条件下……"）
3. 添加第二层从句（进一步解释/展开——"而YY条件又取决于ZZ因素……"）
4. 检查：整句是否形成了一个不可拆分的完整论证单元？

**检验标准**：如果把这个句子拆成3个短句，中间的连接关系是否依然清晰？如果拆开后逻辑变弱，说明这个从句链是必要的。

**过度使用警告**：
- 如果一句话超过80字且没有自然的断句点 → 拆成两句
- 如果从句嵌套超过4层 → 简化

### 特征2：判断句开段

**核心要求**：段落首句不使用任何引导语，直接以判断句亮出核心观点。

**开段句式库**：

| 类型 | 句式模板 |
|------|---------|
| 本质界定型 | "XX的本质在于……" |
| 否定重设型 | "YY并非……，而是……" |
| 根因追溯型 | "ZZ的问题，根源于……" |
| 转向揭示型 | "从XX到YY的转变，折射出……" |
| 悖论呈现型 | "XX与YY之间的张力，构成了……" |
| 机制揭示型 | "AA之所以呈现为BB，关键在于CC机制……" |

**禁止的开段句式**：
- "本文认为……" → 直接说"XX是……"
- "通过XX可以看出……" → 直接说结果
- "笔者以为……" → 完全删除这个结构

### 特征3：设问自答嵌入

**核心要求**：在段落中部（不是开头也不是结尾）自然嵌入自问自答，作为从"现象描述"到"机制分析"的过渡。

**触发时机**：
- 当前面已经描述了1-2个现象，读者自然会产生"为什么会这样"的疑问时
- 当论证需要一个转折（从"是什么"转向"为什么"）时
- 当需要引入一个反直觉的判断时

**句式模板**：
- "何以如此？原因在于……"
- "问题在于，[设问]？[自答]。"
- "这不禁令人追问：[设问]？答案是[自答]。"
- "那么，[设问]？事实上，[自答]。"
- "[设问]？归根结底，[自答]。"

**使用频率建议**：
- 每500-800字1次
- 同一章节不超过3次
- 不要连续两个段落使用设问自答

### 特征4：段落三段式

**核心要求**：每个核心段落 → 判断（1-2句）→ 机制展开（3-5句）→ 边界过渡（1-2句）。

**每步的具体功能**：

| 步骤 | 功能 | 字数占比 | 禁止事项 |
|------|------|---------|---------|
| 判断 | 亮出核心观点 | 15-20% | 不能以"本文""笔者"开头 |
| 机制展开 | 因果关系/条件分析/证据支撑 | 55-65% | 不能只是一个例子（要有机制解释） |
| 边界过渡 | 限定条件/例外说明/引出下段 | 15-25% | 不能是"综上所述"式的总结 |

**第三步"边界过渡"的句式模板**：
- "当然，这一判断的前提是……"
- "不过，上述分析主要针对……，对于……是否成立，有待进一步检验。"
- "这并不意味着……。恰恰相反，……"
- "需要指出的是，XX的适用存在明确的边界：……"

### 特征5：段落递进链

**核心要求**：3个以上连续段落 → "结构→机制→趋势"的递进。

**递进模式**：

```
段落1：描述现象的结构特征（"长什么样"）
  → 主题句："XX呈现为一种典型的三层结构……"
段落2：分析现象的生成机制（"为什么长这样"）
  → 主题句："这一结构的形成，根源于YY与ZZ的双重驱动……"
段落3：预判机制的演化趋势（"会变成什么样"）
  → 主题句："随着AA条件的变化，BB结构正在向CC方向演化……"
```

**禁止的并列模式**：
```
❌ 段落1："第一个特征是……"
   段落2："第二个特征是……"
   段落3："第三个特征是……"
   （这是并列罗列，不是递进论证）
```

### 特征6：数据三步法

**核心要求**：引用数据时 → 判断句（先行给出论点）→ 数据锚定（具体数字）→ 意义升维（回扣理论/政策）。

**操作步骤**：

1. **判断句先行**："XX领域正在经历显著的结构性转变。"
2. **数据锚定**："据XXXX统计，202X年A类内容占比从XX%上升至YY%，增幅超过ZZ个百分点。"
3. **意义升维**："这一数据变化的意义，不仅在于数量增长本身，更在于它标志着[理论概念/政策方向]的实质性转变。"

**禁止的先数据后归纳模式**：
```
❌ "数据显示A增长了X%。这表明……"
✅ "A领域正在经历深刻变革。数据显示……。这一变革的意义在于……"
```

### 特征7：辩证张力贯穿

**核心要求**：全文多处使用转折词，避免非此即彼的简单结论。

**转折类型与用途**：

| 转折词 | 用法场景 | 使用频率 |
|--------|---------|---------|
| "但是"/"然而" | 直接转折——揭示矛盾/悖论/反直觉判断 | 约60%的转折 |
| "当然"/"不过" | 补充性转折——承认限定条件/例外 | 约25%的转折 |
| "另一方面"/"同时" | 并列性转折——展示多重因果/多维视角 | 约15%的转折 |

**使用密度**：每300-500字至少1次转折。

## 三、分章节的差异化撰稿策略

### 3.1 引言（最后写）

引言是最需要"类文风"的部分——它是审稿人对论文语言的"第一印象"。

**策略**：
- 特征2（判断句开段）最严格应用——引言每一段的首句必须是判断句
- 特征7（辩证张力）重点应用——引言需要在"已有研究不足"和"本文的创新贡献"之间建立张力
- 特征1（长句链）适度控制——引言需要可读性，句长可略短于正文

### 3.2 文献综述

**策略**：
- 特征4（段落三段式）最严格应用——每一类文献的综述 = 判断（这类文献的共性/趋势）→ 机制展开（代表性成果+优缺点）→ 边界过渡（这类文献的共同盲点）
- 特征7（辩证张力）用于建立"已有研究做了什么"和"已有研究没做什么"之间的张力
- 特征3（设问自答）可用于从"综述"转向"本文定位"的过渡

### 3.3 理论框架

**策略**：
- 特征2（判断句开段）最密集使用——理论框架本质上是"一系列判断的集合"
- 特征1（长句链）适度使用——理论概念的层层嵌套适合长句
- 特征3（设问自答）可用于"为什么选择这个理论而不是那个"的论证

### 3.4 核心章节（案例分析/实证分析）

**策略**：
- 特征6（数据三步法）强制应用——所有数据/案例引述必须判断先行
- 特征5（段落递进链）强制应用——连续段落按"现象→机制→意义"递进
- 特征4（段落三段式）用于每个案例/维度的分析

### 3.5 结论

**策略**：
- 特征7（辩证张力）重点应用——结论不能是"全对"，要有"限定条件"和"未来追问"
- 特征2（判断句开段）——结论的每段首句是对应引言段的回应
- 特征4（段落三段式）——判断（核心发现）→ 解释（为什么重要）→ 边界（不适用于什么情况）

## 四、五层清稿管线的优先级

类文风撰稿过程中，五层清稿管线的去味优先级高于文风注入：

| 层级 | 规则类别 | 说明 |
|------|---------|------|
| L1 | Quick Checks（删冗余副词/元评论句/宣布动作/控破折号/删机械连接词） | 最快见效，撰稿后首先执行 |
| L2 | 短语黑名单（中英文禁用词/套话） | 绝对不能出现，必须替换 |
| L3 | 结构反模式（Binary Contrast/Tripling/Punch Line/Rhetorical Setup） | 句式模板检测，必须重构 |
| L4 | 虚假施动者（"数据表明"→"XX数据的分析发现"） | 检查无来源断言 |
| L5 | 五维评分（直接性/节奏/可信度/真实感/信息密度≥35/50） | 量化质量门槛 |

## 五、质量自检清单（每章写完执行）

- [ ] 该章每段首句是否为判断句？（特征2）如果不是，标注并修改
- [ ] 核心段落是否符合三段式？（特征4）检查第一段的第3步是否存在
- [ ] 连续段落是否形成递进链？（特征5）检查是否有超过3段的并列罗列
- [ ] 是否有设问自答？（特征3）每500-800字至少1次
- [ ] 是否有辩证转折？（特征7）每300-500字至少1次
- [ ] 是否出现了任何禁用词？（五层清稿管线L2短语黑名单）全文搜索
- [ ] 是否有超过3个点的并列罗列？（五层清稿管线L3结构反模式）
- [ ] 数据/案例引用是否为"判断→锚定→升维"？（特征6，如适用）
