# 创作档·小说子类工作流（调度 chinese-novelist-dragon）

> **档位定位**：创作档·小说子类 = 面对“文学/网文读者”这一话语共同体时，以叙事性、人物弧光、节奏爽感为质量基准的表达方式。作者身份默认 = 创作者 / 网文作者（网文创作者）。
> **一句话**：小说写的是“让人在另一个时空里活一遍”——不是把观点讲清楚，是把人带进去。
> **母版关系**：学术档是母版，小说关闭“论证/证据”权重、开启“叙事/人物/节奏”权重，骨架（S/C1-C6）不变；但 C1-C5 的专业执行由 chinese-novelist-dragon 接管。
> **加载时机**：O2 锚定卡档位 = 创作档·小说子类时，S/C1-C6 每道工序按“星躔调度 + dragon 执行”模式运行。
> **学术锚点**：叙事学“展示而非告知”+ 网文“黄金三章 / 章尾钩子 / 屏级爽点”原理 + 人物弧光理论。

- 若 dragon 不可用（降级），星躔按母版迁移表“小说子类”五要素（人物·情节账本/三幕剧/叙事驱动/节奏人物伏笔三角/叙事结构+人物弧光）降级执行，提示用户专业度下降。

## S 论证锚定复核（小说子类）

复核四要点（星躔主导，对齐 O2）：
1. **故事类型**：修仙/现实/悬疑/科幻/爽文？（决定 dragon 题材匹配与雕龙 Skill 激活）
2. **发布平台**：番茄小说（爽感为王）/ 实体出版（文学性优先）/ 自媒体连载？（决定篇幅与节奏）
3. **目标读者**：下沉网文男频 / 女频 / 文学读者？（决定情感目标与语言门槛）
4. **系列规划**：单本 / 系列？预估篇幅？（决定三幕剧 vs 多卷结构）

**档位特有复核项（S1 段）**：四要点确认 → 进入 C1（dragon Phase 0/1 偏好加载完毕）。

## C1 选题（题材/故事核 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节。创作档·小说子类.md 转义：
> 态势分析 → **题材冷热（可选）**；选题推荐 → **题材/故事核候选**；定题评测三维 → **意象新颖性/情感真实性/形式可行性**；标题打磨 → **题眼打磨**。

1. 从 P0 论证锚定卡提取选题关键词
2. 按四环节收敛候选 → 定题评测三维均过 → 定稿选题
3. 输出选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）

**守门③（选题定稿）**：三维均过 → 放行 C2。

## C2 材料建档（人物·情节账本）

> 与学术档“证据账本”同构但内容不同：小说的“证据”是**人物、动机、情节钩子、世界观设定**。

| 编号 | 素材 | 类型 | 用途 |
|---|---|---|---|
| F01 | 主角核心人设：职业身份 × 世界观反差（示例） | 人物 | 核心人设锚点 |
| F02 | 金手指设定：日常能力在异世界错位（示例） | 设定 | 爽点来源 |
| F03 | 第一卷核心冲突：凡人学生 vs 仙门规矩 | 情节 | 三幕剧第一幕 |

**守门⑤**：核心人物有动机、核心冲突已建档、服务于创作意图 → 放行（不强制覆盖率，见母版迁移表 3.2）。

## C3 结构设计（三幕剧 / 黄金三章）

- 第一幕（建置）：主角处境 + 触发事件 + 目标确立（黄金三章须抓人）
- 第二幕（对抗）：主冲突升级 + 支线展开 + 伪失败
- 第三幕（解决）：高潮对决 + 价值兑现 + 余韵（系列则留钩子）

**结构检查**：黄金三章是否“开篇即异常”；每章章尾是否有钩子；伏笔是否埋设可回收。

**守门⑥**：三幕完整 + 黄金三章抓人 → 放行。

---

## C4 逐段写作（叙事驱动 · 屏级爽点 · 章尾钩子）

**撰写顺序**：按卷→章→屏（手机阅读单元）推进，不跳章。
**核心机制**：
- 每屏一个情绪点（爽/疑/虐/燃）
- 每章章尾钩子（悬念/反转/新危机）
- 三大禁令写作（dragon 规则）：不水、不尬、不崩人设
- 自然嵌入专业知识（L1 词汇自然、L2 合适场景展开）

**守门⑦**：章尾有钩子 + 人设不崩 + 节奏达标 + 去AI味L1通过 → 放行。

## C5 对抗评审（节奏 / 人物一致性 / 伏笔回收 三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 节奏评审 | 爽点密度？拖沓？章尾钩子力度？ | 节奏问题清单 |
| 人物评审 | 人设一致？动机合理？弧光清晰？ | 人物问题清单 |
| 伏笔评审 | 伏笔埋设？回收？逻辑闭合？ | 伏笔问题清单 |

**C5b 回退**：节奏/人物 → C3；结构断裂 → C2；类型/读者定错 → O2。

**守门⑧**：三角色通过（dragon Phase 4 终检通过）→ 放行至打磨。

---

## C6 打磨交付（发布就绪）

1. 平台格式适配（番茄=分章短屏；出版=章节整合）
2. 封面建议（dragon Phase 9 + oh-story-cover 增强）
3. 生成发布就绪包：标题备选(2-3) + 简介（神秘不剧透）+ 标签 + 转发语
4. DOCX / 推送文件生成调用 `docx` Skill

**守门⑧**：格式就绪 + 简介不剧透 + 〔待核〕全替换 → 终稿交付 → 进入 E 层。
