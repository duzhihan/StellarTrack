# 创作档·散文子类工作流（叙事 / 抒情 / 随笔）

> **档位定位**：创作档·散文子类 = 面对“文学审美 / 生活感悟”这一话语共同体时，以意境、语言、真情为质量基准的表达方式。作者身份默认 = 散文作者 / 创作者。
> **一句话**：散文写的是“形散神聚”——笔可以散，心不能散；看似随手写，实则句句归一处。
> **母版关系**：学术档是母版，散文关闭“论证/证据”权重、开启“意境·语言·真情”权重，骨架（S/C1-C11）不变；C3 由“分析驱动”切“情感驱动，随笔式”。
> **加载时机**：O2 锚定卡档位 = 创作档·散文子类时，S/C1-C11 中 C1–C6 段的档位转义按本文件执行，C7–C11 走骨架默认。
> **学术锚点**：中国散文“形散神聚”传统（唐宋八大家以降）+ 汪曾祺“语言的音乐性”+ 抒情散文的情感真实性原则。

---

## S 论证锚定复核（散文子类）

复核四要点：
1. **题材**：叙事散文（记人记事）/ 抒情散文（寄情于景）/ 随笔（议论杂感）？（决定 C2 结构）
2. **篇幅**：千字短文 / 三千字长文？（决定展开度）
3. **视角**：第一人称“我”/ 旁观视角？（决定亲切感与叙述距离）
4. **情感基调**：怀念 / 欢喜 / 怅惘 / 释然？（决定意象取向）

**档位特有复核项（S1 段）**：题材 + 情感基调确认 → 进入 C1。

---

## C1 选题（题材/情感 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节；执行顺序 **①态势 → ②推荐 → ⑤选题确认（人机对话）→ ③评测 → ④打磨**，⑤未拍板不进评测。创作档·散文子类转义：
> 态势分析 → **题材冷热（可选）**；选题推荐 → **题材/情感候选**；定题评测三维 → **意象新颖性/情感真实性/篇幅可行性**；标题打磨 → **题眼打磨**。

产出：选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）。

**守门③（选题定稿）**：⑤选题确认已由用户拍板 + 三维均过 → 放行 C2。

---

## C2 材料建档（意象 · 情感账本）

> 与学术档“证据账本”同构但内容不同：散文的“证据”是**意象、细节、情感点**。

| 编号 | 意象/细节 | 情感/意味 | 来源 |
|---|---|---|---|
| Y01 | 老屋的樟木箱 | 岁月·记忆 | 童年记忆 |
| Y02 | 母亲补了又补的围裙 | 操劳·慈爱 | 生活观察 |
| Y03 | 阳台上半枯的茉莉 | 时光流逝·惜别 | 自设情境 |

**细节原则**：散文靠细节立起来——一个准确的细节胜过十句抒情（“母亲把围裙解下来，又系上去”比“母亲很操劳”有力）。

**守门⑤**：核心意象已建档且服务情感主线（母版迁移表 3.2，不强制覆盖率）→ 放行。

---

## C3 结构设计（形散神聚：主线 + 发散）

### 标准结构

```
开头（入境）：一个场景/细节切入，定情感基调（不写“今天我要写…… ”）
主体（发散）：围绕主线展开 3-5 个细节/片段，笔随意走但句句归主线
结尾（收束）：回到开头意象，情感落地/升华（有余味，不点破）
```

**主线检查**：所有片段是否都指向同一情感核心？有无“散出去收不回”的段落？

**守门⑥**：主线清晰 + 开头有细节 + 结尾有余味 → 放行。

---

## C4 逐段写作（情感驱动 · 随笔式）

> **撰写顺序**：先写**开头场景**（定基调）→ 主体片段（最动情的先写，其余按情感流排布）→ 结尾收束。

**话术底线（写入时即带着）**：
- **细节优先**：写具体的物、事、话，不写抽象感慨（“阳光透过窗棂”而非“时光美好”）
- **情感克制**：情感藏在叙述里，不直白喊出来——让读者自己感到，不替他感到
- **语言节奏**：长短句交错，长句抒情、短句定格；避免四字成语堆砌
- **真话原则**：不造作、不拔高——散文本色是“家常话讲真感情”
- **禁用 AI 腔**：禁用“在这个喧嚣的时代/岁月静好/不禁让人感叹”等套话；不写“这篇散文表达了”

**每节强制操作**：回顾该节在主线的位置 → 按话术底线写 → 检查细节密度 → 更新写作状态摘要。

**守门⑦**：细节到位 + 情感不直白 + 无套话 → 放行。

---

## C5 对抗评审（意境 / 语言 / 真情 三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 意境评审 | 整体氛围是否成立？结尾有无余味？ | 意境问题清单 |
| 语言评审 | 细节是否准确？节奏是否自然？有无套话/成语堆砌？ | 语言问题清单 |
| 真情评审 | 情感是否真实克制？是否拔高造作？ | 真情问题清单 |

**C5b 回退**：语言/细节问题 → C3；结构散乱 → C2；题材定错 → O2。

**守门⑧**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（文体校验）

1. **语言节奏终校**：回读全篇，删冗余形容词，改拗口长句
2. **情感脉络检查**：情感推进是否自然（从境入情、由情入理）？
3. **排版**：散文 = 自然段 + 适当空行，可配题记/小标题（长文）
4. 生成发布就绪包：标题（可给 2-3 候选）+ 正文 + 创作小记（可选）

**守门⑧**：语言干净 + 情感脉络完整 → 终稿交付 → 进入 E 层。
