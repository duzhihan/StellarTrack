# 文风指纹库

> 基于殿主（杜智瀚老师）5篇已发表论文的语言特征提取
> 用途：论文模式、评论模式、申报模式、研究报告模式的类文风撰稿阶段自动注入
> 配合：`ai-vocabulary-filter.md`（五层清稿管线，通用AI深度去味）+ 本文档（个人风格注入）

---

## 一、七大文风特征

### 特征1：长句嵌入式从句链

**描述**：殿主的句式以长句为主，采用"俄罗斯套娃"式从句嵌套——主句嵌入限定性从句，限定性从句再嵌入解释性从句，形成层层推进的论证链。

**量化参数**：
- 平均句长：40-70字（中文学术论文标准句长为25-40字，殿主明显偏长）
- 从句嵌套深度：2-4层
- 典型句式：主句+（因为……，（而……，（这又……）））

**示例模式**：
```
[现象A]之所以呈现为[特征B]，[并非][简单解释C]，
而是[深层原因D]——[原因D]的形成，[又]与[背景因素E]密切相关，
[E]在[条件F]下，[经由][机制G]，最终[导致][结果H]。
```

### 特征2：判断句开段

**描述**：段落首句不使用"本文认为""笔者以为"等引导语，而是直接以判断句亮出核心观点。判断句通常是"XX是YY"或"XX并非YY，而是ZZ"的结构。

**量化参数**：
- 判断句开段比例：≥80%的段落首句为判断句
- 禁用开段句式："本文""笔者""我们""通过XX可以看出"

**典型开段句式**：
- "XX的本质在于……"
- "YY并非……，而是……"
- "ZZ的问题，根源于……"
- "从XX到YY的转变，折射出……"

### 特征3：设问自答嵌入

**描述**：在段落中间嵌入自问自答，不打断论证流，而是作为逻辑转折的过渡。

**量化参数**：
- 设问自答频率：约每500-800字出现1次
- 典型位置：段落中部，作为从"现象描述"过渡到"机制分析"的连接

**典型句式**：
- "何以如此？原因在于……"
- "问题在于，[设问]？[自答]。"
- "这不禁令人追问：[设问]？答案是[自答]。"
- "那么，[设问]？事实上，[自答]。"

### 特征4：段落三段式

**描述**：每个核心段落遵循"判断→机制展开→边界过渡"的三段结构。

**结构模板**：
```
第1步：判断句（核心观点，通常1-2句）
    ↓
第2步：机制展开（因果关系/条件分析/证据支撑，通常3-5句）
    ↓
第3步：边界过渡（限定条件/例外说明/引出下一段，通常1-2句）
```

**量化参数**：
- 三段式段落比例：≥70%的核心段落符合此结构
- 三步字数分配：第1步占15-20%，第2步占55-65%，第3步占15-25%

### 特征5：段落递进链

**描述**：连续段落之间形成"结构→机制→趋势"的递进关系，而非并列罗列。

**递进模式**：
```
段落1：描述现象的结构特征（"长什么样"）
    ↓
段落2：分析现象的生成机制（"为什么这样"）
    ↓
段落3：预判机制演化的趋势（"会变成什么样"）
```

**量化参数**：
- 递进链段落比例：≥60%的连续段落形成可辨识的递进关系
- 禁用模式：连续3个以上段落以同一句式开头的并列结构

### 特征6：数据三步法

**描述**：引述数据/案例时，遵循"判断句→数据锚定→意义升维"的三步结构。

**结构模板**：
```
第1步：判断句（先行给出论点，不是先给数据再推导）
    ↓
第2步：数据锚定（用具体数据/案例事实支撑判断）
    ↓
第3步：意义升维（将数据回扣到理论/政策/趋势层面）
```

**量化参数**：
- 数据引用段落三步法比例：≥80%
- 禁止模式：先给数据再推导的"归纳式"写法

### 特征7：辩证张力贯穿

**描述**：全文多处使用"但是/然而/不过/当然/另一方面"等转折词，避免非此即彼的简单结论，始终维持论证的辩证张力。

**量化参数**：
- 转折词密度：约每300-500字出现1次转折
- 转折类型分布：
  - "但是/然而"（直接转折）：约60%
  - "当然/不过"（补充性转折）：约25%
  - "另一方面/同时"（并列性转折）：约15%

## 二、禁用清单（论文模式强制）

> ⚠️ 维护须知：本清单与 `ai-vocabulary-filter.md` 有内容重叠。修改禁用词时，请同步检查两个文件的一致性。本清单侧重"文风层面的禁止规则"（如禁用"本文""笔者"），`ai-vocabulary-filter.md` 侧重"语言层面的过滤规则"（如禁用英文AI味词汇）。

### 2.1 绝对禁用
- "本文"/"本研究"/"笔者"/"我们"（以判断句开段替代）
- "综上所述"/"总而言之"/"总之"
- "有待进一步研究"（必须具体化为可操作的未来研究方向）
- "首次"/"开创性"/"填补空白"（无法验证的宣称）

### 2.2 避免使用
- 简单并列罗列超过3个点
- "一方面……另一方面……"（过度使用时）
- "值得注意的是"（无实质信息量的引导语）
- "在一定程度上"（模糊限定词，应替换为精确的限定条件）

## 三、不同模式的文风注入策略

### 论文模式（最高文风要求）
- 七大特征全部启用
- 禁用清单全部适用
- 段落三段式严格检查
- 数据三步法强制应用（如有数据）

### 课题申报模式
- 特征2（判断句开段）、特征4（段落三段式）、特征7（辩证张力）启用
- 禁用清单中"本文""笔者"绝对禁用
- 特征1（长句链）适度控制（申报材料的可读性优先于文学性）

### 评论模式
- 特征2（判断句开段）、特征3（设问自答）、特征7（辩证张力）启用
- 特征1（长句链）放宽（评论需要更短促有力的节奏）
- 禁用清单中的"综上所述"绝对禁用

### 研究报告模式
- 特征2（判断句开段）、特征4（段落三段式）、特征7（辩证张力）启用
- 特征1（长句链）不启用——研究报告面向管理者，需要更高的可读性和直接性
- 特征3（设问自答）不启用——报告不是学术对话，不需要设问式过渡
- 特征5（段落递进链）和特征6（数据三步法）不强制——报告结构由模板固定
- 禁用清单中的"本文""笔者""我们"绝对禁用
- 语言风格：比学术论文更精炼务实，每句都应有可查证的实质信息

| 规则来源 | 性质 | 适用范围 |

| `ai-vocabulary-filter.md` | 通用负面规则（"不能用什么"） | 所有模式 |
