# 传播档工作流（公众号 / 大众媒体推文）

> **档位定位**：传播档 = 面对“大众读者 / 学院师生 / 社会受众”这一话语共同体时，以可读、感染力、信息密度为质量基准的表达方式。作者身份默认 = 内容创作者 / 学院宣传员。
> **一句话**：传播档写的是“让人愿意读、读得懂、愿意转”——不是把公文翻译一遍，是按读者认知节奏重新组织。
> **母版关系**：学术档是母版，传播档关闭“论证创新”权重、开启“可读·感染力”权重，骨架（S/C1-C6）不变，C3 可调用雕龙叙事 skill。
> **加载时机**：O2 锚定卡档位 = 传播档时，S/C1-C6 每道工序按本文件执行。
> **学术锚点**：传播叙事的根本逻辑 = “钩子吸引 → 场景代入 → 价值呈现 → 共鸣收束”（对应叙事学“展示而非告知”+ 雕龙叙事“黄金三章 / 章尾钩子”原理）。

---

## S 论证锚定复核（传播档）

复核四要点：
1. **传播目标**：告知动态？塑造形象？招募参与？凝聚认同？（目标决定 C2 结构重心）
2. **读者画像**：本院师生？同行院校？社会公众？决定语气与知识门槛
3. **渠道特性**：公众号（长文+排版）/ 短视频文案（口播脚本）/ 朋友圈（短文案）——决定 C4 节奏与 C6 版式
4. **转发诱饵**：读者凭什么转发？金句？实用？情绪价值？（传播档的灵魂）

**档位特有复核项（S1 段）**：目标与读者确认 → 进入 C1。

---

## C1 选题（话题切入 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节。传播档转义：
> 态势分析 → **热点趋势（大众议题）**；选题推荐 → **话题切入候选**；定题评测三维 → **传播性/差异化/可执行**；标题打磨 → **钩子标题**。

1. 从 P0 论证锚定卡提取选题关键词
2. 按四环节收敛候选 → 定题评测三维均过 → 定稿选题
3. 输出选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）

**守门③（选题定稿）**：三维均过 → 放行 C2。

---

## C2 材料建档（素材账本）

> 与学术档“证据账本”同构，但素材类型不同：传播档的素材是**故事 / 案例 / 数据 / 金句 / 图片**。

| 编号 | 素材 | 类型 | 用途 |
|---|---|---|---|
| S01 | 学生从迷茫到拿奖的真实转变 | 故事 | 代入感 |
| S02 | 活动参与人数同比 +35% | 数据 | 说服力 |
| S03 | “在艺术设计学院，每个学生都是创作者” | 金句 | 转发点 |
| S04 | 现场照片 / 作品图 | 图片 | 视觉节奏 |

**素材缺口处理**：故事不足 → 提示用户补充真实案例（不虚构）；数据缺失 → 标注〔待核〕占位，发布前必须替换。

**守门④**：核心叙事有真实故事 / 数据支撑，无凭空编造 → 放行。

## C3 结构设计（传播档骨架）

### 标准五段（公众号长文）

```
标题：钩子型（数字 / 冲突 / 悬念 / 身份代入），不写公文标题
一、钩子开场（1-2 段）：场景 / 冲突 / 反常识，让读者“对，说的就是我”
二、主体展开（2-4 段）：用故事 / 案例 / 数据呈现核心内容，避免一上来就讲道理
三、价值升华（1-2 段）：这件事的意义、对读者的价值
四、行动召唤（1 段）：关注 / 参与 / 转发，给明确指令
五、金句收尾（1 句）：可截图转发的记忆点
```

### 调用雕龙叙事

C3 可调用**雕龙叙事 skill** 提供专业骨架（黄金三章节奏、章尾钩子、爽点编排）——星躔管 O-S-C-E 流程，雕龙管叙事专业度，两者“框架 vs 插件”不冲突。

> **雕龙激活时机（N5）**：① 长推文（≥300 字、需叙事节奏）在 C3 确定骨架后、C4 写作前调用，由雕龙提供章法建议；② 短动态（<300 字）、纯通知、纯数据播报，不调用，直接按标准五段写；③ 若已加载“雕龙叙事”skill 则自动接管 C3-C4 叙事层，星躔退居流程守门。

**结构检查**：开场是否“展示而非告知”（不用“我院近日举办了……”这种汇报体开头）；每段是否有“钩子-展开-落点”微结构。

**守门⑤**：开场有钩子 + 主体有故事 + 结尾有金句 → 放行。

## C4 逐段写作（传播档话术底线）

> 撰写顺序：先写**钩子开场**（决定全篇节奏），再写**主体**，最后写**金句收尾**（写完后提炼）。

**话术底线（写入时即带着）**：

- **口语化**：用“你 / 我们”拉近距离，不用“该院 / 此活动”等公文称谓；短句为主，一句一意
- **展示而非告知**：写“凌晨两点的画室还亮着灯”，不写“学生勤奋刻苦”；写场景、写细节、写人
- **短段视觉节奏**：手机阅读，每段 ≤4 行，多用空行；金句单独成段
- **情绪曲线**：开篇代入（共鸣）→ 中段张力（冲突/反转）→ 结尾升华（认同），不要平铺直叙
- **可转发设计**：埋 1-2 个“可截图”金句；结尾给明确转发理由（“转给同样在追梦的人”）
- **禁用 AI 腔**：禁用“综上所述 / 值得一提的是 / 在这个快节奏的时代 / 不仅仅是……更是”等模型套话；不写“本文 / 本推文”
- **数据不堆砌**：一个核心数字足够，不列清单；数字要“有人味”（“35% 的增长，背后是 200 个加班的夜晚”）

**每节强制操作**：回顾该节在叙事链的功能（钩子/展开/升华/召唤）→ 按话术底线撰写 → 写过渡句（承上启下）→ 更新写作状态摘要。

**守门⑥**：开场有钩子 + 无公文汇报体 + 金句可转发 + AI 味禁用词 ≤3次/千字 → 放行。

## C5 对抗评审（传播档三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 可读性评审 | 开头 3 秒能否留住人？句子是否过长？术语是否过多？ | 可读问题清单 |
| 感染力评审 | 有无情绪曲线？金句是否够转？场景是否鲜活？ | 感染力清单 |
| 传播性评审 | 转发诱饵是否明确？标题是否想点开？有无违规风险？ | 传播问题清单 |

**C5b 回退**：可读/感染力问题 → C4；传播风险 → 回退 O2（目标/渠道可能定错）；结构问题 → C3。

**守门⑦**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（传播档）

1. **排版适配**：公众号 = 短段 + 小标题 + 加粗关键句 + 配图位（〔图1〕占位）；短视频文案 = 口播分镜脚本
2. **标题候选**：给 2-3 个标题（数字型 / 悬念型 / 身份代入型），供用户选。
   - **钩子策略（N6）**：① 数字型——“35% 增长背后，是 200 个加班的夜晚”；② 悬念型——“这场比赛，你敢来吗”；③ 身份代入型——“那个半夜画图的女孩”；④ 冲突型——“我们劝退了他，三个月后他拿了奖”。
   - **避坑**：不标题党、不夸大（“震惊”“史上最”禁用）；钩子必须正文有对应支撑，不得文不对题。
3. **标签与封面**：建议 3-5 个标签（如 #党建引领 #艺术教育 #学生成长）；封面建议（是否有现成图）
4. **生成发布就绪包**：标题备选 + 正文(渠道格式) + 封面建议 + 标签 + 转发语 + 发布前必核清单（〔待核〕占位未替换不得发布）
5. DOCX / 推送文件生成调用 `docx` Skill

**守门⑧**：标题有吸引力 + 排版就绪 + 〔待核〕全替换 → 终稿交付 → 进入 E 层。

## 附：传播档高频场景速查

| 场景 | 标题风格 | 结构重心 | 转发诱饵 |
|---|---|---|---|
| 学院动态 | 数字/成果型（“35% 增长背后”） | 成果展示 + 故事 | 荣誉感 |
| 活动宣传 | 悬念/参与型（“这场比赛，你敢来吗”） | 亮点 + 报名方式 | 好奇/参与 |
| 人物故事 | 身份代入型（“那个半夜画图的女孩”） | 人物弧光 | 共鸣 |
| 政策解读 | 实用型（“一图读懂 XX 政策”） | 要点 + 图解 | 收藏价值 |
| 节日/节点 | 情绪型（“教师节，想对您说”） | 情感共鸣 | 情绪价值 |
