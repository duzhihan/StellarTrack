# 规范档工作流（党建材料 / 公文）

> **档位定位**：规范档 = 面对“党政机关 / 高校基层组织”这一话语共同体时，按组织规范、官方用语、合规标准写作的表达方式。作者身份默认 = 公文写作者 / 组织宣传人员。
> **一句话**：规范档写的是“组织要你说的话、按组织要的格式说”——不抒情、不独创、不夸大，准确合规是底线。
> **母版关系**：学术档是母版，规范档关闭“论证创新”权重、开启“合规规范”权重，骨架（S/C1-C11）不变。
> **加载时机**：O2 锚定卡档位 = 规范档时，S/C1-C11 中 C1–C6 段的档位转义按本文件执行，C7–C11 走骨架默认。
> **学术锚点**：公文写作的根本逻辑 = “如实记录 + 规范表达 + 合规存档”（对应《党政机关公文处理工作条例》15 种文种 + 高校基层党建材料惯例）。

---

## S 论证锚定复核（规范档）

复核四要点：
1. **发文权限**：这份材料你有没有资格写？是以党总支名义、党支部名义、还是个人辅导员身份？（发文身份敏感度）
2. **文体匹配**：总结 / 报告 / 方案 / 通知 / 纪要 / 请示，文体决定了 C2 结构
3. **报送对象**：上级党委？同级公示？存档备查？对象决定语气与详略（N2 报送语气：报上级党委用“请示/报告”上行文体，谦恭据实、有明确请求或结论；同级公示用陈述体，平实公开；存档备查用纪实体，客观完整——语气随对象调整，但合规底线不变）
4. **时间节点**：是否限时报送？决定流程深度（≤3天轻量 / 1周标准 / ≥1月全深度）

**档位特有复核项（S1 段）**：权限与文体确认 → 进入 C1。

## C1 选题（事项+文种 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节；执行顺序 **①态势 → ②推荐 → ⑤选题确认（人机对话）→ ③评测 → ④打磨**，⑤未拍板不进评测。规范档 转义：
> 态势分析 → **政策导向（上级精神/当期重点）**；选题推荐 → **事项候选**；定题评测三维 → **合规性/口径/必要性**；标题打磨 → **公文题（关于XX的文种）**。

产出：选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）。

**守门③（选题定稿）**：⑤选题确认已由用户拍板 + 三维均过 → 放行 C2。

## C2 材料建档（政策依据账本）

> 与学术档“证据账本”同构，但证据类型不同：规范档的证据是**政策文件、上级通知、工作台账、数据记录**。

| 编号 | 事实 / 判断 | 依据来源 | 类型 | 可信度 | 用途 |
|---|---|---|---|---|---|
| G01 | 本学期发展预备党员 X 名 | 党员信息系统台账 | 数据 | 高 | 工作成效 |
| G02 | 落实“第一议题”学习 N 次 | 支部会议记录 | 记录 | 高 | 政治建设 |
| G03 | 贯彻 XX 会议精神 | 上级党委文件（XX号） | 政策 | 高 | 依据 |

**材料缺口处理**：台账缺失 → 提示用户补录（不编造数据）；政策依据不清 → 检索上级文件或提示向党委办公室核实。

> **占位符约定（N1）**：正式稿中缺失数据一律标注〔待核〕，发布/报送前必须替换为真实数据；本文件模板示例中的 X / N / XX 仅为占位示范，实写时替换为真实数值，不得带〔 〕括号进终稿。

**守门⑤**：核心事实均有台账 / 文件支撑，无凭空数据 → 放行。

## C3 结构设计（规范档模板）

### 一、党建总结类（最常用，标准五段）

```
标题：关于 {年度/学期} {单位} {工作} 的总结报告
一、总体情况（背景 + 数据概览，1 段）
二、主要工作及成效（分点，按“政治建设 / 组织建设 / 思想建设 / 作风建设”或实际板块）
三、经验做法（亮点，2-3 条可推广的）
四、存在问题与不足（坦诚、具体、不避重就轻，但措辞有分寸）
五、下一步工作计划（对应问题，可量化）
```

### 二、工作简报 / 动态类（三段）

```
标题：{单位} 开展 {活动}（动宾短语，不写虚词）
一、活动基本情况（时间/地点/参加人员/内容）
二、活动成效与反响（现场反馈 / 数据）
三、下一步安排（如有）
```

### 三、方案 / 通知类（条款式）

```
标题：关于印发《{方案名}》的通知
一、目的依据
二、组织机构
三、工作内容及步骤
四、工作要求
附件：{具体表格/名单}
```

### 四、请示 / 报告类（上行文，单列）

```
标题：关于 {事项} 的请示（报告）
一、事由依据（为什么写：政策要求 / 上级部署 / 实际情况）
二、具体内容（做了什么 / 是什么情况，数据据实）
三、请求事项 / 结论（请示：恳请批准 XX；报告：特此报告，请审阅）
```

> 上行文语气（N3 请示模板展开）：谦恭据实、一事一请，不夹带议论、不打包多项请求；报告重“陈述事实 + 结论”，不写请示用语。

**结构检查**：五段总结须“问题与计划对应”（第四步的问题第五步有回应）；数据在“总体情况”与“主要工作”中一致，不前后矛盾。

**守门⑥**：结构完整 + 问题计划镜像对称 → 放行。

## C4 逐段写作（规范档话术底线）

> 撰写顺序（与学术档不同，规范档**按章节顺序写**，不跳章——读者是按顺序审议的）：

1. **一、总体情况**（先写，定调与数据基准）
2. **二、主要工作及成效**（核心篇幅，分板块展开）
3. **三、经验做法**（提炼，不重复第二点）
4. **四、存在问题**（如实写，分寸感）
5. **五、下一步计划**（对应问题）

**话术底线（写入时即带着）**：

- **政治正确用语**：“深入学习贯彻”“坚持……统领”“落实……要求”“在……指导下”——用规范表述，不口语化改写
- **数据准确**：人数 / 次数 / 比例与 C1 账本一致；“约 / 余 / 近”等模糊量词仅用于确无精确数的场合
- **不夸大不煽情**：成效用事实和数据说话，不用“空前 / 卓越 / 巨大”等虚词；问题不写成检讨书，也不轻描淡写
- **主谓清晰**：多用“支部”“党总支”“我们”明确主语，不用无主句
- **分寸感**：涉及上级评价用“得到……肯定”，涉及自身成绩用“基本完成 / 稳步提升”而非“圆满完成 / 全面领先”
- **禁用 AI 腔**：禁用“综上所述 / 总而言之 / 值得一提的是 / 由此可见”等模型套话；段落不以“本文 / 本报告”开头

**每节强制操作**：回顾该节功能 → 按话术底线撰写 → 写过渡句衔接下节（如“在抓好 XX 的同时，我们同步推进……”）→ 更新写作状态摘要。

**守门⑦**：政治表述无误 + 数据前后一致 + 五段齐全 + AI 味禁用词 ≤3次/千字 → 放行。

## C5 对抗评审（规范档三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 合规评审 | 政治表述是否规范？文种格式是否合规？有无敏感表述？ | 合规问题清单 |
| 规范评审 | 数据前后一致？分点逻辑清晰？有无夸大虚词？ | 规范问题清单 |
| 表达评审 | 去 AI 味？语句通顺？主谓清晰？ | 规范问题清单 |

**C5b 回退**：合规问题 → 回退 O2（可能文体/权限定错）或 C1（数据依据）；规范问题 → C3；表达问题 → C3 或 C5。

**守门⑧**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（规范档）

1. **格式合规**：红头文件（如适用）= 发文机关标识 + 发文字号 + 标题 + 主送机关 + 正文 + 落款（单位 + 日期）+ 印章；内部总结 = 标题 + 落款（党支部 / 党总支 + 日期）
2. **称谓统一**：全文“党支部 / 党总支 / 党委”层级不混用
3. **生成发布就绪包**：标题备选(2-3) + 正文(合规格式) + 报送清单（报哪个部门 / 抄送谁 / 是否公示）
4. DOCX 生成调用 `docx` Skill

**守门⑧**：格式全项合规 → 终稿交付 → 进入 E 层。

## 附：规范档高频文体速查

| 文体 | 标题格式 | 结构 | 落款 |
|---|---|---|---|
| 党建工作总结 | 关于 {期} {单位} {工作} 的总结报告 | 五段 | 党支部 + 日期 |
| 工作简报 | {单位} 开展 {活动} | 三段 | 视报送要求 |
| 实施方案 | 关于印发《{方案}》的通知 | 条款式 | 党总支 + 日期 + 章 |
| 组织生活会对照检查 | 个人对照检查材料 | 查摆问题-原因-整改 | 个人 + 日期 |

> **落款例外（N4）**：个人名义材料（对照检查、个人述职、心得体会）落款 = 个人姓名 + 日期，无单位红头、无印章；与组织名义材料（党支部/党总支落款 + 红头）严格区分，不得混用。
| 请示 / 报告 | 关于 {事项} 的请示（报告） | 事由-内容-请求 | 党支部 + 日期 |
