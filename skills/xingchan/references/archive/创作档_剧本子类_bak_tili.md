# 创作档·剧本子类工作流（话剧 / 短剧 / 微电影脚本）

> **档位定位**：创作档·剧本子类 = 面对“舞台 / 银幕”这一话语共同体时，以冲突、人物、可表演性为质量基准的表达方式。作者身份默认 = 编剧 / 创作者。
> **一句话**：剧本写的是“用对话和动作讲故事”——不写心理描写，写人物在冲突里怎么选、怎么做。
> **母版关系**：学术档是母版，剧本关闭“论证 / 证据”权重、开启“冲突 · 人物 · 可表演性”权重，骨架（S/C1-C6）不变；C3 由“分析驱动”切“对话驱动，场景化”。
> **加载时机**：O2 锚定卡档位 = 创作档·剧本子类时，S/C1-C6 每道工序按本文件执行。
> **学术锚点**：亚里士多德《诗学》“情节首位”+ 戏剧性反讽 + 三幕剧结构（起 / 承 / 转 / 合 / 突转 / 发现）。

---

## S 论证锚定复核（剧本子类）

复核四要点：
1. **剧种**：话剧 / 短剧 / 微电影脚本 / 情景剧？（决定 C2 场次密度与 C5 格式）
2. **核心冲突**：什么人与什么之间的张力？（如“理想与现实”“两代人的观念”）
3. **时长 / 场景数**：5 分钟单场 / 30 分钟多场？（决定 C2 结构）
4. **基调**：喜剧 / 正剧 / 悲剧？（决定人物语言风格）

**档位特有复核项（S1 段）**：剧种 + 核心冲突确认 → 进入 C1。

---

## C1 选题（题材/冲突 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节。创作档·剧本子类.md 转义：
> 态势分析 → **题材冷热（可选）**；选题推荐 → **题材/冲突候选**；定题评测三维 → **冲突新颖性/情感真实性/可表演性**；标题打磨 → **题眼打磨**。

1. 从 P0 论证锚定卡提取选题关键词
2. 按四环节收敛候选 → 定题评测三维均过 → 定稿选题
3. 输出选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）

**守门③（选题定稿）**：三维均过 → 放行 C2。

## C2 材料建档（人物 · 冲突账本）

> 与学术档“证据账本”同构但内容不同：剧本的“证据”是**人物设定、冲突节点、转折设计**。

| 编号 | 人物 / 冲突素材 | 功能 / 意味 | 来源 |
|---|---|---|---|
| J01 | 老周：守了二十年厂门的老门卫 | 时代落幕的见证者 | 原型观察 |
| J02 | 核心冲突：拆迁通知 vs 不愿离开 | 全剧张力源 | 自设情境 |
| J03 | 转折：孙女说“爷爷，外面也有星星” | 情感破局点 | 自设 |

**素材缺口处理**：人物动机不清 → 提示用户补背景（不硬编）；冲突无力 → 标注〔待核〕，重写前不进 C2。

**守门⑤**：核心人物 / 冲突已建档且服务于核心冲突（母版迁移表 3.2，不强制覆盖率）→ 放行。

## C3 结构设计（分场 + 戏剧弧）

```
开场（建置）：呈现常态 + 抛出冲突（10% 篇幅）
发展（对抗）：冲突升级，人物两难（50% 篇幅，多场次）
高潮（突转）：关键抉择 / 反转（20% 篇幅）
结尾（释解）：新常态 / 余韵（20% 篇幅）
```

**结构检查**：每场是否有“戏剧目的”（推进冲突或揭示人物）；是否有“突转”与“发现”；场次之间是否因果相连。

**守门⑥**：四段齐全 + 冲突贯穿 → 放行。

---

## C4 逐段写作（对话驱动 · 场景化）

> **撰写顺序**：先写**建置场**（定人物定冲突）→ 写**对抗场**（冲突升级）→ 写**高潮场**（转折）→ 写**结尾场**（释解）。每场独立成块。

**话术底线（写入时即带着）**：
- **展示冲突而非告知**：用人物行动和对话表现，不写“老周很孤独”（写他每天擦三遍没人坐的椅子）
- **对话即性格**：不同人物说话方式不同（老周短句土话，孙女长句城市腔）
- **舞台提示克制**：只标必要的动作 / 神情 / 灯光（〔环视空荡的车间，手停住〕），不写小说式心理
- **潜台词**：好台词说一层、藏一层（“这厂，我不走”——藏的是半生）
- **禁用 AI 腔**：禁用说明性旁白堆砌；不写“此时此刻，他内心充满了……”

**每场强制操作**：回顾该场在戏剧弧的位置 → 按话术底线写 → 标舞台提示 → 更新写作状态摘要。

**守门⑦**：每场有戏剧目的 + 对话区分人物 + 无说明腔 → 放行。

## C5 对抗评审（冲突 / 人物 / 可表演性 三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 冲突评审 | 张力够不够？高潮是否成立？转折是否可信？ | 冲突问题清单 |
| 人物评审 | 人物是否立体？对话是否像他？动机是否合理？ | 人物问题清单 |
| 可表演性评审 | 能否被演出来？提示是否可执行？场景是否过碎？ | 可表演问题清单 |

**C5b 回退**：对话 / 表演问题 → C3；结构问题 → C2；剧种定错 → O2。

**守门⑧**：三角色通过 → 放行至打磨。

---

## C6 打磨交付（文体校验）

1. **场次结构终校**：场序连贯，每场标注“时间 / 地点 / 人物”
2. **舞台提示核对**：〔待核〕占位替换；提示可执行不冗余
3. **格式**：标准剧本格式（场景标题 + 人物表 + 对话 + 提示）
4. 生成发布就绪包：剧名 + 人物小传 + 全剧本 + 标签（#剧本 #短剧）

**守门⑧**：格式规范 + 冲突贯通 + 可表演 → 终稿交付 → 进入 E 层。
