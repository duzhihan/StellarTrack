# 查重与学术诚信检测模块

> 用途：论文模式和课题申报模式的打磨阶段自动触发
> 定位：方法论指南——告诉AI"检查什么"和"怎么检查"，实际查重需配合外部工具
> 关联：`ai-vocabulary-filter.md`（五层清稿管线）、`style-fingerprint.md`（文风一致性）

---

## 一、检测维度

### 1.1 文字重复检测

**检测范围**：

| 重复类型 | 说明 | 典型阈值 |
|---------|------|---------|
| 逐字重复 | ≥15个连续汉字完全相同 | 必须修改 |
| 近义替换重复 | 同一段落与已知文献的语义重叠 ≥40% | 必须修改 |
| 句式模板重复 | 连续3句使用完全相同的句式结构 | 建议修改 |
| 段落级重复 | 250字以上的段落与单一来源的相似度 ≥30% | 必须重写 |

**检测方法**（AI内部执行，不依赖外部API）：

1. **高频短语提取**：从文中提取所有5-gram，标记频率异常的短语组合
2. **句式结构分析**：检测连续句子的语法树结构是否过于一致（AI生成文本的典型特征）
3. **语义重叠检测**：对每个核心段落，用语义相似度评估其与已有文献的关系
4. **引文重复检查**：检测是否有同一段被多次引用但标注不同的情况

### 1.2 自我重复检测

| 检测项 | 操作 |
|--------|------|
| 与殿主已发表论文的文字重复 | 标记所有≥20字的连续重复段 |
| 与殿主已发表的论证重复 | 标记与已有成果的核心论点高度相似的部分 |
| 一稿多投风险 | 如果同一核心论证出现在多篇论文中，标注风险 |

### 1.3 文献真实性检测

| 检测项 | 操作 |
|--------|------|
| 引用年份 | 是否出现"未来"年份（如当前为2026年却引用2027年文献） |
| 文献可检索性 | 每条引用的作者+标题+期刊组合是否可被检索到 |
| 引用内容准确性 | 被引用的论述是否与原文一致（如可核实时） |
| DOI/URL有效性 | 电子资源的访问链接是否有效 |

**AI幻觉预警信号**（检测以下特征，如果出现则高概率是AI编造的引用）：
- 作者名过于"完美"（如"张三、李四、王五"等常见姓名组合）
- 期刊名不存在或拼写错误
- 出版年份与期刊创刊年份矛盾
- 文献标题过于贴合当前论文的论证需要（"刚好有这么一篇完美支持我论点的文献"）

### 1.4 AI生成痕迹检测

与 `ai-vocabulary-filter.md` 联动，额外检查：

| 检测项 | 检测方法 |
|--------|---------|
| AI高频词密度 | 统计全文英文禁用词的出现次数/千字 |
| 句式均匀性 | 检测句子长度方差是否过小（雕龙去AI化规则2） |
| 段落模板化 | 连续段落是否使用相同的"判断→分析→总结"模板 |
| 引用均匀性 | 是否所有章节的引用密度一致（AI倾向均匀分布，人类会有聚集） |

### 2.2 课题申报模式的额外检查

申报模式下的专属检测项：

| 检测项 | 操作 |
|--------|------|
| 与已立项课题的重复 | 检索近3年同方向已立项课题，评估重复风险 |

| 一题多报风险 | 同一活页是否同时申报多个基金 |

## 三、修改策略

### 3.1 文字重复的修改方法

**逐字重复（≥15字）**：
- 方法：重写——换一个角度表述同一内容
- 示例：原句"新媒体场域下戏曲文化的数字化转型"→"戏曲艺术在数字平台生态中的适应性变迁"

**近义替换重复（≥40%语义重叠）**：
- 方法：重构论证角度——不是换词，而是换论证路线
- 示例：原来从"技术驱动力"角度论述→改为从"受众接受心理"角度论述

**句式模板重复**：
- 方法：打散句式——长句变短句、被动变主动、倒装变顺叙
- 结合 `style-writer.md` 的特征7（辩证张力）——增加转折来打破模板化节奏

### 3.2 AI生成痕迹的消除方法

见 `ai-vocabulary-filter.md` 和 `style-writer.md` 中的完整指南。

### 3.3 文献真实性问题的处理

| 问题类型 | 处理方式 |
|---------|---------|
| 年份存疑 | 逐篇检索CNKI/WOS确认 → 修正或删除 |
| 文献不可查询 | 删除该引用，论点转为课题组的理论阐述 |
| 引用内容与原文不符 | 核实原文 → 修正引用 → 标注修改 |
| AI幻觉引用 | 立即删除 → 寻找真实文献替代 |

## 四、使用说明

本模块提供的是**检测方法论和修改指南**，实际的全文查重需要配合外部工具（如CNKI学术不端检测系统、万方相似性检测等）。

在论文工厂中的使用时机：
- **论文模式**：阶段四（逐段修改）的第三轮（AI味消除）时自动触发
- **课题申报模式**：阶段五（修改迭代）的第一轮（致命性问题清零）时自动触发
- **独立触发**：殿主说"查重检查""检测重复率""检查AI痕迹"时触发
