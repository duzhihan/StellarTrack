## L1 快速清扫（初稿后必跑 · 20 条）

### Quick Checks（5 项基础操作）

1. **删冗余副词**：显著地/深刻地/极大地/大幅度/明显地——无实质信息即删。❌“这深刻地改变了产业格局”→✅“这改变了产业格局”（或给出具体变化）
2. **删元评论句开头**：值得注意的是/需要指出的是/必须承认的是/毋庸置疑——删整句，只留后续信息
3. **删“宣布动作”开篇**：让我们先……/首先需要明确的是……——从信息本身开始
4. **控制破折号**：每 500 字 ≤1 个——优先用逗号、从句或括号替代
5. **删机械连接词**：首先…其次…再次…/第一…第二…第三…——用句意自然递进

### 高频套话替换（必改）

| 禁用表达 | 处理 |
|---|---|
| 毋庸置疑 / 众所周知 | 删除，直接陈述 |
| 深刻地 / 极大地 | 删除或用具体数据替代 |
| 不可磨灭的贡献 / 颠覆性 | 重要贡献 / 创新性（不夸大） |
| 切中要害 / 令人惊叹的 | 准确揭示了 / 显著的 |
| 从某种程度上说 / 在一定意义上 / 严格来说 | 删除或用精确限定词 |
| 不可否认的是 / 必须指出 | 删除，直接陈述 |
| 本文试图/尝试探讨 | 本文分析/论证（判断句直接开头） |
| 以期为……提供参考 / 有待进一步研究 | 具体贡献表述 / 具体未来方向 |
| 总而言之 / 综上所述 | 删除，用实质结论 |

### 口语化 + AI 口语感（必改）

| 禁用表达 | 处理 |
|---|---|
| 我们觉得/我们认为 | 删除主语，直接陈述判断 |
| 可以发现 | 这表明/由此可知/数据显示 |
| 很大/非常多 | 显著/大幅/超过 X% |
| 不管是 A 还是 B | 无论 A 抑或 B |
| 事情是这样的 / 答案很简单 / 说实话 | 删除，直接进入实质内容 |
| 这就是为什么…… | 正因如此，或用因果句 |

### 英文高频 AI 味词（英文文本自动检查）

leverage→use ｜ delve into→investigate ｜ elucidate→explain ｜ pivotal→important ｜ underscore→highlight ｜ robust→strong ｜ paradigm→framework ｜ unveil→present ｜ nuanced→subtle ｜ foster→promote ｜ utilize→use

### 英文元评论与句式反模式（v12.6.1 补 · 来源 wave2234/paper-cn-to-en，MIT）

- **it is worth noting that / it should be noted that** → 删整句，只留后续信息（与中文 L1 第 2 条“删元评论句开头”同族）
- **Moreover / Furthermore / Additionally 句首连发** → 禁连发（同段 ≤1 次）；改用转折逻辑（Yet/But/In contrast/句意递进）
- **英文学术散文原则（人文社科）**：领域术语（gaze／discipline／allegory／oblique critique 等）正常使用，**不因“生僻”降级为大白话**——SCI 的短句化/去术语化规范不套用于人文写作；对应 C6 文风底线在英文写作场景的扩展

## L2 质量检查（C4 表达评审对照 · 5 条清单）

1. **结构反模式**（连续出现即暴露模型感）：
   - “不是X而是Y”对比句——全文严控 ≤8 处/篇；多数情况直接陈述 Y
   - 三连列举——恰好 3 项 = 模型统计偏好，检查是否每一项有实质区别
   - 金句收尾——每段强行短句收尾（“算法，才是真正的创作者”）→ 直接以分析结束
   - 机械设问——设问嵌入论证流每千字 ≤1 次；“答案很简单/答案是”等机械过渡词禁用
   - 空泛过渡段——“以上分析了X，接下来将从Y展开”→ 删除（节标题已承担过渡功能）
2. **虚假施动者**（谁在具体做这件事？）：
   - 数据表明/研究表明/结果表明 → 加来源限定（“对XX数据的分析发现”“XX（学者名）的研究表明”）
   - 算法决定了/市场选择了/技术塑造了/时代要求我们 → 改写为具体施动者
   - 自动检查：凡主语为“数据/研究/市场/技术/时代/社会”的句子，逐一核验施动能力
3. **文风底线复核**（与 SKILL.md C3 联动）：
   - 段落首句 = 判断句（禁用“本文”“笔者”）
   - 段落三段式：判断(1-2句)→机制展开(3-5句)→边界过渡(1-2句)，缺第 3 步标记补充
   - 转折频率：每 300-500 字 ≥1 次辩证转折
4. **AI 味密度**：全文禁用词（L1 清单）≤3 次/千字；单段 ≥3 个禁用词自动标记
5. **五维抽查**（不再强制抽样统计，评审按表逐项核对）：

| 维度 | 核对项 |
|---|---|
| 直接性 | 随机 3 段，划掉可删而不影响论证的句子，留存 ≥80% |
| 节奏 | 连续 10 句无 5 句以上句长相近（±5 字内） |
| 可信度 | 全文无来源断言（“数据表明”等）每处扣分 |
| 真实感 | 禁用词密度 ≤3 次/千字 |
| 信息密度 | 随机 1 段能否压缩 40% 而不失要点 |

## L3 正向库与校准（v12.6.1 补 · 管“该用什么”）

> 与 L1/L2（管“删什么”）互补：L3 给正向论证句式与限定语校准。来源：Manchester Phrasebank / GMU Hedges / anti-defensive-writing（kiterlin，Claude Code Skill）蒸馏，2026-10-15 用户拍板落盘。

### L3-1 论证连接与推进表达库（按论证动作分类 · 中英对照）

| 论证动作 | 中文句式 | 英文句式 |
|---|---|---|
| 主张强度分级（强→弱） | 本文论证…／证据表明…／这一结果提示…／可能暗示… | This paper argues… / The evidence indicates… / These results suggest… / This may be taken to indicate… |
| 让步转折 | 诚然…然而…／必须承认…但… | Admittedly… yet… / It is true that… however… |
| 因果衔接 | 由此可知…／这意味着…／根源于… | This implies that… / This follows from… / This is attributable to… |
| 综述推进 | 在X的基础上推进…／回应了Y的质疑／与Z的结论相左 | builds on X… / responds to Y… / conflicts with Z… |
| 归纳收束 | 综上，本文的贡献在于… | Taken together, the contribution of this paper is… |
| 作者姿态（anti-defensive） | 本文考察…／本分析聚焦…／证据指向… | This paper examines… / The analysis focuses on… / The evidence indicates… |

**用法**：C6 撰写随用随查；主张强度分级与证据强度匹配（强证据用强主张，弱证据降一档），禁“强证据弱主张”或“弱证据强主张”错配。

### L3-2 hedging 双向表与“一 claim 一 hedge”校准（C9 评审 grep 用）

**正向 hedges（限定语 · 保留必要）**：
- 情态：may/might/could/would（可能/或许/大概）
- 动词：suggest/indicate/appear/seem/tend（表明/显示/似乎/倾向于）
- 概率形副：likely/possibly/probably/presumably/apparently/relatively
- 数量：some/many/one of/in general/typically/usually
- 作者距离：based on limited data…/according to this preliminary study…/in this sample…

**反向 boosters（绝对化 · 禁）**：definitely/absolutely/certainly/prove/clearly/obviously/utterly（毋庸置疑/众所周知/彻底/完全/绝对/显然）

**校准原则（Copyeditor.app “one hedge per claim”）**：
- 每条承重 claim 至少 1 个 hedge、至多 2 个；**单句叠 ≥3 限定词（如“在某种程度上或许可以初步推测”）＝过度限定（over-hedging），判不可证伪**
- 限定语要“配证据”：不确定性真实时指明来源（“现有证据支持此解读，但设计未估计总体效应”），不靠叠 hedge
- **anti-defensive 校准（kiterlin 蒸馏）**：不必要的 caveat/免责/道歉框架/自我设限句删除；防御性表达转正向范围——“本文不声称代表所有情境”→“本文聚焦 2015-2023 城市治理案例”；保留的限定必须是影响 claim 有效性/证据解读/适用范围/研究设计的必要限定，且集中放 methods/discussion/limitations，不散布在摘要/引言/主题句/结论

**修订一致性检查（C7/C10 必检）**：C7 净化/C10 返修后 grep 对比修订前后 hedges 命中集合，**命中数下降即标“限定语可能被误删”回查**（humanizer 去味流程有误删限定词盲区）。

## L4 机检闸（v12.6.1 补 · SNL-UCSB gate_mechanical 中文转译）

> 来源：SNL-UCSB/paper-writing-skill（MIT，240★，实证 7600+ 编辑）机检闸门蒸馏。**每写完一节即跑，报告命中数而非“已检查”**（R-10 写入时检查扩展）。

- **被动语态扫描（中文转译）**：`被指出/被认为/被表明/被广泛使用/被定义为` → 改主动（“本文论证/证据表明/本文采用”）；被动在方法节亦禁（“实验被开展”→“我们开展实验”）。中文被动不算泛滥，但“被X”出现在论断句即视为弱化主张。
- **声明式开启句**：`本文研究了/本文介绍了/本文探讨了` 开段 → 禁，改 claim 先行（“本文论证…”）；`In this paper, we…` 同理（英文装载节联检）。
- **术语漂移（term-drift）**：同一概念全文只准一个规范名（C4 概念收敛 ≤3 的约束落到全文）；C11 终检 grep 每个核心概念的表面变体（中文同义改写/中英混用/缩写不一致），收敛为一。
- **空泛形容词换数字或删**：显著/重大/深刻/全面/有效/强大的/极具——L2 已禁一部分，此处补“换数字”正向操作（“显著提升”→“提升 2.4 倍”）。
- **清嗓词**：值得注意的是/值得一提的是/事实上/本质上/换言之（作转场装饰时）→ 直接陈述；仅当其后有真实逻辑动作时保留（L3-1 让步转折句式除外）。

**确定性机检闸扩展（v12.6.1 补 · ganzhi-black/humanities-thesis-skill 21 条规则蒸馏 · MIT，673★）**：其 `scripts/review.py` 用**正则＋术语表**做确定性校验（不依赖模型自我判断，防“模型自己检查自己等于没检查”）——星躔守门增一层可执行机检。与既有闸互证的不重复登记；新增项：

- **模糊引用检测**：`有学者指出/有研究者认为/据研究` 后无具体文献 → 打回换“作者＋出处”或删（R1-01；守门⑤“删作者名测试”的自动化版）
- **未来年份引用**：`（20XX 超当前年份）` → 编造嫌疑（R1-03）
- **空脚注**：脚注编号后无内容（F-01）
- **文献类型标识缺失**：参考文献行无 [M]/[J]/[D]（F-02；GB/T 7714 要求）
- **标题编号体系混用**：`第一章` 与 `1.1` 并存全文 → 择一（F-04）
- **自称统一**：笔者/本文/本研究/我们/我 同稿混用超 2 种 → 收敛为一（S-02）
- **引文后缺分析**：引文结束直接跳新话题（下句以“此外/同时/值得一提的是/另外”开头）→ 补对引文的分析（L-03；方法卡11 第 4 步的检测层）
- **因果前提未论证**：`由于/因为/鉴于 ＋ 否定判断（并非/不是/并未）` 且上下文无引用 → 前提须先论证再推导（L-05；评分维度库“因果跳步判别”的检测层）
- **总结句概念堆砌**：`由此可见/综上所述/总之` 后顿号并列 ≥4 项 → 前文未展开的概念删或补论证（L-07）
- **强度词缺论据**：`显然/无疑/极其/毋庸置疑` 句 60 字内论据标记（不仅/而且/第一/例如/根据等）<2 → 删强度词或补论据（L-08；L3-2“一 claim 一 hedge”的检测层）
- **术语同义译名组（人文社科实例）**：赤裸生命/裸命、灵晕/灵韵/灵光、延异/延差/分延、规训/训诫、操演性/述行性、话语/论述、异托邦/异质空间、解域化/去疆域化、询唤/质询、主体化/主体建构 → 全文收敛一（T-01；本条为 L4 术语漂移的实例库）
- **互证不重复**：过度断言词表（毫无疑问/众所周知/不言而喻/显而易见）↔ L3-2 hedging 双向表；口语化词表（其实/说白了/笔者觉得/很明显）↔ L1/L2；连续 4 句无论证连接 ↔ 方法卡11 第 3 步；并列堆砌（同时/此外连发 ≥3 段）↔ L3-1 推进表达库与 C7 反模式

## L5 英文风格语料 · Nature 六原则（v12.6.1 补 · nature-skills 蒸馏）

> 来源：Yuan1z0825/nature-skills（Apache-2.0，48.4k★）nature-polishing/nature-shared 语料蒸馏（源语料从已发表 NMI 论文提炼，作风格参考非期刊官方政策）。**英文润色（方法卡07/08 装载节）时随用随查；与目标刊现行规则冲突时以期刊为准。**

| # | 原则 | 操作含义 |
|---|---|---|
| 1 | claim escalation（主张递进） | 主张强度沿引言→结果→讨论逐级递进，禁在引言透支结论 |
| 2 | fast question funnel（快问漏斗） | 引言快速从大问题收到本文具体问题（收窄有速度，不绕圈） |
| 3 | Introduction-Results alignment（引言-结果对齐） | 引言承诺的每个问题，结果必须逐一回应；结果发现不得脱离引言问题 |
| 4 | discovery-centred abstract compression（发现中心式摘要压缩） | 摘要以“发现”为中心压缩：方法让位给发现与含义，每句承载信息 |
| 5 | evidence-bound local interpretation（证据绑定局部解释） | 每段解释只推进本段证据能支撑的结论（禁全局拔高）；modal 动词按证据强度校准（may/suggest/indicate/argue 分级，与 L3-2 一致） |
| 6 | cross-Results synthesis（跨结果综合） | 多个结果节之间要有显式综合句（发现模式而非并列罗列） |

**Discussion 功能标签**：去 Results replay（讨论不得复述结果）、从具体发现走向有界启示（bounded implications）、modal/reporting 动词按证据强度校准、limitations 与 future work 须消解命名 claim 边界（点名的边界而非泛泛“未来研究”）。
