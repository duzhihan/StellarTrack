# 创作档·歌词子类工作流（流行 / 民谣 / 古风）

> **档位定位**：创作档·歌词子类 = 面对“音乐受众 / 旋律语境”这一话语共同体时，以韵律、意境、感染力为质量基准的表达方式。作者身份默认 = 词作者 / 创作者。
> **一句话**：歌词写的是“戴着手铐跳舞”——在旋律、韵脚、字数的三重约束里，把话说得最好听。
> **母版关系**：学术档是母版，歌词关闭“论证/证据”权重、开启“韵律·意境·感染力”权重，骨架（S/C1-C11）不变；C3 由“分析驱动”切“节奏驱动，音韵先行”。**专业内容由 lyrics-writing 引擎接管**（见下方 §〇）。
> **加载时机**：O2 锚定卡档位 = 创作档·歌词子类时，S 及 C 层按“本件档位转义 ＋ 骨架守门 ＋ 引擎按需取章”执行，适用工序见下方“档位路径声明”。
> **学术锚点**：歌词语音学“字词入乐”规律（平仄/开口音闭口音与旋律配合）+ 流行歌词“重复-对比”结构 + 民谣叙事传统 + 引擎源书《歌词写作十八讲》（吴颂今）与《歌词写作入门与提高》（毕春泽）。

## S 论证锚定复核（歌词子类）

复核四要点：
1. **曲风**：流行 / 民谣 / 古风 / 说唱？（决定 C2 段落结构与 C3 韵脚密度）
2. **主题**：爱情 / 青春 / 思乡 / 励志？（决定意象取向）
3. **有无现成旋律**：先有曲填词 / 先有词谱曲？（决定 C3 音韵先行程度）
4. **段落结构**：主歌-副歌-桥段？（标准三段式或按曲而定）

**档位特有复核项（S1 段）**：曲风 + 段落结构确认 → 进入 C1。

## C1 选题（题材/韵律 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节；执行顺序 **①态势 → ②推荐 → ⑤选题确认（人机对话）→ ③评测 → ④打磨**，⑤未拍板不进评测。创作档·歌词子类转义：
> 态势分析 → **题材冷热（可选）**；选题推荐 → **题材/韵律候选**；定题评测三维 → **意象新颖性/情感真实性/韵律可行性**；标题打磨 → **题眼打磨**。

产出：选题卡 C1-xxx（定稿选题 + 四环节记录 + 备选题）。

> **引擎取用**：题材冷热与备选角度查 `references/engines/lyrics-writing/chapters/02-题材构思.md`（选材三原则／创意立意／角度与细节）；定题评测前先定韵方向（`references/engines/lyrics-writing/references/rhyme-table.md` 情感匹配表：高昂→江阳／中东／发花，深情细腻→一七／灰堆／姑苏）。

**守门③（选题定稿）**：⑤选题确认已由用户拍板 + 三维均过 → 放行 C2。

## C2 材料建档（意象 · 韵脚账本）

> 与学术档“证据账本”同构但内容不同：歌词的“证据”是**意象、韵脚、情绪点**。

| 编号 | 意象/素材 | 情感/意味 | 韵脚候选 |
|---|---|---|---|
| Y01 | 老街·旧车站 | 离别·怀念 | ang / an |
| Y02 | 月亮·路灯 | 守望·孤独 | uang / uan |
| Y03 | 风·信·远方 | 向往·告别 | iang / an |

**韵脚原则**：主歌可松，副歌必严（副歌是记忆点）；同段同韵，转韵在段落边界。

> **引擎取用**：韵脚候选查 `references/engines/lyrics-writing/references/rhyme-table.md`（十三辙全表＋常用字词速查）；押韵技法（首句押韵／隔句押韵／换韵）与节奏表现见 `references/engines/lyrics-writing/chapters/04-韵律节奏.md`。

**守门④**：核心意象已建档 + 副歌韵脚方向明确（母版迁移表 3.2）→ 放行。

## C4 大纲协商（主歌-副歌-桥段）

### 标准三段式

```
主歌 A（叙事）：铺垫情境，写细节，韵脚可松（2 段，每段 4 句）
副歌 B（点题）：情绪高潮，重复记忆点，韵脚必严（2 遍，每遍 4 句）
桥段 C（转折）：情感深化或视角转换（1 段，2-4 句）
尾段（收束）：重复副歌或渐弱收尾
```

**结构检查**：副歌是否“一句能记住”？主歌是否“有画面”？段落情绪是否递进？

> **引擎取用**：曲式与段式辨析、建构组织十一法见 `references/engines/lyrics-writing/chapters/03-结构章法.md`（布局卡壳时读，勿全篇通读）。

**守门⑥**：副歌记忆点明确 + 情绪递进成立 → 放行。

## C6 正式撰写（节奏驱动 · 音韵先行）

> **撰写顺序**：先写**副歌**（定记忆点与韵脚）→ 再写主歌（补叙事铺垫）→ 最后写桥段（转折升华）。

> **引擎取用**：十六种修辞（比喻／比拟／对比／反复／对偶／设问／夸张／衬词／排比／顶真／叠字／通感／物候／括连／双关／起兴）与歌名／词眼设计查 `references/engines/lyrics-writing/chapters/05-语言修辞.md`；初稿→构思→修改四阶段与填词四步查 `references/engines/lyrics-writing/chapters/06-写作流程.md`；灵感或卡壳查 `references/engines/lyrics-writing/references/patterns.md`。

**话术底线（写入时即带着）**：
- **音韵先行**：先定副歌韵脚，再填词；字音要“唱得开”（开口音配长音、闭口音配短音）
- **口语入词**：歌词是唱出来的话——用口语短句，不用书面长句；避免生僻字
- **重复强化**：副歌关键词重复出现（“如果”“当初”等词眼）；动词比形容词有力
- **画面感**：每句有画面，不写抽象口号（“风把站牌吹旧了”而非“时光流逝”）
- **字数对齐**：每句字数大致相当（旋律节拍决定），主歌副歌字数可不同但各自内部一致
- **禁用 AI 腔**：禁用“岁月/星辰大海/不负韶华”等歌词套话堆砌；不写“这首歌表达了”

**每段强制操作**：回顾该段在歌曲结构的位置 → 按话术底线写 → 数字数、验韵脚 → 更新写作状态摘要。

**守门⑧**：副歌押韵 + 字数对齐 + 有画面 → 放行。

## C8 格式校验与合卷（文体校验）

1. **韵脚终校**：逐段核韵脚统一性（〔待核〕标注的韵脚核对）
2. **字数终校**：逐句数字数，与旋律节拍对齐
3. **开口音检查**：副歌长音处是否配开口音
4. 生成发布就绪包：歌名（2-3 候选）+ 歌词全篇（标注段落）+ 创作说明（主题/情绪基调）

> **引擎取用（必跑）**：`references/engines/lyrics-writing/references/checklist.md` 八项逐查——世界统一／题目承重／韵律／结构／语言／记忆点／净化／篇幅；任一项未过不得进 C9。

**守门⑩**：韵脚字数全合规 → 放行 **C9 联合评审**。

## C9 联合评审（韵律 / 意境 / 感染力 三角色）

**第一道 · 三角色合审**（星躔角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 韵律评审 | 韵脚是否统一？字数是否对齐？字音是否唱得开？ | 韵律问题清单 |
| 意境评审 | 画面是否成立？主题是否凝聚？有无套话堆砌？ | 意境问题清单 |
| 感染力评审 | 副歌能否记住？情绪能否被唱出来？ | 感染力清单 |

**第二道 · 引擎六层审**（`references/engines/lyrics-writing/SKILL.md`“评审模式”，一层不过即回改，不跳层）

| 层 | 审什么 | 判据 |
|---|---|---|
| 1 题目承重 | 歌名扛不扛得住主题全部重量 | 主题三要素（沉重／生机／前行）是否跳层；正文是否再现歌名 |
| 2 世界统一 | 一个主体、一个空间、一条时间线 | 每段能答“这一段在谁的故事里干什么” |
| 3 画面具体 | 有体温的动作与生活细节 | 与“道具名词贴标签”区分（吊嗓／勒头／数更漏 vs 铜锣／髯口／粉墨） |
| 4 格言排查 | 是否把道理说破 | 删掉该句情绪还在＝格言，须藏进画面 |
| 5 韵脚字数 | 段内同韵、句数对齐 | 篇幅是否够完整一首（全词 30-40 句） |
| 6 净化 | 套话／口号／点题喊主题 | “岁月／星辰大海／不负韶华／此生无悔”类套话清零 |

**C9b 回退**：韵律/字数问题 → C3；结构问题 → C2；曲风定错 → O2。

**守门⑪**：两道均通过（三角色 + 引擎六层）→ 放行 **C11 最终精校**（骨架默认）；任一道有未解项 → 挂起并列清单。
