> 纪律：**key/token/cookie 一律不入本册正文、不入记忆文件、不入产物**——本册只登记“用什么、怎么坏、怎么降级”；凭据本体存放位置在册内指路即可。

## 登记条目

### IF-01 知网检索底座（kns8s）
- 用途：C2 文献检索／C1 选题四环节｜驱动：Chrome DevTools MCP
- 凭据：用户账号密码登录（cookie 会话复用）
- 失效表现：跳登录页／cookie 过期｜降级：cnki-deepsearch→WebSearch 学术检索
- 已知坑：扫码 30-60 秒自动刷新不可靠，优先账密
- 【状态-2026-08-27核查】本地 skills 目录未检出 cnki-deepsearch/kns8s 对应 skill 文件，Chrome DevTools MCP 通道未确认连接 → 判定未部署。C2 实际须走降级通道，降级须显式披露并获授权（守门④）。

### IF-02 知网选题通道（x.cnki.net）
- 用途：C1 AI 选题分析（态势→推荐→评测→打磨）｜驱动：Vuex store＋SSE
- 凭据：同 IF-01 会话｜失效：SSE 中断→刷新重连｜降级：本地化四环节

### IF-03 cnki-deepsearch
- 用途：C2 学术采集优先通道｜凭据：无独立凭据
- 失效：接口超时｜降级：IF-01 手动＋WebSearch
- 【状态-2026-08-27核查】cnki-deepsearch 技能文件本地未检出，与 IF-01 同为未部署状态。注册表原记载“优先通道”与实际不符，已校正。

### IF-04 WebSearch / WebFetch
- 用途：通用检索与网页抓取｜凭据：平台内置
- 红线：学生个人信息／党建涉密／未发表全文禁出网，检索只出主题词

### IF-05 公众号采集路线（PC 历史消息接管）
- 用途：知识库服务供链补采（中国学派／中国文艺评论等 D 卡语料）
- 状态：搜狗路线判死，PC 接管路线待办（P2 悬置）

### IF-06 SiliconFlow embedding（bge-m3）
- 用途：K 库语义检索（keyword 升级）｜凭据：key 已备验证通过（存放处见用户密钥管理位）
- 状态：待接入｜失效降级：keyword 检索模式（K 铁律④）

### IF-07 GitHub 推送
- 用途：DiTing Protocol v2.0 开源发布｜凭据：需用户 token/connector
- 状态：待办｜降级：本地归档

### IF-08 ima 导入管道
- 用途：移动端文章收藏→月度导出灌 Vault L0 RAW｜凭据：ima 账号
- 状态：管道已定义（K 库知识架构 v1），执行随知识库读写窗

### IF-09 anydoc 文档摄取（本地·离线）
- 用途：知识库“目”阶默认摄取通道；C2 材料建档、PDF/docx/pptx/xlsx 等十四格式统一转 Markdown
- 形态：Python（`firecrawl-anydoc`，已装受管 venv）／CLI（`npx -y @firecrawl/anydoc@0.2.4`）／Agent Skill（已实装于用户级 skills）
- 许可：**MIT** → 可随星躔发布包分发（与 AGPL v3 的 MarxSphere、CC-BY-NC 4.0 的 ARS 不同，后二者禁入发布包）
- 凭据：无；hosted OCR 分支需 `FIRECRAWL_API_KEY`，**本环境禁用**
- 红线：未发表论文稿件与申报书／含学生个人信息材料／党内文件与内部纪要，**一律禁 hosted OCR**（整份上传第三方、无页选择、无需注册即可匿名上传）
- 失效表现：`NeedsOcr`（退出码 3）→ 报告用户转人工或本地 OCR；`Encrypted`／`Malformed` → 降级 `pdfplumber`
- 降级：pdfplumber 后备（保留在受管 venv）
- 状态：**已部署**（2026-09-15）｜审计 P0=0／P1=2（npx 供应链＋OCR 外传诱导，已由本机补丁加固）
- 版本纪律：锁 v0.2.4，升级须重过安全审计

### IF-10 知识库图录语义检索（向量，规划）
- 用途：知识库阶二“万物问答”——回答“我读过什么关于 X／某理论我积累了什么”
- 方案：嵌入沿用 **IF-06 SiliconFlow bge-m3**（key 已备，零新增凭据）＋ **本地 sqlite-vec 存储**（向量落本机，查询离线）
- 凭据：同 IF-06（存放处见用户密钥管理位）
- 红线：含**未发表论证**的笔记（论文③交叉段、女性向／AI 玩具相关分析）标 `no-embed`，排除出网；仅公开文献笔记参与嵌入
- 失效降级：keyword 检索（CSV ＋ 总索引，K 铁律④）
- 状态：**待用户授权启动**（包与脚本已备，未执行灌入）

### IF-11 歌词写作引擎（lyrics-writing）

- 用途：创作档·歌词子类专业内容源（韵辙／结构／修辞／校验），挂 C1／C2／C4／C6／C8／C9｜形态：纯 Markdown 指令包（12 件 · 84 KB，无脚本、无外链、无凭据）
- 安装位：`references/engines/lyrics-writing/`（随星躔活体走，不另设用户级 skill 安装位）
- 来源：蒸馏自《歌词写作十八讲》（吴颂今）、《歌词写作入门与提高》（毕春泽）｜许可：自建蒸馏件，随包分发
- 安全审计：2026-10-26 全量扫描（curl／wget／exec／eval／subprocess／requests／http(s)／base64／token／api_key／prompt 注入话术）**P0=0／P1=0**；无脚本文件
- 加载纪律：按需取章，`SKILL.md` 只作索引；单稿调用 ≤3 章
- 失效表现：误引旧版章节名／把引擎当流程源接管守门 → 以档位条款为准（`创作档_歌词子类.md` §〇 冲突裁定）
- 降级：引擎缺件时回退到档位内联条款（S 四要点／C2 韵脚原则／C4 三段式／C6 六条话术底线／C8 三项终校／C9 三角色）
- 状态：**已挂载**（2026-10-26）
