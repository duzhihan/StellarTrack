# 创作档·起名子类工作流（人名 / 品牌 / 作品名）

> **档位定位**：创作档·起名子类 = 面对“命名对象 / 寓意期待”这一话语共同体时，以寓意、音韵、笔画为质量基准的表达方式。作者身份默认 = 命名者 / 创作者。
> **一句话**：起名写的是“一个名字就是一篇微型小说”——几十个字里，藏着家庭的期待、品牌的性格、作品的魂。
> **母版关系**：学术档是母版，起名关闭“论证/证据”权重、开启“寓意·音韵·笔画”权重，骨架（S/C1-C11）不变；C3 由“分析驱动”切“组合驱动，寓意优先”。
> **加载时机**：O2 锚定卡档位 = 创作档·起名子类时，S 及 C 层按“本件档位转义 ＋ 骨架守门”执行，适用工序见下方“档位路径声明”。
> **学术锚点**：中国传统命名学“名字与寓意互文”（《说文》字义考）+ 音韵学“声韵搭配”（双声叠韵/开口闭口）+ 品牌命名“语音象征”（sound symbolism）。
> **T 层工具挂载（2026-09-12）**：C1 候选生成可用 **gushi-namer**（古诗文起名工具，在线 Demo https://holynova.github.io/gushi_namer/ ，用法与降级见 `skills/gushi-namer/SKILL.md`）——路径 A 引导用户在线交互挑选，路径 B AI 按同款方法论直接生成；每个候选名必须保留“典籍+篇名+原句”出处三件套；Demo 不可达时直接走路径 B，不卡死。

## S 论证锚定复核（起名子类）

复核四要点：
1. **命名对象**：人名（孩子）/ 品牌 / 作品 / 栏目？（决定 C2 候选策略与 C5 校验项）
2. **姓氏/约束**：姓什么（人名必填）；品牌有无行业前缀？（决定 C1 典故方向）
3. **寓意偏好**：期望什么含义——品格（仁/诚/毅）、福泽（安/康/瑞）、志向（远/鸿/鹏）？（决定 C1 选字方向）
4. **风格**：古雅 / 现代 / 文艺 / 接地气？（决定候选气质）

**档位特有复核项（S1 段）**：对象 + 寓意偏好确认 → 进入 C1。

## C1 选题（命名方向 · 定题四环节转义）

> 完整映射见学术档工作流 C1 节；执行顺序 **①态势 → ②推荐 → ⑤选题确认（人机对话）→ ③评测 → ④打磨**，⑤未拍板不进评测。创作档·起名子类转义：

**守门③（选题定稿）**：⑤选题确认已由用户拍板 + 三维均过 → 放行 C2。

## C2 材料建档（典故 · 音韵账本）

> 与学术档“证据账本”同构但内容不同：起名的“证据”是**字义、典故、音韵搭配**。

| 编号 | 候选字/词 | 字义/出处 | 音韵特征 |
|---|---|---|---|
| Y01 | 聿（yù） | 《说文》笔也，书写 | 去声，开口 |
| Y02 | 之恒 | 《诗经》如月之恒 | 平仄搭配 |
| Y03 | 望舒 | 《离骚》望舒御月 | 双声叠韵 |

**选字原则**：寓意字 + 音韵字搭配——一个承载期望，一个调节声调；避免生僻字（宁常用不俗）。

**守门④**：核心候选字已建档且寓意明确（母版迁移表 3.2）→ 放行。

## C4 大纲协商（候选生成 + 筛选）

### 标准流程

```
候选生成（5-8 个）：按寓意方向组合（寓意字 × 音韵字 / 典故词 / 现代风格词）
初筛（3-5 个）：去生僻、去拗口、去明显谐音坑
排序：按“寓意契合度 × 音韵顺口度”排出 2-3 个主推
```

**结构检查**：每个候选是否有“寓意一句话解释”（为什么是这个名字）？是否覆盖不同风格？

**守门⑥**：候选 ≥3 个 + 各配寓意解释 → 放行。

## C6 正式撰写（组合驱动 · 寓意优先）

> **撰写顺序**：先定**寓意方向**（C1 偏好）→ 生成候选组合 → 每个候选写“寓意+音韵+理由”三行说明。

**话术底线（写入时即带着）**：
- **寓意第一**：每个字都要“讲得出为什么”（不凭空组字）
- **声调搭配**：连读要顺（平仄错落，忌三连仄/三连平）；避免同声母叠字（“静静/婷婷”慎用）
- **谐音排查**：必须读谐音——正面谐音可用（“知远”谐“致远”），负面谐音必杀（“杨伟/杜子腾”类）
- **笔画平衡**（人名）：姓名总笔画适中，勿过于繁简悬殊
- **时代感**：古雅 ≠ 生僻；现代 ≠ 网红化——平衡“有出处”与“好写认”
- **禁用 AI 腔**：禁用“梓/萱/浩/宇”等过度流行的 AI 高频起名字（泛滥即俗）；不写“这个名字寓意深刻”

**每名强制操作**：回顾该名对应寓意方向 → 按话术底线生成 → 谐音笔画自查 → 更新写作状态摘要。

**守门⑧**：候选 ≥3 + 无负面谐音 + 声调顺口 → 放行。

## C8 格式校验与合卷（文体校验）

1. **谐音终检**：每个候选读三遍（含方言/英语谐音检查）
2. **重名检查**：人名提示查户籍重名率（可调用工具）；品牌查商标近似（提示用户）
3. **字形终检**：手写一遍，看结构是否美观、繁简是否协调
4. 生成发布就绪包：候选清单（3-5 个）+ 每个的“寓意/音韵/理由”三行 + 主推建议（1-2 个）

**守门⑩**：谐音重名全排查 + 主推建议明确 → 放行 **C9 联合评审**。

## C9 联合评审（寓意 / 音韵 / 笔画 三角色）

| 角色 | 审什么 | 输出 |
|---|---|---|
| 寓意评审 | 每个字是否有出处/理由？整体含义是否健康正面？ | 寓意问题清单 |
| 音韵评审 | 连读是否顺口？有无拗口/负面谐音？ | 音韵问题清单 |
| 笔画评审 | 笔画是否失衡？是否生僻难写？ | 笔画问题清单 |

**C9b 回退**：音韵/笔画问题 → C3（重组候选）；寓意方向偏 → C1；对象定错 → O2。

**守门⑪**：三角色通过 → 放行 **C11 最终精校**（骨架默认）。
