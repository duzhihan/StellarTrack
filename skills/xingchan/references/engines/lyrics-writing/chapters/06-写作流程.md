# 06 写作流程（从想法到成稿 + 填词 + 修改）

> 来源：书1 第九、十三、十四讲；书2 第十一、十二章。用途：完整走流程、改稿、填词、给歌手写词。

## 1. 创作四阶段（书1 第九讲）

1. **前期创意（立意）**：先有总体想法——写什么题材、表达什么主题、什么形式与用途。想法不清不动笔。
2. **构思（图纸）**：像建楼先画图纸——定段式、定结构章法（见 chapters/03）、排意象、定韵脚。
3. **写作初稿（打草稿）**：把构思落成文字，先求全不求精，一气呵成。
4. **修改定稿**：全面检查主题是否鲜明、结构是否完整、语言是否精当、韵脚是否顺口，反复打磨到满意。

## 2. 唱着写（作词小窍门）

- 歌词是音乐文学，创作时最好有旋律相伴；
- 会唱歌就随口哼哼——把写出的词句随口唱出来，拗口处当场改；
- “唱着写”是检验一切歌词的终极手段：唱不顺的词再漂亮也是废词。

## 3. 填词（书1 第十三讲 · 为现成旋律写词）

- 填词是实用有效的作词方式（诗经→汉乐府→宋词→元曲皆是填词传统）。
- **方法与步骤**：
  1. 反复听旋律、哼熟、摸清曲式（段落划分）；
  2. 按曲式定段落与句数、每句字数（对节拍）；
  3. 定主题、情感方向（词曲感情风格必须一致）；
  4. 排韵（注意旋律终止音、长音处放开口音）；
  5. 逐段填写、唱着校准。
- **注意方面**：词曲感情风格一致；按旋律节奏填（强拍放重字、长音放长韵）；曲式与字数对应；衬词处可填感叹词；注意旋律可塑性——同一旋律可填不同情绪的词，风格仍要贴合。
- 能词能曲（颂今实践）：自己既写词又作曲，自由度最大；次之是词曲作者紧密合作。

## 4. 修改（书1 第十四讲 · 书2 第十二章）

- **定位**：修改是作品成功的关键，贯穿写作全程；它是二次创作、是思维沉淀再升华。
- **修改的四个方面**：
  1. 主题提炼（主旨是否鲜明、集中）；
  2. 结构安排（段落是否完整、层次是否清楚、节奏是否对）；
  3. 语言运用（是否准确、形象、口语化、有新意）；
  4. 风格把握（词风与曲风、体裁、受众是否一致）。
- **过程**：自我审视（带批评质疑的眼光问：词稿成不成立？有没有修改价值？哪里最弱？）→ 修改 → 定稿。放一放再改更有效（时间冷却）。
- **小窍门（增删改调四法）**：
  - **增**：缺铺垫加句、少细节补细节、情绪不到位加词眼；
  - **删**：删套话、删重复多余的修饰、删偏离主题的段落；
  - **改**：改不顺口的字、改弱动词、改生硬押韵、改抽象为具象；
  - **调**：调整段落顺序、调整句序、调换意象位置、调韵脚分布。

## 5. 学习与积累（书2 第十一章）

- 阎肃：“学书要临帖”——写歌词也要临“帖”：背唱优秀歌词，分析结构韵律，研究词作高手（乔羽、阎肃、颂今等）。
- 王立平：“读万卷书行万里路”——阅读积累语言，生活积累素材；二者缺一不可。
- 保持：多听（各种曲风）、多读（诗歌散文小说）、多写（笔耕不辍）、多改。

## 6. 和乐（书2 第十二章 · 词曲结合）

- 歌词定稿后与旋律结合＝和乐；歌词是歌曲的半成品，靠音乐展现完整。
- 和乐阶段：试唱全曲、核对字数与节拍、调整句尾音、必要时局部增删词句；
- 词作者应主动与曲作者合作、倾听演唱者的意见（见 chapters/07 运作节）。
