# 歌词写作（lyrics-writing）

## 心智模型

**歌词 = 戴着镣铐跳舞**：在旋律、韵脚、字数的三重约束里，把话说得最好听。它先是被唱出来的话（口语、上口、易记），再是文学（形象、意境、情感），最后才是诗（结构、修辞）。

三条总原则（两本书的共识）：

1. **形式为内容服务**：押韵、结构、修辞都服从主题与情感表达，绝不为押韵而损伤主旨。
2. **歌词是听觉艺术**：写给耳朵听的——口语短句、通俗易懂、朗朗上口、易唱易记；诗歌是视觉艺术，可以艰涩，歌词不行。
3. **音韵先行**：先定韵脚再填词；字音要“唱得开”——开口音（a、ia、ua、ang 等）配长音高音，闭口音配短音弱音。

## 工作流（写一首新歌词）

1. **定标**（动笔前一次问清，缺项按默认走）：
   - 曲风：流行 / 民谣 / 古风 / 摇滚 / 说唱 / 儿童 / 企业行业 / 艺术——决定结构、韵脚密度、语言风格。
   - 主题与情感基调：爱情 / 青春 / 思乡 / 励志 / 家国……
   - 有无现成旋律：有 → 填词流程；无 → 自由创作但预设曲式。
   - 段落结构：主歌-副歌-桥段三段式（默认），或按曲式定。
   - 受众：谁在唱、唱给谁听（影响口语度与用词）。
2. **定韵**：按主题情绪选辙（见 `references/engines/lyrics-writing/references/rhyme-table.md` 情感匹配表：高昂→江阳/中东/发花，深情细腻→一七/灰堆/姑苏……）。主歌可松、副歌必严；同段同韵，转韵只在段落边界。
3. **建意象账本**（对应星躔 C2）：列 3-6 个核心意象 + 各自情感 + 韵脚候选；确保副歌韵脚方向明确。
4. **先写副歌**：定记忆点（一句能记住的话）、定韵脚、定重复词眼。
5. **再写主歌**：叙事铺垫、画面细节、为副歌蓄势；最后写桥段（转折/升华/视角切换）。
6. **校验**：读 `references/engines/lyrics-writing/references/checklist.md` 七项逐查——世界统一、题目承重、韵脚统一、字数对齐、画面成立、口语化、净化；篇幅不足先补“日子”（具体动作与生活细节），不注水口号。
7. **打磨**：按 `references/engines/lyrics-writing/chapters/06-写作流程.md` 修改节（增删改调四法）收尾，最后“唱着写”验证顺口；被批“拼接/低级/格言”返工时，回到“评审模式”逐层重审。

## 成稿七查（快速版）

1. **世**（世界统一）：全歌只有一个主体、一个空间、一条时间线？每段都问“这一段在谁的故事里干什么”——答不上就删或改？
2. **题**（题目承重）：歌名扛不扛得住主题的全部重量（沉重层/生机层/前行层都不跳层）？副歌一句能记住？歌名在正文再现（记忆闪光点）？
3. **韵**：副歌逐句押韵统一？转韵只发生在段边界？
4. **字**：每句字数与旋律节拍对齐，段内句长大致一致？篇幅够一首完整歌（全词 30-40 句）？
5. **画**：每句有画面、有体温的动作与生活细节，不写抽象口号、不堆道具名词？
6. **口**：口语短句、无生僻字、唱得开（长音配开口音）？
7. **净**：无套话、无标语口号、无哲理格言（把道理端到脸上）？

## 评审模式（拿到词稿 / 审自己一稿时）

按层审，一层不过就回改，不跳层：
1. **题目承重**：歌名扛不扛得住主题三要素？
2. **世界统一**：一个主体、一个空间、一条时间线？
3. **画面具体**：有体温的动作与生活细节，还是道具名词贴标签？
4. **格言排查**：把道理说破的句子，删了情绪还在不在？还在就是格言。
5. **韵脚字数**：段内同韵、句数对齐、篇幅够不够。
6. **净化**：套话/口号/点题喊口号清零。

## 反模式（禁用）

- 套话堆砌：岁月、星辰大海、不负韶华、此生无悔、泪眼婆娑、灯火阑珊（无具体画面地堆）。
- 哲理格言：把道理直接说破（“沙咽进嗓，珠胎暗结”）——要藏在画面里（“江底沙，磨十年”）。判据：这句删掉，情绪还在不在？还在就是格言。
- 道具名词堆砌：贴标签式的符号罗列（铜锣/髯口/粉墨）——要有体温的动作与生活（吊嗓、勒头、数更漏、炊烟上檐）。
- 典故引用代替重历：原句入词或“翻译典故”——要重历（古人的心境重新长成自己的句子，无一句原句）。
- 点题喊口号：结尾直接喊主题词（“何妨且前行！”）——主题要落在画面与动作上（解缆、水自向前）。
- 书面长句当歌词：主谓宾齐全的书面语、复句、“以及/从而/然而”类连接词。
- 无节制形容词：每个名词都挂形容词，动词软弱（用“风把站牌吹旧了”而非“时光流逝”）。
- 为了押韵颠倒语序或生造词（“爱意融融”“情深意重”这类硬凑）。
- 抽象口号：全是“我们多么勇敢/世界多么美好”式表态，无画面无细节。
- 歌名与内容脱节、不承重，或正文无呼应。
