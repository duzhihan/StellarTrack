# 歌词写作 · 成稿自检清单（checklist）

> 每稿校验必用：按七项逐条过，任一不过即回改。与星躔 C8 韵脚字数终校 / C9 三角色评审配套。

## 〇、世界统一（防拼接）

- [ ] 全歌只有一个主体（“我”是谁，全程不变）
- [ ] 全歌只有一个空间（一个地方，意象不跨世界）
- [ ] 全歌只有一条时间线（一夜/一天/一段人生，顺序推进）
- [ ] 每段都“在故事里干了一件事”（铺垫/点题/转折），答不上就删或改

## A. 韵律（韵脚/节奏/字音）

- [ ] 副歌逐句押韵统一（二四句必押，首句可押可不押）
- [ ] 同段同韵，转韵只在段落边界
- [ ] 没有为押韵倒装语序、生造词、反复凑同一个韵字
- [ ] 每句字数与旋律节拍对齐，段内句长大致一致
- [ ] 副歌句尾是开口音长韵（ang/eng/ai/ao 等），唱得开
- [ ] 短句长句搭配有节奏松紧，不板不散
- [ ] 篇幅够一首完整歌（全词 30-40 句、戏腔古风 35-45；主歌 4-8 句、副歌 4-6 句）

## B. 结构（段式/章法）

- [ ] 段式与曲式一致（一段/二段/三段 A-B-A/多段）
- [ ] 副歌有明确记忆点（一句能记住）
- [ ] 主歌有画面、为副歌蓄势；桥段有转折或升华
- [ ] 每一段都“在歌里干了一件事”（铺垫/点题/转折），无失职段
- [ ] 篇幅长短适度，为音乐留白

## C. 语言（口语/画面/词眼）

- [ ] 口语短句，无书面长句复句（“以及/从而/然而”零出现）
- [ ] 无生僻字，人人听得懂
- [ ] 动词有力，形容词不轰炸
- [ ] 每句有画面、有细节（有 1-2 处典型细节/旧物/动作）
- [ ] 有词眼（副歌一句精彩到值得重复三遍）

## D. 记忆点（歌名/副歌）

- [ ] 歌名切合词意、精练、新颖、无歧义
- [ ] **歌名扛住主题全部重量**（沉重层/生机层/前行层都不跳层；不得志的沉不能一笔带过）
- [ ] 歌名在正文（副歌）再现形成记忆闪光点
- [ ] 副歌单独拎出来能传唱、能记住

## E. 口语与情感

- [ ] 唱着顺口（逐句默唱一遍，拗口处已改）
- [ ] 情感真实不假大空，不说教
- [ ] 受众定位清楚（谁唱、唱给谁听，语言风格一致）

## F. 净化（反模式清零）

- [ ] 无“岁月/星辰大海/不负韶华/此生无悔”式套话堆砌
- [ ] 无哲理格言（把道理说破的句子删了情绪还在不在？还在就改）
- [ ] 无点题喊口号（结尾直接喊主题词——须落在画面与动作上）
- [ ] 无抽象口号（只有表态无画面）
- [ ] 无道具名词贴标签（有体温的动作与生活细节替代符号罗列）
- [ ] 无硬凑的韵脚生造词
- [ ] 歌名与内容不脱节、承重

## 交付动作

- [ ] 全篇标段（主歌A1/A2、副歌B、桥C）
- [ ] 写出创作说明：主题、情绪基调、曲风、押韵辙名
- [ ] 给出歌名候选 2-3 个（如适用）

## 三角色评审速查（配合星躔 C9）

- **韵律评审**：韵脚统一？字数对齐？字音唱得开？→ 不过回 C6
- **意境评审**：画面成立？主题凝聚？无套话？→ 不过回 C4/C6
- **感染力评审**：副歌能记住？情绪能被唱出来？→ 不过回 C6
