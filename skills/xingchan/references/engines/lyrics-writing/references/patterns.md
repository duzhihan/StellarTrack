# 歌词写作 · 模式库（patterns）

> 蒸馏自两书例词与章法；卡壳时从库里取模式组装，审稿时用反模式挑刺。所有模式按“场景 → 模式 → 示例/说明”组织。

## 〇、标杆写法四条（蒸馏自《江声入旧年》——化用王湾《次北固山下》的治愈系古风）

> 实战教训：被批“拼接/低级/格言化”时，回到这四条逐条验。这是“高级感”的最小可执行标准。

1. **化用＝重历，不是引用**：无一句原句入词；古人的心境（乡愁/羁旅/时间）重新长成自己的句子。对照《次北固山下》“海日生残夜，江春入旧年”与歌词“辞旧岁，一夜鱼龙焰”“岁岁年年，咫尺天边”，可见重历而非搬运。
2. **写日子，不写宣言**：生机是具体动作与生活（倚窗、绿酒新添、梧桐疏雨、拥枕抱被眠、堂前新燕）——不是“我还在唱”式自我鼓励。
3. **情绪闷着**：意阑珊，客散懒收敛——不喊，让听众自己品出那层；唯一的点题句只在最末轻收（“治愈，自己给的最好”）。
4. **句子是唱的节奏**：四字+五字/七字长短结合，有留白；短句收尾（“拥枕抱被眠”“风声不减”）。

**使用**：题材卡壳或返工时，先问“我这首的‘日子’在哪？——具体的人在做具体的事吗？”再问“有没有哪句把道理说破了？”

## 一、结构模式（布局）

| 模式 | 适用场景 | 说明与示例 |
|---|---|---|
| 起承转合 | 四句段、通用 | 起：点题。承：铺叙。转：转折。合：收束。例：《问君能有几多愁》式古典四句 |
| 副歌-主歌-桥三段式 | 流行/民谣 | 主歌 2×4 句铺垫 → 副歌 4 句点题重复 → 桥 2-4 句升华 → 尾重复副歌 |
| 问答呼应 | 对唱、设问歌 | 一唱一问、一答一和；可问而不答留悬念。例：《为了谁》“你是谁？为了谁？” |
| 分述并列 | 主题分侧面 | 每段写一个侧面，段间并列对称。例：《我爱五指山，我爱万泉河》《兰花与蝴蝶》 |
| 一字一词贯穿 | 关键词驱动 | 一个词作全篇骨架。例：《辣妹子》“辣” |
| 时间/空间顺序 | 叙事、游记 | 按时间线或空间移动组织（一天/四季/家乡到远方） |
| 情景交融 | 抒情 | 每句景中带情，不空发议论 |
| 回忆倒叙 | 怀旧 | 现在回望过去，先写结果再展开缘由 |
| 回旋反复 | 副歌强化 | 核心句段反复出现，一唱三叹 |
| 条例口号 | 队列歌/行业歌 | 条目化、口号化铺排，整齐有力 |
| 先擒后纵 | 庄重抒情 | 点题开篇→铺叙→回到主题收束。例：《西部放歌》 |

## 二、修辞武器库（按目的选）

| 目的 | 用哪种 | 例 |
|---|---|---|
| 化抽象为形象 | 比喻、比拟 | “你的眼睛像星星”“风儿唱着歌” |
| 强化记忆点 | 反复、排比 | 副歌重复词眼；“你是风，你是雨，你是光” |
| 制造强烈反差 | 对比 | “你从前慢，现在快” |
| 吸引注意 | 设问 | “这是谁家的孩子？” |
| 增强气势 | 排比、对偶 | 古风对仗；排比连发 |
| 民歌风味 | 衬词、起兴、叠字 | “呼儿嗨哟”“孔雀东南飞”；“青青的山蓝蓝的天” |
| 含蓄深沉 | 双关、通感 | 言在此意在彼；感觉互通 |
| 环环相扣 | 顶真 | “上句末字即下句首字” |
| 借时令表情 | 物候 | 草木荣枯、燕子来去 |
| 词语移用 | 括连 | “种下希望，收获秋天” |
| 情绪强化 | 夸张 | “眼泪流成河” |

## 三、句式节奏模式

- **五字句**（2+3）：简洁明快，儿歌/民谣常用。
- **七字句**（2+2+3 或 4+3）：最稳，叙事主力。
- **长短结合**：长句舒展、短句紧凑；主歌长副歌短或反之，制造松紧。
- **破句/倒装口语化**：反整齐制造自然感，但倒装不能生硬。
- **句尾拖腔**：段尾/副歌句尾放开口音长韵（ang/eng/ai/ao），唱得开。

## 五、歌名与词眼模式

- 歌名＝核心意象 / 关键词眼 / 情感句 / 矛盾反差 / 动作场景 / 设问 / 时间地点。
- 词眼位置：副歌首句或末句、段落转折处；值得重复三遍的句子。
- 记忆闪光点：歌名在正文副歌再现（句尾点题）。

## 六、反模式（审稿挑刺清单）

| 反模式 | 判据 |
|---|---|
| 套话堆砌 | 岁月/星辰大海/不负韶华/此生无悔/泪眼婆娑无画面堆叠 |
| 哲理格言 | 把道理直接说破（“沙咽进嗓，珠胎暗结”）——删了这句情绪还在不在？还在就是格言 |
| 道具名词堆砌 | 贴标签式符号罗列（铜锣/髯口/粉墨）vs 有体温的动作（吊嗓、勒头、数更漏、炊烟上檐） |
| 典故引用代替重历 | 原句入词或“翻译典故”——须把古人心境重新长成自己的句子 |
| 点题喊口号 | 结尾直接喊主题词（“何妨且前行！”）——主题须落在画面与动作上（解缆、水自向前） |
| 题目轻飘不承重 | 歌名只取一面（豁达）跳过主题沉重层——三要素（沉/微/韧）一个都不能跳 |
| 书面长句 | 主谓宾齐全的复句、“以及/从而/然而”连词入词 |
| 形容词轰炸 | 名词个个挂形容词，动词软弱 |
| 硬凑押韵 | 为押韵倒装语序、生造词、反复用同一韵字 |
| 抽象口号 | 无画面的表态（“我们多么勇敢”） |
| 歌名脱节 | 歌名与正文无呼应，无记忆闪光点 |
| 段落失职 | 某段不知在歌里干什么（不铺垫不点题不转折） |
| 世界不统一 | 一个主体/一个空间/一条时间线断裂——每段换人换景换时间 |
| 韵脚混乱 | 段内转韵、副歌不押韵、句尾闭口音拖腔难唱 |
| 字数不齐 | 同段句长悬殊，旋律节拍对不上 |
| 篇幅不足 | 全词 <25 句，情绪未展开——先补“日子”不注水 |
| 说教腔 | 教育口吻（尤其儿童歌：寓教于乐而非板脸说教） |
