# 歌词写作 · 术语表（glossary）

> 蒸馏自两书；按写作场景需要查用。常见术语先看本表，深挖看对应章节。

## 结构类

| 术语 | 含义 |
|---|---|
| 歌词 | 合乐能唱的诗；歌曲的半成品，靠音乐完整呈现 |
| 歌名/标题 | 歌词的题目，给人第一印象，常在副歌中再现形成记忆闪光点 |
| 词眼 | 全篇最精彩的语句，给人深刻烙印的语言（“出血点”） |
| 句式 | 歌词结构的基本单位，由汉字构成，字数多少与节奏分组形成句式 |
| 段落 | 句子组合成的意义单位，通常对应歌曲的一段旋律 |
| 段式 | 歌词整体结构形式，与歌曲曲式一致（一段式/二段式/三段式/多段式） |
| 曲式 | 音乐的结构形式（乐句→乐段→全曲），歌词结构受曲式制约 |
| 主歌（A段） | 叙事铺垫部分，交代情境细节，韵脚可松 |
| 副歌（B段） | 点题高潮部分，重复记忆点，韵脚必严 |
| 桥段（C段） | 转折升华部分，情感深化或视角切换 |
| 前奏/间奏/尾奏 | 音乐部分，词不占位但要留白 |
| 记忆点 | 副歌中一句能记住的句子，全歌的灵魂 |
| 起承转合 | 中国诗词歌曲最常用的结构：起（点题）承（铺叙）转（转折）合（收束） |
| 一唱三叹 | 回旋反复的章法，核心句段反复出现强化记忆 |

## 音韵类

| 术语 | 含义 |
|---|---|
| 押韵（合辙） | 歌词句尾字的韵母相同或相近 |
| 十三辙 | 普通话押韵体系：发花/梭坡/乜斜/一七/姑苏/怀来/灰堆/遥条/由求/言前/人辰/江阳/中东 |
| 响韵/洪亮级 | 江阳、中东、发花、言前、人辰——开口大、情绪高昂 |
| 哑韵/细微级 | 乜斜、灰堆、姑苏、一七——口形小、情绪细腻 |
| 宽韵/窄韵 | 按同辙汉字多少分；宽韵易写（江阳/中东/言前…），窄韵难写（乜斜/梭坡…） |
| 开口音/闭口音 | 发音口形大/小；开口音拖腔响亮、配长音高音 |
| 节奏 | 字词句段组合的长短轻重变化，歌词音乐性的支柱 |
| 音节 | 节奏的基本单位；汉语双音节词前重后轻 |
| 合辙押韵 | 见“押韵”；辙与韵同义 |

## 技法类

| 术语 | 含义 |
|---|---|
| 直叙（赋） | 开门见山直接叙述，不加修饰（“赋比兴”之赋） |
| 比喻 | 打比方：本体+喻体+比喻词，化抽象为形象 |
| 比拟 | 转化：拟人/拟物/形象法 |
| 反复（重复） | 有意重复词句强调情感——副歌的本质武器 |
| 衬词 | 感叹词/语气词/唱名/象声词，有音无义表情丰富（如“呼儿嗨哟”） |
| 顶真 | 上句末字=下句首字，环环相扣（连珠） |
| 通感（移觉） | 五官感觉互通 |
| 物候 | 借草木荣枯、鸟虫鸣叫、气象变化表时间情感 |
| 括连 | 把用于甲物的词移用于乙物（甲+乙→甲+丙） |
| 双关 | 表面一义暗含一义 |
| 起兴 | 先言他物营造氛围再引出正题（“赋比兴”之兴） |
| 填词 | 为现成旋律/曲谱写词（词曲感情风格一致、按节拍字数） |
| 和乐 | 歌词定稿后与旋律结合的过程 |
| 唱着写 | 边哼旋律边写词，拗口当场改；检验歌词的终极手段 |
| 增删改调 | 修改四法：增补/删除/改写/调整 |

## 体裁与运作类

| 术语 | 含义 |
|---|---|
| 通俗歌词 | 流行歌曲的词：口语化、易传唱、有记忆点 |
| 艺术歌词 | 美声/民族唱法：讲究艺术性，可成教材与保留曲目 |
| 影视歌词 | 主题歌/插曲：紧扣剧情画面人物 |
| 行业歌词 | 厂歌/校歌/司歌：体现行业精神、易集体唱 |
| 广告歌词 | 商业歌曲：针对宣传对象量体裁衣、一句入脑 |
| 儿童歌词 | 寓教于乐、童趣、语言浅显形象 |
| 摇滚歌词 | 直面现实困惑、直接坦率地表达宣泄 |
| 受众群 | 按年龄/地域/职业划分的音乐消费群体，先定受众再动笔 |
| 版权 | 词作者对歌词的署名、修改、使用权与获酬权（受著作权法保护） |
