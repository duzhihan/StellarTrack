# 前端守门规则（C1–C3 补门 · v12.5.1）

> **来源**：MarxSphere 实证层拆解教训——取材料段决定上限（检索质量 0.795 vs 答案质量 0.985；失败归因 80% 在 retrieval/context）。星躔守门原全压写后（C7–C11），C1 选题 / C2 材料 / C3 综述全段无门，与对方同构缺陷。本轮补 C1–C3 前端门，把材料可信度与覆盖度提到进场前校验。
> **设计原则（用户拍板）**：可证伪门非一刀切——**C2 材料门硬（不过不进下道）、C3 综述门软（计入评分但放行）、C1 选题门软（标注不阻塞）**。门要可校准才敢设硬（见 §五 校准前提）。
> **性质**：升级既有守门③/④/⑤，非新建守门编号；正文判据见 SKILL.md 对应 C 工序，本文件给可操作细则。

---

## 一、C2 材料门（硬阻塞 · 升级守门④）

> 守门④现有两检：① 引擎来源披露 ② 判断句-证据覆盖率 ≥80%。本轮增三检，且①保持、②升底线。

### 1.1 来源类型分级白名单（硬）

每条入表材料（总成卡/账本）须标“来源分级”字段，二档：

| 分级 | 可作 | 包含 |
|---|---|---|
| **一级（承重证据）** | 独立支撑任一承重主张 | 同行评议期刊论文（CSSCI/核心/普通学报）／学位论文（博硕）／官方文件与统计（政府公报·统计年鉴·白皮书·标准）／一手档案（合规采集的访谈·问卷原始数据·档案原件）／权威机构署名报告（研究院·智库·国际组织署名报告，非媒体转述） |
| **二级（辅助证据）** | 须与一级交叉印证，不可单独承重 | 会议论文摘要集／书评／媒体深度报道／未署名网络资料／自媒体／商业机构营销材料／百科类 |

**硬判据**：
- 任一承重主张（判断句 / 缺口卡承重席 / 装配核对表主张句）若**仅由二级来源支撑** → **不放行**，须补一级来源；
- 二级来源占入表材料比例 **>50%** → 显式标注“证据基础偏软”并降级（不可作为 C5 引用内容卡承重证据）；
- 账本模板增“来源分级”列，缺标 → 守门④不放行。

### 1.2 证据冲突处理（硬）

同命题出现相反结论的，须**并列登记不吞**，标注“作者采纳哪条 ＋ 理由”；**未并列即吞掉反例 → 不放行**。冲突登记格式见接口件契约 C2 总成卡“提醒区”。

### 1.3 核心文献覆盖度下限（硬 · 升底线）

- 判断句-证据覆盖率 ≥80%（沿用）；
- 选题卡列出的**每个核心概念 / 理论锚点**须各有 **≥2 篇一级来源**支撑文献；
- 缺口成立所需证据链 **≥2 条可回指 asset_id**（沿用缺口卡要求）。

### 1.4 降级标注传承

C2 产物因降级检索（WebSearch/用户粘贴）来源不足时，须连带标注“降级检索·来源 X”——一级/二级分级在此基础上再判定，不互相抵消。

## 二、C3 综述门（软警告 · 升级守门⑤）

> 守门⑤现有：承重席全覆盖 / 强缺口表述 / 故事主线卡经用户择优留痕 / 四功能齐备 / 评分维度库打分留痕。本轮增薄弱综述段识别，软处理。

### 2.1 命题张力自检（借对方 S36–S45 简化）

对每段综述问——这段是在对话还是在罗列？识别三类薄弱段：

| 类型 | 判据 | 改进提示 |
|---|---|---|
| 前提未反思 | 直接采用某理论/数据而未说明其成立条件 | 补“该理论适用的边界条件”一句 |
| 无跨学科联结 | 同领域堆砌、无跨域对话 | 补一条相邻学科的对照视角 |
| 纯罗列无对话 | 作者未对文献间分歧表态 | 显式写“甲主张 X、乙主张 Y，本文取 X 因 Z” |

### 2.2 软判据

- 须在产物标注“薄弱综述段 ×N”并附改进提示（N＝命中的段数）；
- 计入评分维度库“内容质量”扣分（命中一段 ≤−1 分，封顶扣至 5），**但不阻塞放行**；
- 放行形态＝**条件通过**：挂起项列出薄弱段，清零前不得进入下游两道工序（C4/C5）——与评分维度库判定线 5.0–6.9 一致。

## 三、C1 选题门（软警告 · 升级守门③）

> 守门③现有：⑤选题确认已由用户拍板 ＋ 定题评测通过。本轮增可证伪性检查，软处理。

### 3.1 可证伪性检查（软）

选题的判断句须能设想**至少一个反例 / 边界条件**（否则为描述性选题，非论证性选题）。

- 软判据：标注“可证伪性弱：描述性选题”但**不阻塞**（因 S 层已做对抗 S3，论证骨架已立）；
- **例外升级**：若 S 层对抗 S3 未排除不可证伪（判断句本身不可设想反例）→ 升级为 C1 硬问题，回 S2 重写，不进 C2。

---

## 四、与生效性判据的关系

C1–C3 三道门同样适用 §五 运行纪律⑥ 生效性三问——尤须答（a）作用计数：本轮实际新增/剔除材料几条；（c）工具实证：覆盖率/分级占比须附 grep/账本实测数字，禁转述。

---

## 五、校准前提（与 B 项联动）

C2 硬门敢设，前提是评分维度库锚点表＋kappa 已用标尺稿验证（v2.0 铁律）。**首次实战须先跑校准**（造 3–5 篇标尺稿、你与我背靠背评分、confirm 分差 ≤1、kappa 真实 ≥0.7 非饱和），方可把 C2 硬门用于正式稿。校准未做前，C2 硬门仅作提示性检查运行，不强制阻断——防用未标定的尺子量长度。

---

## 六、回退矩阵衔接

C2/C3 硬门或软门挂起未清零即进下游 → 依 C9 回退矩阵：证据不足回 C2、综述缺口不成立回 C3。材料门卡住的稿，问题在 C2 而非 C9 评审——把校验前移正是本补门的目的。
