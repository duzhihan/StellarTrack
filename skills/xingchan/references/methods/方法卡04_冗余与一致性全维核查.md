# 方法卡 04｜冗余与一致性全维核查

> 适用：长篇稿件（论文／报告／书稿）交付前的“去冗”与“改动后对账”。
> 首次实战：2026-09-13 广西哲社结项报告（`C11_out.docx`，正文 675 段／汉字 93,438）。
> 脚本族：`Desktop/结项/_tools/c114`–`c122`（只读，不改稿）。

## 一、两条铁律（不守则结论全废）

### 铁律 1｜先划定正文范围，再谈冗余
目录（TOC）区的段落是**章节标题的副本**，若不剔除，13 字滑窗会在目录与正文之间产生成百上千个假重复。首次实测：未剔除目录时得 1196 个重复窗簇；剔除后降至 **141 个**。

**做法**：先定位目录标题段（末位为 `目录` 的 style=3 段）与正文首段（`前言` 一级标题），把区间整段排除。宁多排一段，不可漏。

### 铁律 2｜任何“改动后”核验，先做账目平衡
母本被本地编辑器（Word／WPS）保存后，**段数、部件数、脚注 id、图片编号、嵌入字体都可能变**。不要凭旧指纹判断，先用平衡式对账：

```
现存段数 = 改动前段数 − 删除块段数 − 其他删除块段数
```

实测例：`1796 − 930（附录B）− 29（重复封面块）= 837` ✓ 分毫不差 → 证明**无意外丢失**。

再叠加**逐章汉字数比对**（按一级标题切段计汉字）：各章 `+0` 即为零丢失。这一步比总字数更硬——总字数相同也可能发生“此处删、彼处加”。

## 二、六维扫描口径

| 维度 | 判据 | 阈值（经验值） | 常见误报 |
|---|---|---|---|
| 字符级 | 相邻同字 `([\u4e00-\u9fff])\1` | 白名单外的 ≥2 连字 | 专名、引文原话、量词叠用（一个个／一套套） |
| 词级 | 套话与虚词频次 | “这一”>1.4/千字、“进行”>0.8/千字 | 术语不可减（机制／结构／生态） |
| 句级·查重 | 13 字滑窗 | 跨段重复窗 | 术语名、政策全称、摘要↔正文回指 |
| 句级·相似 | difflib，≥30 字句，比值 ≥0.65 | 命中即真问题 | 无 |
| 段级 | difflib，≥70 字段，比值 ≥0.50 | 命中即真问题 | 无 |
| 内容级 | 核心概念／论断的段分布 | 看是否越界集中 | 概念高频属必要 |
| 句式 | 翻案腔（不是…而是）、相邻段首相同、连续 3 段同构 | 相邻段首相同 ≥1 即为问题 | 历时铺陈（“2010年／2011年／…”）属必要同构 |

### 滑窗自重叠必须合并
一段文字内部会与自己重叠（同一窗在两三个相邻位置重复），直接统计会虚增数倍。**做法**：把同一窗的所有位置按“间隔 < 窗长”聚类，**簇数 ≥2 才算真实重复**。

```python
def clusters(ps, WIN):
    ps = sorted(ps); g = [[ps[0]]]
    for x in ps[1:]:
        (g[-1].append(x) if x - g[-1][-1] < WIN else g.append([x]))
    return [x[0] for x in g]
```

## 三、三栏分诊（强制）

机械正则在中文学术语料上**误报率极高**，直接上报会造成虚假工作量。任何自动扫描结果一律三栏：

1. **真问题**——附段号 + 原文片段 + 建议改法（最小改动）；
2. **误报**——写明误报类型与理由（专名表／引文原话／统计术语／量词叠用）；
3. **待裁**——语义级判断交作者定（如是否换例、是否拆长句）。

实测参考：字符级 77 处命中，**真问题仅 7 处**（其余为咚咚锵、胡彬彬、慕容晓晓、戏曲多多、桄桄、陌陌、小潘潘等专名，及“底妆好好下下功夫”等引文原话）。

## 四、改动后完整性核验清单（8 项）

| # | 检查 | 判据 |
|---|---|---|
| 1 | 段数与账目平衡 | 见铁律 2 |
| 2 | 图 ↔ 图题注 | `a:blip r:embed` 数 = `^图\d+-\d+` 题注数 |
| 3 | 表 ↔ 表题注 | `<w:tbl>` 数 = 题注数（**注意布局表格**：单格包图会产生 1 个无题注表） |
| 4 | 脚注闭环 | 引用 id 集合 ⊆ 条目 id 集合；悬空 = 0；空条目仅 `separator`／`continuationSeparator` 两条 |
| 5 | 嵌入字体 | 逐字体比 `w:rFonts` 引用数；**引用为 0 的字体丢失 = 正确收缩，非损害** |
| 6 | 分节符 | `sectPr` 数比对；文末无孤立分页符／空白页 |
| 7 | 部件清单 | 逐项列 `infolist()`；丢失项须能一一解释 |
| 8 | 交叉引用 | 全文搜被删对象的名称，**正文归零、目录残留须清理** |

### 交叉引用的隐藏面
删掉一个块（如附录）后，正文可能仍留“（见附录B）”这类悬空指针。**扫法**：全文搜该块名称，逐条看是否为目录条目（style=59/74）——目录条目由 `Ctrl+A → F9` 重建时自动清理，正文悬空则必须改写。

## 五、常用片段

```python
# 段落正则：自闭合分支必须在前（否则 <w:p/> 被吞，段号整体 −1）
P_RE = re.compile(r'<w:p\b[^>]*/>|<w:p\b[^>]*>.*?</w:p>', re.S)
# 提取 <w:t> 必须容忍属性
T_RE = re.compile(r'<w:t(?:\s[^>]*)?>(.*?)</w:t>', re.S)
# 实体内联反转义
for a, b in (('&amp;', '&'), ('&lt;', '<'), ('&gt;', '>'), ('&quot;', '"')): t = t.replace(a, b)
```

**输出控制**：长扫描一律先 `io.open(out,'w',encoding='utf-8').write()` 落盘，再分段 Read；直接打印会被截断且中文可能乱码。

## 六、批次落改纪律（沿用方法卡 03）

备份 → 基线指纹断言 → 段号／锚串双定位 → “段文本=预期串”断言 → 13 字滑窗（仅新增窗）→ 违禁串复扫 → 结构不变量（段／引用／表／部件）→ 序列对齐逐段核验 → 出对照表。
**改节标题时须同步改目录同名条目**，否则目录与正文不符。
