# 方法卡 02 ｜题目·摘要·关键词定稿（艺术学范式）

| 字段 | 内容 |
|---|---|
| **名称** | 题目·摘要·关键词三件套定稿法（艺术学范式） |
| **适用范式** | 思辨／阐释为主的艺术学、传播学、文化研究；实证轨可借用摘要骨架与关键词三环，题目句式慎用断言式 |
| **适用工序** | C1 定题（题目七句式选型）、C8 合卷（摘要六段拼装＋关键词配比）、C11 精校（三件套终检） |
| **核心流程要点** | ① 定题：从七大句式选型（从X到Y／自铸概念冒号副题／张力对举／引号概念起手／动宾断言），副题用钉子句式把对象钉死；概念铸造优先走六种构词法（X化／X性／类X准X超X／隐喻嫁接／对生概念／数序装配），并对照第九节选题热力图评估赛道拥挤度；② 摘要：按六段骨架拼装——背景张力→对象追问→理论材料→发现展开(40%)→概念落点→收束升格，250～450 字；首句五开法选型，“然而”转折前置，动词按强度表选档，实证稿发现段必须带硬数字；③ 关键词：三环配比（自铸概念1-2＋对象1-2＋理论锚点1-2），3～5 个分号降序；④ 理论锚点 ≤3 组且必须参与论证（第十节工具箱按论题域取用）；⑤ 终检跑模板库第四节自检清单＋第五节反面清单 |
| **自检清单** | 题目有理论动作且副题钉死对象？摘要概念落点段存在？发现展开用分层列举/机制链？关键词三环齐备不超 5 个？无“综上所述”类套话？ |
| **来源日期** | 2026-08-25 蒸馏自北大艺术学国际博士生论坛五分论坛约 75 篇论文样本（戏剧/电影/文化产业/艺术理论/计算艺术）；全量规律见 `references/题目摘要关键词模板库_艺术学.md` |
