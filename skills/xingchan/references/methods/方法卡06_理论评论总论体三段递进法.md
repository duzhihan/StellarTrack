# 方法卡 06｜理论评论·总论体三段递进法

> 适用：文艺理论评论／总论类稿件（《光明日报》理论版、《中国社会科学文摘》转载体、评论刊物与报纸理论版）。
> 实测样本：《光明日报》2026-05-27 新大众文艺总论（3,122 字／17 段／62 句，2026-09-16 全文实测）。
> 与学术论文的关系：**学其骨架与段落构造，不学其句子与密度**——四处边界见文末。

## 二、骨架：条件 → 机制 → 意义

总论不按“现象—原因—对策”走（那是工作研究写法），而按三层递进，配比约 **36 : 29 : 29**：

| 节 | 承载 | 内容 |
|---|---|---|
| 一 | **外部条件** | 历史溯源＋技术／媒介／平台／制度等发生条件（首节略重，因含溯源） |
| 二 | **内部机制** | 主体／方式／体验／关系等运转维度（用短路标句切并列小节） |
| 三 | **意义后果** | 价值内涵＋生态判断＋时代定位 |

## 三、四套构造动作

### 动作 1｜节标题统一格式
**“研究对象前缀 ＋ 〔A〕与〔B〕”**：三节同前缀形成复沓节奏；A、B 均为四字／六字对仗短语；A、B 之间由外到内（语境→特征、重塑→体验）。

### 动作 2｜段首观点承载率 100%
- **判断句开路**（约 82%）：“媒介融合推动了……的发展。”“互联网和各种传播媒介为……提供了……”
- **短路标句**（约 18%，用于并列小节群）：“形成新的叙事方式。”“带来新的体验效果。”“重塑……关系。”——动词短语独立成句。
- **连接词开段 = 0**：首先／其次、第一／第二、综上所述、值得注意的是、换言之一律不出现；靠并列连词＋复沓主题词＋同构段首衔接。

### 动作 3｜历史溯源定位（开篇必用）
把新现象接进“**同一个问题的历史形态**”谱系（问题同一才有谱系意义），一句“与以往相比具有特殊的发生语境”完成合法性论证。

### 动作 4｜辩证三步（处理敏感面）
“尽管……（承认问题）→ 但客观上……（转折化解）→ 更主要的是……（提升到主流方向）”。不回避、不辩驳、不停留。

**辅助**：全文只引一处权威源，且仅用于**概念授权**（给核心概念下定义）；引号只作术语自标，不堆他人原话。

## 四、自检清单（交付前逐项核）

- [ ] 三节是否同前缀＋“〔A〕与〔B〕”对仗并列？
- [ ] 每段是否观点开路（判断句或短路标），连接词开段为 0？
- [ ] 序号词／总结语／模糊引导词是否全为 0？
- [ ] “不是X而是Y”家族 ≤3 处（克制典范为 3，红线 8）？
- [ ] 段落是否均匀（平均 150–200 字，无超长段）？
- [ ] 溯源三波是否“问题同一”？
- [ ] 敏感面是否走了辩证三步？

## 五、四处边界（不可带进学术论文）

| 项 | 评论体做法 | 论文中为何不能学 |
|---|---|---|
| 句长 | 平均约 50 字，短句占比低 | 与“句子密集短促”偏好相逆；CSSCI 对超长句容忍度低 |
| 术语密度 | 主题词每 35 字复现一次 | 论文会被批词汇贫乏 |
| 引证 | 零脚注、仅一处外部文献 | 论文须回源可核 |
| 个案 | 全篇不下沉 | 论文需个案支撑与可检验性 |

**它未展开处＝选题入场理由**：总论通常“价值共创不拆机制、类别不做分化、主体不讲分层”——垂直切口（机制／类别／分层）即论文的差异化空间。
