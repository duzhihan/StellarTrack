# 方法卡 07 ｜跨语言术语表工程（中英锁定·一致性终检）

| 字段 | 内容 |
|---|---|
| **名称** | 跨语言术语表工程（中英锁定 → 全篇一致性终检） |
| **适用范式** | 学术／传播／规范全档 × 含英文输出的稿件（题目/摘要/关键词英译、全稿中译英、英文写作） |
| **适用工序** | C1（定题后锁定英译题目）、C2（建档建表）、C6（撰写随用随录）、C8（引文/术语核对）、C11（终检必跑全篇检索） |
| **核心流程要点** | ① **通读全文抽取**核心概念、人名、作品名、机构名，中英锁定后全篇统一；② **专有名词以官方英文名为准逐一查证**（艺术家官网/机构收藏页/政府文件），不确定标注询问**不猜**——例：黄炳＝Wong Ping（绝非拼音 Huang Bing）；劏房＝subdivided unit（港府官方英文）；③ 理论概念沿用**领域通行译法**——例：私密叙事＝intimate narrative、挪用＝appropriation、规训＝discipline；④ 术语表在翻译/写作过程中**持续维护**，新术语随时补录；⑤ **交付前按术语表逐项检索全篇**，确认译法统一（机翻味最大来源，必查） |
| **自检清单** | 术语表先于成稿存在？专有名词有官方出处（未猜）？全篇检索零译法冲突？题目/摘要/关键词中英锁定一致？ |
| **来源日期** | 2026-10-15 蒸馏自 wave2234/paper-cn-to-en（MIT）＋衔接方法卡02 三件套定稿 |

> 加载时机：含英文输出的稿件 **C1 定题后即建表**；C11 终检必跑全篇检索。与本卡配套：方法卡08（词数预算分配法）。
