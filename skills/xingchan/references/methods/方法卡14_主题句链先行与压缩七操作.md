# 方法卡 14 ｜主题句链先行与压缩七操作

| 字段 | 内容 |
|---|---|
| **名称** | 主题句链先行（写前查连贯）＋压缩七操作（投稿前收紧） |
| **适用范式** | 学术档全轨；传播/规范档长文可借用压缩操作 |
| **适用工序** | C6 正式撰写（主题句链先行）＋C11 最终精校/投稿前（压缩七操作） |
| **核心流程要点** | **主题句链先行**：C6 展开正文前，先写全稿每段主题句（判断句，一段一句），**连读成链检查论证连贯**——上一段主题句能否推出下一段主题句？链断处先修链再写正文（防“段内漂亮、段间断裂”）。**压缩七操作（投稿前按序执行，30-50% 为常态目标）**：① **句缩短**——删从句/冗余限定/清嗓句，每词须挣得位置；② **段合并**——同点异例段落并为一段取最强例（多例稀释不如一例精准）；③ **删空泛形容词**——显著/重大/深刻/全面等换具体数字或删除；④ **删教程式解释**——受众已知的概念定义不进正文（除非重定义即贡献）；⑤ **声明式标题与段首**——标题/段首承载该节结论而非话题（“实验设置”→“系统 X 全面超越基线 2-4 倍”）；⑥ **结果节 Takeaway 段**——多段逐条件数字压成 3 段分组 + 1 段综合（读者要模式不要每个数字）；⑦ **数字比较入表**——逐数字罗列移入图表，正文只解读模式。**压缩强度表**：10-20% 微调已近终稿；30-50% 常态（作者已知孰重孰轻）；50-65% 危机压缩（叙事框架变，非文字啰嗦）；>65% 预示结构性重写 |
| **自检清单** | 主题句链连读论证连贯？七操作逐项执行？空泛形容词清零？声明式标题在场？Takeaway 段在场？压缩强度落在常态档？ |
