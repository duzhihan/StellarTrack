# 方法卡 09 ｜综述类型判定四问

| 字段 | 内容 |
|---|---|
| **名称** | 综述类型判定四问（先定类型，再定严谨度） |
| **适用范式** | 学术档全轨（实证轨/理论轨通用）；传播/规范档综述节可借用类型轴 |
| **适用工序** | C3 第 1 步（确定模式前先定类型，与 M1/M2 篇幅轴正交） |
| **核心流程要点** | C3 开场先答四问定综述类型：① 系统型——答“干预是否有效”（需检索留痕＋证据分级）；② 整合型——答“概念在多范式文献中长什么样”（评而不剔，注明每源贡献）；③ 批判型——要产出假说或模型（以论证推进组织文献）；④ 范围型——答“领域里已有什么”（边界扫描）。**类型定严谨度**：系统/整合型须配检索留痕三行与证据强度标注；批判/范围型须配逐源批判性七问。类型与篇幅（M1 嵌入式/M2 完整式）独立，可交叉 |
| **自检清单** | 四问已答？类型与严谨度匹配？检索留痕（M2）或逐源七问（批判型）在场？ |
| **来源日期** | 2026-10-15 蒸馏自 Grant & Booth (2009) A typology of reviews（Wiley）+ PRISMA 2020 留痕思想；用户拍板落盘 |

> 加载时机：C3 开工首步。类型错配是综述肤浅的总根源——先答四问再动手。
