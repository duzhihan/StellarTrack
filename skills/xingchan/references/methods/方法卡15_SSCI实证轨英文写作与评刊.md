# 方法卡 15 ｜SSCI 实证轨英文写作与评刊（社会科学）

| 字段 | 内容 |
|---|---|
| **名称** | SSCI 实证轨英文写作与评刊法（社会科学） |
| **适用范式** | 实证轨（问卷／内容分析／实验法），英文期刊投稿 |
| **适用工序** | C1 选题（评刊四查）、C3/C6 撰写（英文轨，与方法卡01 互补）、C8 合卷（APA 结果报告）、C11 终校（投稿自检清单） |
| **核心流程要点** | ① **评刊四查**：真伪核实（查 JCR/SSCI 官方列表，防“伪 SSCI”冒名）、分区三套读法（JCR 四分位／中科院分区／ESI，不混读）、预警与 ESCI 辨析（**ESCI 不等于 SSCI**；水刊避坑看自引率与发文量）、desk reject 判据预判（**编辑判稿先看话题再看结构**——缺具体研究问题即退；中文 C 刊“描述现象＋提建议”体在 SSCI 不被认可）；② **Intro 五段逻辑**：大背景→小领域→缺口→目的→价值；**现在完成时**句型（“Recent work has shown that…”），研究缺口三写法（文献未答／未解／未验证）；目的段转一般现在时；③ **文献综述“每段朝假设走”**：每句文献都朝 H1/H0 铺路，脱节是学生稿典型毛病；假设**五种类型**（差异／相关／中介／调节／交互）先于写作选型；④ **方法与问题 match 四问**：问卷问态度、内容分析处理文本、实验靠对照组——选错即答非所问；操纵性检验放方法节不放结果节；⑤ **results 只报关系，原因留给 discussion**（两者混写最常见失误）；APA 报告格式（描述统计 M=, SD=；相关 r( df )=, p=；T 检验 t( df )=, p=；ANOVA F( df1,df2 )=, p=）；⑥ **投稿前自检清单**：否定量词与真实文献量对得上（“大量研究”需可数文献数支撑）、引用不改原作者本意、摘要五要素齐、无 desk reject 硬伤 |
| **自检清单** | 评刊四查过？Intro 五段＋时态对？假设类型先定？方法与问题 match？results/discussion 分界清？APA 格式对？自检清单过？ |
