# 方法卡 16 ｜散碎材料四步整合法（笔记/草稿/摘录 → 完整论文）

| 字段 | 内容 |
|---|---|
| **名称** | 散碎材料四步整合法 |
| **适用范式** | 全范式（人文社科尤其适用——材料来自读书笔记/草稿/摘录/田野记录等碎片时） |
| **适用工序** | O2 素材拼装前置、C2 材料建档、C3-C5 正文构建（材料已有多份碎片时启用）；与“方法卡05 选题生成”三轮收敛协议衔接 |
| **核心流程要点** | ① **材料清点**：逐份读完全部材料，生成**材料清单**（材料编号/来源文件/类型/核心内容/可用于章节/问题），逐份问三问——这段有没有可直接用的论点？这段引文属于哪个论证环节？这段草稿的问题在哪（描述性？逻辑断裂？理论脱节？）；② **论证线索提取**：从碎片中提取可论证的核心观察，**不是所有材料都要用**——筛掉重复/偏题/无分析潜力的；保留材料按论证功能排列（支撑论点A/支撑论点B/反例与张力/背景备用）；③ **结构重组**：按提取的论证线索设计递进式结构，材料分配到章节，**标注每章还缺什么**——缺细读（有引文无分析）／缺理论接应（有分析无理论提升）／缺过渡（章内或章间逻辑连接）／缺收束（章节结尾未收拢论点）；④ **缝合与补写**：按章节顺序把材料缝合成连贯文本——**语气统一**（不同时期草稿语气不一，统一为中等正式学术书面语）、**逻辑连接**（材料间补过渡句，说明“为什么从这里到那里”）、**分析补充**（对只有引文无分析处补“这意味着什么”） |
| **自检清单** | 材料清单生成？筛掉的材料有理由？每章缺口已标注？语气统一？无拼贴感（每段过渡说明因果）？详略以论证需要而非熟悉度分配？ |
| **整合四陷阱** | 舍不得删（笔记全塞进论文→与核心论点无关果断舍弃）｜拼贴感（材料间无论证串联→每段加过渡）｜详略失衡（熟悉的写过细→以论证需要分配篇幅）｜语气不统一（口语与过度学术混用→统一中等正式） |
