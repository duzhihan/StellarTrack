> **定位（一句话）**：本卡是 **C1 开工路由卡**——第一问定轨别（轨 A 研学智得全流程／轨 B 免费替代管线），第二查权益边界（会员档位决定可用节点），第三按轨映射工具源，保证“**普通用户不因会员墙降质，机构用户不重复造轮子**”。
> **与四支柱关系**：路由只解决“用什么工具”，质量把关仍由方法卡18 四支柱关卡完成（P1 权威性／P2 可行性／P3 方法适配／P4 聚焦性）。

## 一、路由判定（C1 开工首步 · 一句话问身份）

```
询问/判定用户身份（一句话，不追问两轮以上）：
├─ 在校研究生 或 可关联机构知网会员（IP 自动关联/口令/机构账号）
│   → 轨 A：研学智得全流程（研究态势＋AI 选题推荐＋定题评测＋标题打磨全可用）
└─ 普通用户（无机构权益）
    → 轨 B：研究态势分析（免费）＋本地替代管线（方法卡05→17→18）
规则：
  · 不确定 → 默认轨 B（零门槛可跑，不卡流程）
  · 中途开通机构权益 → 升轨 A，从当前节点续接，不重跑已过节点
  · 轨 A 额度耗尽/页面不可用 → 降轨 B，从当前节点续接
轨别＋权益依据写入选题卡（字段：轨别 A/B＋权益依据一句话）
```

## 六、升降轨规则（不重跑已过节点）

1. **升轨 A**：机构权益开通/登录 → 声明“升轨 A”，从当前节点换工具源续接；
2. **降轨 B**：研学智得不可用/额度耗尽 → 声明“降轨 B·原因X”，当前节点换轨 B 工具续接；
3. **切换留痕**：选题卡记录轨别变更（原轨→新轨→原因），C1 总成卡同步；
4. **禁止**：轨 A 阶段产物直接冒充轨 B 产物（如会员期 AI 评测结果在降轨后继续当免费结论用——须标注来源轨别）。
