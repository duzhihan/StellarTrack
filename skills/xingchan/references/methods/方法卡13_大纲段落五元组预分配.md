# 方法卡 13 ｜大纲段落五元组预分配

| 字段 | 内容 |
|---|---|
| **名称** | 大纲段落五元组预分配（extended outline） |
| **适用范式** | 学术档全轨（实证/理论通用）；长篇综述、学位论文章节尤佳 |
| **适用工序** | C4 大纲协商（与素材分配表并行产出——素材分配表管“哪段装什么素材”，五元组管“每段论证角色”） |
| **核心流程要点** | 大纲阶段给**每个规划段落**预分配五元组：① **读者功能**——读者读完这段得到什么（立论/证据/反驳/边界/过渡）；② **承重主张**——本段可辩护的 claim（判断句，一段一主张）；③ **授权证据**——允许使用的账本条目（未授权证据不得入段）；④ **推理边界**——能推出什么、不能推出什么（防越界断言）；⑤ **过渡桥**——与前段/后段的衔接关系（显式承接）。五元组先行，正文写作（方法卡11 五步）只负责“把五元组兑现成段落”。**nonclaims 预登记**：大纲同时登记本文明确不主张什么（架构期登记，写作期不再防御性声明——与 anti-defensive 作者姿态联动） |
| **自检清单** | 每段五元组齐备？承重主张=判断句？授权证据可回指账本？推理边界显式？过渡桥成链？nonclaims 已登记？ |
