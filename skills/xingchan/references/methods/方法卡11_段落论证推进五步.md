# 方法卡 11 ｜段落论证推进五步

| 字段 | 内容 |
|---|---|
| **名称** | 段落论证推进五步（段落级装配＋自明性验收） |
| **适用范式** | 学术档全轨；传播/规范档长段落可借用 |
| **适用工序** | C5 块状粗稿装配核对表（升级第 2 步）＋C6 定稿逐段自检 |
| **核心流程要点** | 每段按五步推进：① **主题句＝判断句**（立论，非话题宣告；禁“本文/笔者”开头）→ ② **证据到位**（≥1 条可回指账本条目）→ ③ **分析步＝warrant 外化**（证据意味着什么、为什么支持此论断——**消灭“论断悬空、要读者脑补”的自明性缺陷**；后 2 句内必须出现推理连接词：因为/由于/这意味着/这表明/换言之/即）→ ④ **回扣本段论点**（首尾呼应，不跑题）→ ⑤ **过渡递交下段**（承接关系显式）。**每段验收五问**：主题句是判断不是宣告？证据可回指？warrant 在场（后 2 句内）？段末回扣？过渡显式？五问任一不过即回改 |
| **自检清单** | 五步齐全？五问全过？无“论断悬空”段（抽 3 个承重段核 warrant）？ |
| **来源日期** | 2026-10-15 蒸馏自 Purdue OWL Body Paragraphs TTEB 四要素＋Toulmin 六格（SJSU/Purdue 讲义）＋中文段落六问；用户拍板落盘 |

> 加载时机：C5 装配时按五步核对，C6 每节写完按五问自检。与词法区 L3-1 正向句式库配合。
