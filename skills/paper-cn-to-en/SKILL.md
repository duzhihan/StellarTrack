# 中文人文论文 → 地道学术英文

适用于艺术史、视觉文化、策展研究、文化研究等人文社科论文的中译英。这不是SCI理工翻译：要保留论证的声音、句法的节奏感和领域术语的精确性，产出读起来像英文母语者写的学术散文，而不是逐词对应的译文。

## 流程

### 1. 开工前确认三件事（对话中已知则跳过，不重复问）
- 目标词数上限（如全文5000词），以及本次翻译的是全文还是某部分
- 是否有英文范文可锚定风格：该领域期刊文章、或论文参考文献里的英文文献（访谈、展评尤佳）
- 引用格式（APA/Chicago/MLA），以及标题、小节标题是否已有定稿译法——已有则沿用，不另起炉灶

### 2. 建术语表
通读全文，抽取核心概念、人名、作品名、机构名，中英锁定后全篇统一。规则：
- 专有名词以官方英文名为准，逐一查证（艺术家官网、机构收藏页、政府文件），不确定不要猜。例：黄炳 = Wong Ping（绝非拼音Huang Bing）；劏房 = subdivided unit（港府官方英文）
- 理论概念沿用该领域通行译法。例：私密叙事 = intimate narrative；挪用 = appropriation；规训 = discipline
- 术语表在翻译过程中持续维护，新术语随时补录

### 3. 词数预算
- 统计中文各节字数，按占比给英文各节分配词数预算
- 经验比率：紧凑压缩翻译约 3:1（3个汉字≈1英文词），常规密度约 1.7:1
- 每翻完一大块，写入文件用 `wc -w` 实测核对（不要口算），超预算立即收紧下一节；向用户汇报时给实测数字和全文预估

### 4. 翻译原则
- **直接生成地道英文，严禁先直译再修**——直译稿会锚定句子骨架，改出来的成品仍是中文语序
- 以段落为单位重组句子逻辑，不逐句对应；中文的"因此/这种/也/与此同时"回环连接链在英文里合并或删除
- 句子长短交错制造节奏，避免每句等长的列队感
- 论证声音可以在场（This essay reads... / The point is not X but Y），但避免口语化
- 禁用：Moreover / Furthermore / Additionally 开头连发；utilize；delve into；it is worth noting that
- 领域术语放心使用：gaze、discipline、allegory、oblique critique 等是人文写作的正常词汇，不因"生僻"降级为大白话
- 压缩时砍的是冗余连接词和重复修饰，论点、引用、数据一个不动，不添加原文没有的内容

### 5. 引文与引用
- 原文中已是英文的直接引语（艺术家原话、机构声明）原样保留，一字不改
- 括号内文献引用（作者, 年份, 页码）格式照搬，不翻译不改动
- 数据（面积、人数、年份）逐项与原文核对

### 6. 交付前检查
- 按术语表逐项检索全篇，确认译法统一（这是机翻味的最大来源，必查）
- 报告实测总词数 vs 预算
- 除非用户只要文本，成品用 docx skill 生成 Word 文件交付；分次翻译则维护同一个文件累积追加

## 忌
- 不切块并行翻译（多个子任务各翻一段会导致术语和文脉断裂）
- 不逐段孤立处理后简单拼接（前后术语打架）
- 不套SCI理工文风规范（短句化、去术语化）于人文写作
