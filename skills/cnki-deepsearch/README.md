# cnki-deepsearch

替代体验糟糕的知网内置检索：调用**本机有头浏览器**上知网，让用户亲自登录 / 走校外访问拿到全文权限，再用"三层渐进式关键词发现 + 逐篇关联判定"做可复核的中文学术检索，并自主判断何时只取详情页、何时必须下载 PDF 解析正文。

> 核心理念：**检索的终点是可分析的全文，而不是题录。** 无头方式拿不到登录 / 校外访问权限，所以默认用有头浏览器——用户看得见界面，AI 才能一条线做完：搜索 → 正文 → 下载 PDF → 分析。

## 为什么需要这个

- 知网内置检索与"AI 助手"经常返回不准、无法核验、看不到原文；
- 纯 HTTP / WebFetch / 无头浏览器**无法让用户手动登录或走校外访问**，拿不到全文下载权限；
- 本技能用本机有头浏览器（Chrome 等）填补这个缺口：界面可见、登录可控、全文可下。

## 特性

- **环境自适应**：自动识别当前 AI 宿主（Trae / Codex / HanaAgent / WorkBuddy 等）能用的浏览器能力；已有有头工具或 MCP 直接用，默认无头则引导接入有头浏览器 MCP。
- **调用即引导**：技能被调用后主动带用户完成配置（约一分钟），不干等。
- **三层渐进式发现**：概念树 → 单层宽检 → 进重点论文读摘要 / 目录 / 参考文献发现新词 → 回溯第三层术语与引文。
- **证据分级判定**：自主判断何时仅取详情页信息、何时必须下载 PDF 解析正文，记录 `metadata_only` → `pdf_fulltext_complete` 等证据状态。
- **学科口径控制**：保持目标学科口径，其他学科只作机制 / 背景补充。

## 快速开始

### 1. 接入有头浏览器

技能调用后会自动引导。若你的环境默认是无头方式，需要配置一个"调用本机有头浏览器"的 MCP（以 Chrome 为例，使用 chrome-devtools-mcp）：

```json
{
  "mcpServers": {
    "cnki-browser": {
      "command": "npx",
      "args": [
        "-y",
        "chrome-devtools-mcp@latest",
        "--executablePath=<本机浏览器可执行文件路径>",
        "--headless=false",
        "--userDataDir=<独立缓存目录，不要与默认浏览器或其他 MCP 共享>"
      ]
    }
  }
}
```

- `--headless=false` 必须（有头、可见）；
- `--userDataDir` 用独立目录，避免污染默认浏览器；
- 也可授权技能自动探测本机浏览器路径并写好配置。

配置细节见 [`Google Chrome MCP Config.md`](./Google%20Chrome%20MCP%20Config.md)。

### 2. 登录与检索

配置完成后，在可见浏览器中登录知网（个人账号或机构 / 校外访问），确认能打开全文，技能即开始三层检索。

## 使用流程

1. **启动引导**：开场说明 → 环境自诊（A / B / C）→ 接入引导（自动 / 手动）→ 登录引导；
2. **三层发现**：构建概念树 → 第一层宽检 → 第二层进重点论文发现新词 → 第三层回溯术语与引文；
3. **关联判定**：子词独立宽检、逐篇判定相关性、合并去重与编码、交叉验证仅查漏；
4. **全文获取决策**：背景 / 旁证只读详情页；核心代表文献、需方法 / 变量 / 机制 / 引文 / 编码对比则下载 PDF 解析；
5. **沉淀**：输出检索报告 + 本地 Markdown 档案（可选同步宿主记忆 / 知识库）。

完整的技能正文与判定规则见 [`skill.md`](./skill.md)。

## 适用环境

面向不同 AI 宿主广泛适配，不绑定某一家：

- **Trae**：通过插件直接控制本机有头浏览器的 `browser_*` 工具；
- **Codex / HanaAgent 等**：接入 `cnki-browser` MCP；
- **其他默认无头环境**：按引导接入有头浏览器 MCP 即可。

> 多数工具以 `SKILL.md` 识别技能文件，部署时可将 `skill.md` 按宿主约定重命名或放入技能目录。

## 注意事项

- 登录由用户在可见浏览器中自行完成，技能不记录账号凭据；
- 遇到滑块 / 验证码，暂停交用户手动完成，不自动破解或规避；
- 下载 PDF / 批量操作或可能产生费用前，先征求用户确认；
- 检索与综述须保持目标学科口径，其他学科文献不得主导学术史叙述。
