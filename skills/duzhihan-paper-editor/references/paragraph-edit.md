## 六、模式B：逐段修改

### 6.1 章节层级

| 层级 | 识别方式 | 暂停点 |
|------|---------|--------|
| 主要章节（一级） | 顶格的`一、二、三、`或`1. 2. 3.` | 是 |
| 次级章节（二级） | 缩进的`1.1、1.2`或`（一）（二）` | 否 |

每完成1个主要章节暂停一次，询问是否继续。

### 6.2 逐段修改核心原则

**6.2a 语义关联度决定合并/拆分**：同一小节内连续论证同一分论点的段落合并；论点转换、话题切换、层级跃迁时拆分。

**6.2b 章节标题诊断（强制）**：每进入新章节，先诊断章节标题——标题必须是论点/判断，不能只是研究对象名。输出"原文→问题→修改后→修改说明"。

**6.2c 修改透明度原则（强制）**：
- ⚠ 高风险修改（删除完整段落、改变论证方向、合并超过3段）→标注"请作者确认"
- ❓ 不确定性修改（无法判断原文意图）→标注"请作者检查"
- 全局诊断问题回应 → 标注"此处修正全局诊断问题X"

### 6.3 逐段输出格式模板

```
【修改对照全文】
【标题】：原文→问题→修改后→修改说明
---
段落组 N（原第X-Y段）
【原文】：[完整粘贴]
【原文问题】：[1-3条]
【修改后】：[整合后文本]
【修改说明】：主要问题 / 修改了什么 / 合并理由
```

### 6.4 修改总结

全文完成后输出：删除/合并统计、字数变化、全局诊断问题回应清单、新增发现。

### 6.5 作者风格保护原则

修改时必须保护以下内容：

| 保护项 | 操作原则 |
|--------|---------|
| 作者自创术语 | 不可替换为通用术语，不可改变定义 |
| 标志性句式 | 除非语法错误，否则保留 |
| 辩证性修辞（"但是""然而"） | 不可为了"流畅"而删除 |
| 长句思辨链 | 只在主谓宾混乱时才优化 |
| 设问自答 | 不可删除，除非不服务于论证推进 |
| 学术修辞个性 | 不可标准化为"通用学术腔" |

涉及以上保护项的操作，在【修改说明】中标注"⚠ 作者风格保护项：[说明]"。
