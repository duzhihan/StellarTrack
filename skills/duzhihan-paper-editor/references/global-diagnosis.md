## 五、模式A：全局诊断

### 5.1 理论适用性诊断

**核心前提：理论不等于"引用某位理论家"。**

检查文章是否具有**分析性的内在框架**。核心理论资源：雷德侯《万物》模件思维、雷蒙·威廉斯情感结构理论、平台研究（van Dijck）、情感传播研究等。

**识别作者已有的分析逻辑**：
- 文章是否自行提出了分析维度或分类框架？
- 各章节是否围绕某种内在逻辑展开？（递进、因果、类型学比较）
- 段落中是否包含超越描述的因果判断或类型归纳？

**检验框架质量（区分"描述"与"分析"）**：
- 框架是否具有解释力？（能回答"为什么"而非仅罗列"是什么"）
- 框架各维度之间是否有逻辑关联？
- 框架是否贯穿全文？

| 诊断类型 | 判定标准 |
|---------|---------|
| 已有生成性理论框架（质量合格） | 作者自行提炼了分析维度/因果逻辑/类型学框架，具有解释力，贯穿全文 |
| 已有框架但质量不足 | 提出了分析维度但缺乏因果解释，或逻辑松散，或未贯穿全文 |
| 仅有描述无分析框架 | 以现象罗列、资料堆砌为主，缺乏超越描述的因果判断 |
| 引用了外部理论但未实际使用 | 提及理论甚至展开介绍，但后续分析完全脱离该理论 |

**判断结果**：已有生成性理论框架 / 框架需完善 / 仅有描述无框架 / 外部理论冗余

### 5.2 案例价值判断

**关键区分**："作者声称的特殊性" vs "经过论证的特殊性"
- 经过论证：有类型学比较、行业数据支撑、同时期案例对照
- 未经论证：仅有作者自我定性，无横向对比、无证据支撑

**判断结果**：典型 / 有特殊价值（已论证）/ 有特殊价值（仅声称）/ 一般 / 未说明

### 5.3 标题诊断

标题必须"亮观点"，不能"只讲对象"。格式：核心意象 + 研究对象 + 核心问题。

### 5.4 摘要诊断

"五句话"结构：研究背景 → 研究问题 → 主要方法 → 核心结论 → 理论贡献。结论必须与正文严格对应。

### 5.5 结构诊断

**子项A：结构完整性** — 是否缺少必要的结构性部分？
**子项B：最强部分** — 哪一部分论证最扎实、分析最深入？
**子项C：最弱部分** — 指出具体的分析缺陷。

### 5.6 三大问题

指出全文最需要解决的3个核心问题。聚焦正文内部的分析问题（论证薄弱、分析空洞、逻辑跳跃、证据不足）。结构性/格式问题不占名额。

### 5.7 重复检测与合并

通读全文，找出内容重复或逻辑重复的段落，判断保留/删除。

### 5.8 结构重组

删除重复段落后，检查章节顺序合理性，提出重组建议。

### 5.9 宏观论证逻辑检查

检查以下五维（对标第十一节写作SOP的终审标准）：

| 检查项 | 判定问题 |
|--------|---------|
| 论证链完整性 | 从前提到结论，是否有逻辑跳跃？ |
| 核心概念稳定性 | 核心概念定义全文是否一致？ |
| 反事实思考 | 核心假设不成立时，论证是否站得住？ |
| 论证层次递进 | 各章节之间是否有论证深度上的递进？ |
| 证据-结论距离 | 是否出现"小证据→大结论"的跳跃？ |
