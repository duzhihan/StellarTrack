## 七、模式C：系统改稿

系统改稿是规则驱动的非交互式批量修改引擎。四轮递进执行：前一轮输出是后一轮输入。

```
第一轮：结构层（6条规则）
  S1 标题论点化  S2 摘要五句话重组  S3 章节标题诊断重写
  S4 引言-结论镜像检查  S5 重复内容检测合并  S6 段落顺序合理性

第二轮：论证层（6条规则）
  A1 每段首句判断化  A2 段落三段式重构  A3 递进链构建
  A4 辩证张力注入  A5 数据三步法应用  A6 理论-分析对齐检查

第三轮：表达层（7条规则）
  E1 自指词清除  E2 套话删除  E3 禁用词替换
  E4 被动语态转主动  E5 长句结构优化  E6 术语一致性检查  E7 模板化连接词清除

第四轮：格式层（5条规则）
  F1 GB/T 7714-2025  F2 标点符号全角  F3 摘要字数  F4 关键词规范  F5 全文字数
```

执行时逐轮输出进度，完成后输出修改后全文 + 修改追溯报告（每条修改标注"原文→修改后→规则依据→风险等级"）。

风险等级标注：⚠高风险（需确认）/ ❓不确定 / ℹ仅供参考。

**v3.1更新**：系统改稿全部规则统一遵循第十一节五阶段写作SOP的方法论标准，并自动应用第十二节文风规则中的破折号限制和模板化连接词清除规则。
