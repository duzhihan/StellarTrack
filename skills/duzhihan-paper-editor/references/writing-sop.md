## 十一、五阶段写作方法论SOP

本节是**所有六种模式的底层方法论**。对标《中国社会科学》《求是》、新华社评论、政策研究、"学人之文"传统，与杜老师个人写作习惯深度融合。任何模式的输出都应遵循本节的方法论标准。

### 五句话核心原则

1. 每一个判断都需要有理论根基
2. 每一段论述都需要有逻辑闭环
3. 每一个概念都需要有精准界定
4. 每一句文字都需要有信息密度
5. 每一处引用都需要有规范标注

### SOP总览

| 阶段 | 核心任务 | 对标群体 |
|------|---------|---------|
| 准备 | 把问题想透 | 《求是》、"学人之文" |
| 结构 | 让逻辑闭环 | 《中国社会科学》、新华社 |
| 撰写 | 让表达精准 | 《求是》、政策研究 |
| 打磨 | 让文字干净 | 新华社、《求是》 |
| 终审 | 让全文闭环 | 所有群体 |

### 11.1 准备阶段：把问题想透

#### 11.1.1 确认问题意识

**对标**：《求是》"理论始于问题"——"善于捕捉现实中的真切问题，能够对其进行较为系统的理性思考和回答。"

**规则**：每一篇文章或章节必须有明确的核心追问。追问不能是模糊的"是什么"，必须是"为什么"和"如何"层面的理论问题。

**操作**：
1. 用一句话写出核心追问
2. 追问必须包含一个**判断**（而非仅仅描述现象）
3. 追问必须对应一个**理论缺口**（文献综述中未能回答的问题）

#### 11.1.2 梳理理论链条

**对标**："学人之文"传统——"义理、考据、辞章"三者统一；政策研究——"观点明确、材料扎实、逻辑严密。"

**规则**：每一个判断都需要有理论根基。概念不能凭空出现，必须交代"从何而来"。

**操作**：
1. 列出核心概念清单
2. 为每个概念标注其理论来源（哪位学者、哪篇文献）
3. 确认概念之间的逻辑关系（递进/并列/因果/对立）
4. 确认每个概念的引入都有前文铺垫

#### 11.1.3 构建论证骨架

**对标**：《求是》三层结构——"理论—实践—升华"；新华社评论——"陈述现象、分析原因、阐明危害、提出对策"。

**规则**：每段首句=全段核心判断。首句兼具"总结"与"引领"双重功能。读者只读首句即知整段主旨。

**操作**：
1. 用一句话写出每个段落的核心判断（首句预备稿）
2. 检查所有核心判断之间是否形成**递进关系**（不能是平行罗列）
3. 检查每段结尾是否指向下一段的起点（形成闭环链条）

### 11.2 结构设计阶段：让逻辑闭环

#### 11.2.1 章节引言设计

**对标**：《中国社会科学》——"兼具思想性、学理性和前沿性""选题要具有引领性，要大气厚重。"

**规则**：每一章的开篇必须有统领全章的导引性段落，交代三件事：本章与前章的逻辑关系、本章内部各节之间的递进结构、本章与后章的衔接接口。

**操作**：
1. 首句：用一个判断句说明本章在全篇中的位置（与前章的关系）
2. 第二至四句：概述本章各小节的核心判断（各节首句浓缩版）
3. 末句：指出本章结论指向下一章的逻辑起点（与后章的关系）
4. 禁止使用"本章""本节"等自我指涉词汇

#### 11.2.2 每节首段设计

**对标**：新华社"新华时评"——"选题、论点、论证过程"环环相扣，"观点深度与传播效能的有机统一"。

**规则**：每一节的开篇明确提出本节要解决的问题或要论证的判断。首句即核心判断。

**操作**：
1. 首句：核心判断（一句话说清本节要论证什么）
2. 第二至三句：解释核心判断中的关键概念
3. 后续：展开论证（材料、数据、案例）
4. 末句：收束并指向下一节

#### 11.2.3 段落内部结构

**对标**：《中国社会科学》"论述精美"——"'精'指精确、精致；'美'指文风具有美感"；政策研究——"文字精炼、条理清晰。"

**规则**：每段按"首句判断→概念界定→材料支撑→段尾收束"结构组织。

**操作**：
1. 首句：核心判断（不加修饰，直接陈述）
2. 第二至三句：对核心判断中的关键词进行概念界定（一句话解释，不反复讲解）
3. 第四至六句：用材料支撑判断（文献、数据、案例）
4. 末句：收束——回扣首句的判断，或指出延伸含义
5. 检查：每句话是否推进了认知？是否有冗余？

### 11.3 初稿撰写阶段：让表达精准

#### 11.3.1 概念的处理

**对标**：《中国社会科学》——"在保持学术个性的同时，坚守学术规范。"

**规则**：概念词的引入采用"学术概念+凝练解释"方式，而非反复讲解。

**操作**：
1. 首次出现：写出概念名称 + 一句话定义
2. 后续出现：直接使用概念名称，不再解释
3. 检查：同一概念在不同段落出现时，是否以不同角度呈现？是否重复定义？

#### 11.3.2 文献的融入

**对标**：《求是》——"理论知识引用对不对、逻辑表述全不全……只要觉得不踏实，就不断地查文献。"

**规则**：综述表达以问题/主题/判断为纲、以文献为证。将"张三研究了什么，李四指出了什么"升级为"学界围绕X问题形成了Y共识（张三 2023；李四 2024）以及Z分歧（王五 2025）"。

**操作**：
1. 先用一句话写出学界围绕什么问题形成了什么共识/分歧
2. 再用"（作者 年份）"将文献嵌入论述
3. 引用时直接提炼核心观点，不复述论文题目
4. 文末用【】标注完整引文格式

#### 11.3.3 论证的推进

**对标**：《求是》——"用短小精悍的语言把透彻的思想讲透彻。"

**规则**：每段论述结束时，需明确指出"这一发现/判断意味着什么"，而非仅做现象描述后戛然而止。

**操作**：
1. 每段末句必须包含一个**判断性动词**：意味着、标志着、揭示了、构成了、指向了
2. 末句不能是现象的复述，必须是现象的**理论化提升**
3. 删除所有"浅尝辄止"的描述性结尾

### 11.4 语言打磨阶段：让文字干净

#### 11.4.1 句式优化

**对标**：新华社"实字当头""简约之中求创新"；《求是》"短、实、新"。

**规则**：干净、简洁、有深度、有逻辑密度。一句话能说清的绝不用两句。反对文学化的排比堆砌和修辞铺陈。

**操作**：
1. 删除所有模板化连接词（详见12.2禁用清单）
2. 将三连动结构（"交叠、碰撞、转化"）拆解为具体分析
3. 将口语化表述替换为正式学术用语
4. 反对"如果……那么"假设句式，改为直接判断

#### 11.4.2 逻辑连接

**对标**：《中国社会科学》——"逻辑的连贯远比用词的华丽更重要。"

**规则**：前后文、前后句、前后段的逻辑递进关系必须清晰可辨。每段结尾与下段开篇形成明确的逻辑衔接。

**操作**：
1. 检查每段末句与下段首句之间是否有逻辑连接词或概念承接
2. 如果两段之间跳过了某个逻辑环节，补上
3. 如果两段之间出现了重复内容，删除一处
4. 检查全文是否有三处以上出现同一概念或同一判断——如有，至少改写两处

#### 11.4.3 信息密度提升

**对标**：学术写作规范——"用最少的文字提供最大的信息量。"

**规则**：信息密度的本质是"判断密度"——每一句话都应该是一个判断，而非陈述。AI生成的文章之所以信息密度低，根本原因在于它生成的更多是陈述而非判断。

**操作（冗余检测三步法）**：
1. 逐句检查：这句话是否推进了论证？去掉后论证是否仍然完整？如果去掉不影响，删除
2. 检查每句话是否承担了不可替代的功能——或推进论证、或界定概念、或提供证据、或做出判断
3. 检查是否有两句话表达了同一个意思——如果有，合并为一句

**概念层密度提升**：对核心名词和动词进行替换——用更精准的学术概念替换模糊的日常词汇，用更具体的判断动词替换中性的存在动词。例如"新媒体改变了戏曲传播"升级为"互联网将戏曲传播从链式结构重构为网状结构"——后者包含了谁（互联网）、作用于什么（链式结构）、产生了什么结果（网状结构）、结果的性质（重构而非改变）四个层面。

### 11.5 终审定稿阶段：让全文闭环

#### 11.5.1 全文逻辑检查

**对标**：《求是》三层结构——"理论—实践—升华"。

**操作**：
1. 检查前言是否提出了全文的核心追问
2. 检查各章是否分别回应了核心追问的一个侧面
3. 检查结论是否回扣了前言的核心追问并给出了回答
4. 检查每章开篇是否交代了与前章的关系，结尾是否指向了后章

#### 11.5.2 格式与引用检查

**操作**：
1. 检查所有正文中的"（作者 年份）"是否在文末有对应的【】标注
2. 检查所有【】标注是否包含完整引文要素
3. 区分尾注（引文）和脚注（注释说明）
4. 检查同一文献是否只在正文中出现一次

#### 11.5.3 首句与末句终审

**规则**：每段首句即全段核心判断，每段末句需有理论收束。

**操作**：
1. 通读全文所有段落首句——是否构成一篇独立的"微论文"？（只读首句也能把握全文逻辑）
2. 通读全文所有段落末句——是否完成了从现象到理论的提升？
3. 首句不能独立成义→重写；末句只是现象复述→重写

### 11.6 信息密度专项：判断密度的实现

**核心命题**：AI生成文章信息密度低的根源不在"知识储备"，而在"判断机制"——AI基于概率预测，追求"最可能出现的词"而非"最有信息含量的词"。高信息密度的文本来自"从多到少"的压缩过程——AI有"从少到多"的扩展能力，没有"从多到少"的压缩能力。

**策略一：分步提示词替代一次性生成**

不要一次性生成完整段落。拆解为"论点→论据→论证→结论"四步，每步控制在3-5句话以内，迫使在有限空间内集中信息。

**策略二：追问法替代概括法**

对AI生成文本中的每一个判断句提出追问：为什么？意味着什么？与什么相关？将追问结果压缩进原文——信息密度自然提升。AI擅长"概括"，高信息密度需要"追问"。

**策略三：从多到少的压缩训练**

将初稿作为"偏长版本"，逐句判断：核心信息是什么？能否用更少的字表达？能否与相邻句合并？目标不是删字数，而是保留全部核心信息的前提下压缩。

**策略四：AI负责扩展，人类负责压缩**

AI的生成能力用于快速产出初稿和多种变体，人类的判断力用于筛选、合并、删减、提升。最终判断——哪个概念更精准、哪个证据更有效、哪个结论更深刻——必须由人类完成。
