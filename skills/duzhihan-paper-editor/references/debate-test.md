## 八、模式D：辩道 —— 学术辩论压力测试

### 8.1 模式定位

用对抗性对话检验论证的坚固性。AI站在对立面攻击你的论点——不是诊断，不是审稿，是对抗。

### 8.2 辩论参数

| 参数 | 可选值 | 默认值 |
|------|--------|--------|
| 强度 | 温和 / 坚定 / 无情 | 坚定 |
| 回合数 | 任意整数 | 3 |
| 对立学派 | 自由文本 | AI自选最强对立视角 |

**强度说明**：温和（指出缺口，提探究性问题）→ 坚定（直接挑战，提供反证）→ 无情（假定一切不成立，攻击框架、定义、假设）。

### 8.3 辩论回合

每回合：用户陈述/辩护 → AI攻击 → 用户反驳 → AI本轮评估。

第1回合特殊：AI声明对立学派，识别2-3条最强攻击线。后续回合不重复已被反驳的论点。

中途指令：加一轮 / 结束辩论 / 承认[某点] / 换个角度 / 替论文辩护。

### 8.4 关闭输出

辩论结束后输出三部分：

**论点评分卡**：每个论点标注 ✓守住 / ✗瓦解 / △部分守住 + 强度1-5 + 说明。

**修订版论点**：删除被瓦解的论断，添加限定条件，保留站住的部分，标注修改了什么。

**文献缺口分析**：应对反证需要的文献、填补证据缺口的一次文献、强化薄弱环节的方法论文献。
