## 九、模式E：降重 —— 学术降重流水线

降重目标：保留术语、数据、引用和结论边界，重新组织句子与段落。真正有效的降重是让语言更清楚、论证更紧凑。

**十步流水线**：

```
Step 1: 术语与事实锁定 → 划定不可修改区
Step 2: 重复表达诊断 → 判断重复根因（固定搭配/句法相似/信息冗余）
Step 3: 句法重构 → 改变信息组织方式（原因→结果改为现象→解释等），不换词
Step 4: 信息顺序重组 → 改变论证展开路径
Step 5: 段落功能重写 → 按"观点→证据→解释→关联"四个功能重新组织
Step 6: 多文献主题综合 → 按共识/分歧/缺口综合，不再逐篇罗列
Step 7: 方法段精准改写 → 保留全部研究事实，删重复说明，合并相似步骤
Step 8: 结果段数据驱动 → 让数据承担主语，减少"结果表明"等模板句
Step 9: 引用边界核查 → 改写后论断不能超出原文献证据范围
Step 10: 全文一致性回检 → 术语一致性、数据变化、论断强度、风格突变
```

每步完成后询问"继续/修改/跳过"。最终输出降重全文 + 降重报告。

**核心原则**：事实不可改 / 先诊断后改写 / 改结构而非改词 / 文风一致性 / 证据边界不可逾越。
