## 🤔 What is this?

**Wenfeng Slime** is an AI-powered writing style analysis and transfer system built as a WorkBuddy skill. It learns your unique writing voice across 11+ audience contexts, maps it to 15 quantifiable dimensions, matches it against 12 literary archetypes (from Lu Xun to Qian Zhongshu), and adapts any output to the right style for the right audience — automatically.

> *"文风史莱姆" (Wenfeng Slime) — named after the shape-shifting RPG monster, because it morphs to match any writing style.*

---

## ✨ Features

| Mode | Trigger | What It Does |
|------|---------|-------------|
| **🎓 S-Learn** | `"Analyze my style"` | Full-context scan → 15-D profile → Learning plan → Iteration roadmap |
| **🔍 I-Identify** | `"What style is this?"` | 15-D scoring → 12-archetype matching → 5-section diagnostic report |
| **🔄 T-Transfer** | `"Rewrite in X style"` | L1 Vocab → L2 Syntax → L3 Rhetoric → L4 Structure layered rewrite |
| **🩺 D-Diagnose** | `"What's wrong with my style?"` | Defect localization → Root cause → Quick fix + Long-term training plan |

### The 15-Dimension Analysis Framework

```
L1 Surface (quantifiable)     L2 Technique (semantic)      L3 Deep Gene (cross-text)
─────────────────────────     ────────────────────────     ─────────────────────────
1. Sentence Length            6. Rhetorical Density         11. Citation Pattern
2. Paragraph Length           7. Emotional Temperature      12. Concept Creation
3. Punctuation Habits         8. Logic Density              13. Rhythmic Pattern  
4. Vocabulary Register        9. Person & Perspective       14. Information Density
5. Modal Particles            10. Structural Pattern        15. Cultural DNA
```

### The 12 Archetype Gallery

| Archetype | Nickname | Signature Move |
|-----------|----------|---------------|
| **Lu Xun** | Cold Blade | Minimalist prose, maximum irony |
| **Shen Congwen** | Water Rhythm | Dissolve tragedy into landscape |
| **Qian Zhongshu** | Wit Blade | One sentence, three allusions, all sarcasm |
| **Wang Zengqi** | Light Flavor | Divine luster in everyday objects |
| **Wang Xiaobo** | Demon Blade | Hyper-rational logic → absurd conclusions |
| **Eileen Chang** | Gorgeous Bone | Prettiest metaphors, coldest truths |
| **Academic (Du)** | Anchor Hand | Concept anchoring + rupture diagnosis |
| **New Media** | Hook Hand | Title is a knife; first 3 lines decide life or death |
| **Bureaucratic** | Iron Rule | Zero personality, maximum officiality |
| **Poetic** | Fire Seed | Minimum light, maximum explosion |
| **Essayist** | Wanderer | A daily detail → a not-so-small idea |
| **Critic** | Judge | Position first, evidence second, depth third |

## 🔧 Python CLI: `style_analyzer.py`

A standalone 15-dimension quantitative analyzer. Use it independently of WorkBuddy.

```bash
# Analyze a text file → JSON
python scripts/style_analyzer.py --file essay.txt --output json

# Direct text input
python scripts/style_analyzer.py --text "Your text here..." --output json

# Compare two texts
python scripts/style_analyzer.py --compare draft_v1.txt draft_v2.txt
```

## 🧬 Style Archetype Matching

Matching uses weighted cosine similarity across 3 layers:

```
Match Score = 0.40 × Surface Similarity 
            + 0.35 × Technique Similarity 
            + 0.25 × Deep Gene Similarity

> 80% → "Strong match"
60-80% → "Partial match (likely hybrid)"
40-60% → "Common elements, atypical"
< 40% → "No match"
```

Includes distance matrices for categorical variables (structural pattern, citation mode).
