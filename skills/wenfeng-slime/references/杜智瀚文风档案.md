## 不变核心（跨语境稳定风格基因）

### C1. 概念锚定本能
**表现**：无论什么语境，都有将现象提炼为标识性概念的内在冲动。
**证据**："熔炉效应""双螺旋耦合""数字活态标识""折角时空""相态凝结"——跨学术/创作语境的概念生产力。
**评级**：5/5 — 这是最具辨识度的风格基因。

### C2. 诊断式思维结构
**表现**：不满足于描述，总要走"现象→断裂→核心问题→方案"的完整诊断链。
**证据**：学术论文中的三阶诊断法、申报书中的断裂诊断、小说中对"注意力殖民"的病理学分析。
**评级**：5/5 — 思维结构本身构成风格骨骼。

### C3. 嵌入式从句链
**表现**：偏好中长句，在单句内完成多层逻辑嵌套——不是并列，而是递进嵌套。
**证据**：学术文本中频繁出现"不仅……而且……然而……因此……从而……"的结构链。
**评级**：4/5 — 在学术语境中达到5/5，在其他语境中收敛。

### C4. 隐名引述策略
**表现**：用「」标记他人观点而不具名，将学术对话融入自己的论证流。
**证据**：CSSCI论文中「气氛美学理论进一步将"气氛"提升为独立的美学范畴……」等用法。
**评级**：5/5 — 极具辨识度的引用策略。

### C5. 反讽/批判底色
**表现**：无论学术还是创作，都存在一条批判性暗线——对权力结构、技术异化、规训机制的警惕。
**证据**：学术中对"注意力殖民"的批判、小说中对"装傻役"社会规则的讽刺。
**评级**：4/5 — 在学术中以理性批判出现，在小说中以反讽爆发。

## 语境变量表

### 语境A：学术论文（CSSCI）
| 维度 | 偏移方向 | 程度 |
|------|---------|------|
| 句长 | ↑ 增长（均值38-45字） | +2 |
| 逻辑密度 | ↑ 多链嵌套 | +1 |
| 信息密度 | ↑ 极高 | +1 |
| 情感温度 | ↓ 冷峻克制 | -1 |
| 修辞密度 | ↓ 收敛（判断句取代修辞） | -1 |
| 概念创造 | ↑ 全力释放 | +1 |
| 结构模式 | 诊断式·完整版 | |
| 引用模式 | 隐名引述·极致版 | |
| 段落长度 | ↑ 中长段 | +1 |

**特殊规则**：
- 禁用"某学者指出""综上所述"
- 「」标记观点是标识性手法
- 判断句先行，数据锚定紧跟
- 小标题层级：一级=理论层，二级=实证层

## 原型归属

**主原型**：学术型（杜智瀚式） — 70%
**次原型**：鲁迅型 — 15%（冷峻批判底色）
**第三原型**：钱钟书型 — 10%（嵌入式从句链+跨学科广度）
**独特元素**：岭南口语渗透 + 传播学思维范式 — 5%

---

## 风格优势清单

1. **概念生产力**：业界罕见的概念锚定能力
2. **逻辑穿透力**：诊断式结构赋予文本天然的问题驱动
3. **跨学科整合力**：传播学→哲学→媒介学→数字人文的自由穿行
4. **辨识度**：隐名引述+嵌入式从句链+标识性概念 三重组合不可复制

---

## 风格风险清单

1. **概念悬空风险**（高）：概念提出后操作化路径不足
2. **体系膨胀冲动**（中高）：在申报书中有包罗万象的倾向
3. **长句过剩**（中）：在非学术语境中偶有从句链失控
4. **冷感过度**（低）：在需要温度的场景中克制过头
5. **新媒体语感不足**（中）：碎片化写作的节奏感需要训练
