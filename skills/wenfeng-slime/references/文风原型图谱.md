# 文风原型图谱 — 12种风格原型特征矩阵

## 原型概述

每个原型由 15 维特征向量定义。匹配时使用余弦相似度计算与目标文本的距离。

---

## 原型一览

### 1. 鲁迅型 — 冷刃
**基因标记**：冷峻·讽刺·短句·精准·白描

|------|---|------|
| 句长 | 1-2 | 短句为主，极简有力 |
| 段落 | 1-2 | 短段 |
| 情感温度 | -2 | 冷峻/压抑 |
| 修辞密度 | 3 | 反讽为主，偶用比喻 |
| 逻辑密度 | 3 | 间接推理，不显式 |
| 结构模式 | 散点式/递进式 | 自由收放 |
| 信息密度 | 5 | 极高，每个词都在工作 |
| 词汇层级 | 半文半白 | 文言与现代汉语交替 |
| 人称视角 | 全隐/隐性"我" | 克制出场 |
| 引用模式 | 对抗型 | "正人君子之流……" |
| 概念创造 | 2 | 不造概念，以日常语做手术刀 |
| 节奏模式 | 起伏型 | 平静叙述→短句暴击 |
| 文化基因 | 五四一代/越地 | 深沉忧患 |

**识别口诀**："每一句话都像匕首，没有一句废话。"

## 原型匹配算法

```
匹配度 = 0.4 × 表层相似度 + 0.35 × 中层相似度 + 0.25 × 深层相似度

其中：
- 表层相似度 = 1 - 归一化(|句长差| + |段落差| + |情感温度差|/2)
- 中层相似度 = 1 - 归一化(|修辞密度差| + |逻辑密度差| + |结构模式距离|)
- 深层相似度 = 1 - 归一化(|引用模式距离| + |概念创造差| + |信息密度差|)

相似度 > 80% → "高度吻合"
60-80% → "部分相似（可能混合型）"
40-60% → "有共同元素但非典型"
< 40% → "不匹配"
```

### 分类变量距离矩阵

**结构模式距离矩阵**（5×5）：

|           | 诊断式 | 总分式 | 递进式 | 散点式 | 钩子式 |
|-----------|--------|--------|--------|--------|--------|
| 诊断式    | 0      | 0.3    | 0.2    | 0.5    | 0.4    |
| 总分式    | 0.3    | 0      | 0.3    | 0.4    | 0.5    |
| 递进式    | 0.2    | 0.3    | 0      | 0.4    | 0.3    |
| 散点式    | 0.5    | 0.4    | 0.4    | 0      | 0.2    |
| 钩子式    | 0.4    | 0.5    | 0.3    | 0.2    | 0      |

> 距离含义：诊断式与递进式最接近（0.2，都属逻辑推进型），散点式与总分式/诊断式/递进式差异大（0.4-0.5），钩子式与散点式较近（0.2，都属注意力引导型）。

**引用模式距离矩阵**（5×5）：

|           | 具名对话 | 隐名引述 | 概念援引 | 默默消化 | 对抗型 |
|-----------|---------|---------|---------|---------|--------|
| 具名对话  | 0       | 0.2     | 0.3     | 0.4     | 0.5    |
| 隐名引述  | 0.2     | 0       | 0.2     | 0.3     | 0.4    |
| 概念援引  | 0.3     | 0.2     | 0       | 0.2     | 0.3    |
| 默默消化  | 0.4     | 0.3     | 0.2     | 0       | 0.2    |
| 对抗型    | 0.5     | 0.4     | 0.3     | 0.2     | 0      |

> 距离含义：具名对话与对抗型最远（0.5），隐名引述与概念援引/具名对话都较近（0.2）。

## 混合型标注

当代写作者多为混合型。标注格式：
