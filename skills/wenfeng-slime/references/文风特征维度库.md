# 文风特征维度库 — 15维风格分析框架

## 使用说明
对任意文本进行风格分析时，使用本维度库逐项评分（1-5分）。评分后与原型图谱进行匹配。

---

## L1 — 表层特征（可直接量化）

### 1. 句长特征 (Sentence Length)
**定义**：句子的平均长度及分布形态。

| 评分 | 描述 | 代表人物 |
|------|------|---------|
| 1 | 极短句主导（平均≤15字），断奏感强 | 鲁迅（成熟期） |
| 2 | 短句为主（15-25字），间以中句 | 汪曾祺 |
| 3 | 中句为主（25-40字），均衡布局 | 沈从文 |
| 4 | 长句为主（40-60字），嵌入式从句链 | 钱钟书、杜智瀚（学术） |
| 5 | 超长句主导（≥60字），多层嵌套 | 普鲁斯特、德语学术传统 |

**量化方法**：统计句号/问号/感叹号/分号分隔的句子长度，计算均值、标准差、中位数。

### 2. 段落长度 (Paragraph Length)
**定义**：自然段落的句数分布。

| 评分 | 描述 | 典型场景 |
|------|------|---------|
| 1 | 单句段为主（≤3句/段） | 新媒体文、诗歌 |
| 2 | 短段（3-5句/段） | 随笔、评论 |
| 3 | 中段（5-10句/段） | 学术论文、申报书 |
| 4 | 长段（10-15句/段） | 理论专著 |
| 5 | 超长段（≥15句/段） | 哲学著作 |

### 3. 标点习惯 (Punctuation Pattern)
**定义**：标点使用频率与偏好类型。

| 维度 | 评分标准 |
|------|---------|
| 逗号密度 | 1(稀疏) — 5(密集) |
| 分号偏好 | 1(极少) — 5(高频，体现逻辑分层) |
| 破折号使用 | 1(不用) — 5(频繁，嵌入式解释) |
| 感叹号密度 | 1(学术克制) — 5(情感外露) |
| 引号使用 | 1(极少) — 5(高频标记概念) |

### 4. 词汇层级 (Vocabulary Register)
**定义**：用词的古今中外交叠程度。

| 子维度 | 说明 |
|--------|------|
| 文言比率 | 单音节古词、典故词的使用频率 |
| 白话口语率 | "的了吗呢"等口语标记密度 |
| 学术术语密度 | 学科专属术语的使用频率 |
| 舶来词偏好 | 音译词、西式句式占比 |
| 网络用语率 | 新兴网络词汇、缩写使用频率 |

### 5. 语气词与虚词密度 (Modal Particles)
**定义**："的、了、吗、呢、吧、啊"等语气词及"之、乎、者、也"等虚词的使用频率。

| 评分 | 描述 |
|------|------|
| 1 | 极克制，几乎不用语气词 | 
| 3 | 适度使用，不刻意 |
| 5 | 高频使用，口语化/抒情化明显 |

## L2 — 中层技法（需语义理解）

### 6. 修辞密度 (Rhetorical Device Density)
**定义**：每千字中修辞手法的使用频次。

| 修辞类型 | 监测要点 |
|---------|---------|
| 比喻(明喻/暗喻/借喻) | "如""像""是""化作"等标记 |
| 排比 | 三项及以上并列结构 |
| 反问/设问 | "难道""何以""如何" |
| 对偶 | 对称结构 |
| 用典 | 人名、书名、事件暗引 |
| 反讽 | 表面与实质反差 |

### 7. 情感温度 (Emotional Temperature)
**定义**：文本的情感饱和度与基调方向。

| 评分 | 情感类型 | 典型特征 |
|------|---------|---------|
| -2 | 冷峻/克制 | 情感词汇极少，事实陈述为主 |
| -1 | 冷静/理性 | 分析性主导，偶尔情感词 |
| 0 | 中性 | 均衡 |
| +1 | 温情/热忱 | 情感词频繁，价值观表达 |
| +2 | 激昂/炽烈 | 情绪主导，感叹号/程度副词堆叠 |

### 8. 逻辑密度 (Logic Density)
**定义**：推理链的层数和关联词的复杂度。

| 评分 | 描述 |
|------|------|
| 1 | 直觉跳跃，不显式推理 |
| 2 | 简单因果，"因为……所以……" |
| 3 | 双链推理，让步-转折-因果 |
| 4 | 多链嵌套，"不仅……而且……然而……因此……从而……" |
| 5 | 体系化推理，概念→命题→推论→反驳→综合 |

### 9. 人称与视角 (Person & Perspective)
**定义**：叙述者在文本中的出场方式。

| 类型 | 特征 | 典型场景 |
|------|------|---------|
| 显性"我" | "我认为""笔者"直接出场 | 随笔、申报书 |
| 隐性"我" | 判断句无主语，但明显是个体判断 | 学术论文、评论 |
| 全隐 | 纯事实陈述，无个体判断痕迹 | 新闻稿、公文 |
| "我们"共同体 | "我们注意到""学界普遍" | 综述、导论 |

### 10. 结构模式 (Structural Pattern)
**定义**：段落/章节的组织逻辑。

| 模式 | 特征 | 代表 |
|------|------|------|
| 总分式 | 先结论后展开 | 新闻、论文摘要 |
| 并列式 | 多层并列推进 | 申报书子课题 |
| 递进式 | 层层深入 | 哲学论证 |
| 散点式 | 自由联想 | 随笔、意识流 |
| 诊断式 | 现象→断裂→问题→方案 | 杜智瀚学术风格 |
| 钩子式 | 每段有悬念 | 新媒体、小说 |

## L3 — 深层基因（需跨文本分析）

### 11. 知识引用模式 (Citation Pattern)
**定义**：如何处理他人观点。

| 模式 | 描述 |
|------|------|
| 具名对话型 | "XXX（2024）指出……" |
| 隐名引述型 | 「观点」标记，不具名 |
| 概念援引型 | 只引概念不引入名 |
| 默默消化型 | 不引用，观点已内化 |
| 对抗型 | "学界普遍认为X，但……" |

### 12. 概念创造倾向 (Concept Creation Tendency)
**定义**：是否倾向于提出新概念/新术语。

| 评分 | 描述 |
|------|------|
| 1 | 从不用新概念，只用既有术语 |
| 3 | 偶尔提出操作性概念 |
| 5 | 高度倾向创造标识性概念 |

### 13. 节奏模式 (Rhythmic Pattern)
**定义**：文本的"呼吸节奏"——句长变化与重音分布。

| 类型 | 特征 |
|------|------|
| 匀速型 | 句长波动小，稳定推进 |
| 起伏型 | 长句铺垫→短句暴击交替 |
| 加速型 | 段落内句长渐缩 |
| 阻滞型 | 长句密集，多停顿 |

### 14. 信息密度 (Information Density)
**定义**：单位文本承载的信息量。

| 评分 | 描述 |
|------|------|
| 1 | 低密度，冗余信息多，适合口语 |
| 3 | 中等密度，信息与解释均衡 |
| 5 | 高密度，每句新信息，需反复阅读 |

### 15. 文化基因 (Cultural DNA)
**定义**：文本中的地域、阶层、学科等文化编码。

| 子维度 | 说明 |
|--------|------|
| 地域色彩 | 方言词、地域意象 |
| 学科印记 | 特定学科思维范式 |
| 代际标记 | 年代特定的语言习惯 |
| 阶级/圈层标记 | 特定圈层的术语系统 |

---

## 评分输出格式

```
## 文风15维评分报告

### L1 表层特征
1. 句长特征: 3/5 — 中句为主(均值32字)，间以短句暴击
2. 段落长度: 2/5 — 短段为主(均值4.2句/段)
3. 标点习惯: 逗号密集/分号克制/破折号中频
4. 词汇层级: 文言比0.12 | 口语率0.08 | 术语密度0.23
5. 语气词密度: 2/5 — 克制

### L2 中层技法
6. 修辞密度: 3.2次/千字 — 比喻为主，偶用反问
7. 情感温度: -1/2 — 冷峻克制
8. 逻辑密度: 4/5 — 多链嵌套推理
9. 人称视角: 隐性"我"
10. 结构模式: 诊断式 + 递进式

### L3 深层基因
11. 引用模式: 隐名引述型
12. 概念创造倾向: 4/5 — 高度倾向创造标识性概念
13. 节奏模式: 起伏型 — 长句铺垫→短句暴击
14. 信息密度: 4/5 — 高密度
15. 文化基因: 岭南地域 + 传播学印记 + Z世代语言渗透

### 综合评级
原型匹配: 学术型(杜智瀚式) 82% + 鲁迅型 15%
独特标记: 概念创造倾向+诊断式结构+隐名引述 三重组合
```
