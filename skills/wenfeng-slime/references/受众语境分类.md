# 受众语境分类 — 10+ 语境完整风格参数表

## 使用说明

当需要将内容适配到特定受众语境时，使用本表加载目标语境的风格参数。每个语境包含：核心约束、句式要求、词汇要求、结构要求、禁忌清单。

---

## 1. 新媒体文章（公众号/头条/小红书/微博）

**受众画像**：碎片化阅读、注意力稀缺、情绪驱动
**核心目的**：传播、共鸣、转化

### 风格参数
| 要素 | 要求 |
|------|------|
| 句长 | ≤25字为主，偶用长句点缀 |
| 段落 | 1-3句/段，≤5行手机屏 |
| 开头 | 钩子句（反常识/痛点/悬念） |
| 正文 | 每200字一个信息爆点 |
| 结尾 | 情绪升维 + 行动号召 |
| 词汇 | 网感词、拟声词、程度副词高频 |
| 语气 | "你"第二人称，对话感强 |
| 标题 | 数字+冲突+利益点 |

### 禁忌清单
- ❌ 长段文字（≥5行/段）
- ❌ 学术术语不解释
- ❌ 平铺直叙无钩子
- ❌ 第三人称冷感叙述
- ❌ 以"本文""笔者"开头

### 优化口诀
"前三行决定生死，每一行都在问'要不要看下一行'。"

## 2. 党建申报材料

**受众画像**：党组织、评审委员会
**核心目的**：政治正确、规范达标、事迹突出

### 风格参数
| 要素 | 要求 |
|------|------|
| 句长 | 中句为主（30-50字），多并列 |
| 段落 | 中段（5-8句） |
| 结构 | 三级标题体系（一/（一）/1.） |
| 开头 | "为深入贯彻……"式目的句 |
| 词汇 | "坚持""贯彻""落实""强化""推动"句首高频 |
| 修辞 | 四字格排比为主 |
| 语气 | 正式、庄重、无我 |

### 禁忌清单
- ❌ 个人化表达（"我""我的"）
- ❌ 网络用语、口语化
- ❌ 消极表述（需转化为"改进空间"）
- ❌ 无政治理论引用
- ❌ 标题层级混乱

---

## 3. 课题申报书（国家社科/教育部人文社科）

**受众画像**：通讯评审专家（5位）、学科规划评审组
**核心目的**：选题新颖度、问题凸显度、论证系统度

### 风格参数
| 要素 | 要求 |
|------|------|
| 问题提出 | 三阶诊断法：现象→断裂→概念 |
| 文献综述 | 述—评—立三段式 |
| 核心概念 | 标识性概念 + 操作化路径（≥3维度） |
| 子课题 | ≤4个，目标-问题-方法-工具-产出五要素 |
| 创新点 | 限3点（理论/方法/视角各一） |
| 应用价值 | "基于……可为……提供……"句式 |
| 句长 | 中长句（30-50字），嵌入式从句链 |

### 禁忌清单
- ❌ 概念悬空无操作化
- ❌ 方法工具独立罗列
- ❌ 应用价值套话（"推动……发展"）
- ❌ 体系包罗万象的承诺
- ❌ 前期成果与创新点脱节
- ❌ "某学者指出"具名引述

### 详见
用户专用风格参数：`个人申报风格` skill

## 4. 人文社科论文（CSSCI/核心期刊）

**受众画像**：同行学者、期刊审稿人
**核心目的**：学术贡献、论证严密、对话前沿

### 风格参数
| 要素 | 要求 |
|------|------|
| 摘要 | 问题-方法-发现-结论 四要素 |
| 引言 | 显性综述（述—评—立） |
| 正文 | 判断句先行 → 数据锚定 → 意义升维 |
| 引用 | 「」标记观点，隐名引述 |
| 小标题 | 一级=理论层，二级=实证层 |
| 结论 | 开放性问题或感叹句升维收束 |
| 句长 | 中长句，嵌套从句链 |
| 段落 | 中长段（5-10句） |

### 禁忌清单
- ❌ "某学者指出""有学者认为"
- ❌ "综上所述/总而言之"收尾
- ❌ "有待进一步研究"
- ❌ 独立文献综述章（正文内）
- ❌ 以数据开段
- ❌ 满版具名引用

### 详见
用户专用风格参数：`杜智瀚改论文` skill

## 5. 评论写作（文艺评论/文化评论/时评）

**受众画像**：知识公众、行业读者
**核心目的**：观点穿透、分析深度、公共对话

### 风格参数
| 要素 | 要求 |
|------|------|
| 开头 | 判断句开段（一句亮观点） |
| 正文 | 现象→分析→理论升华 三段推进 |
| 证据 | 案例+数据+理论 三源 |
| 结尾 | 辩证收束（"然而""不过""但") |
| 句长 | 中短句暴击感 + 长句理论展开 |
| 情感 | 有立场但不偏激 |
| 引用 | 理论底牌后亮 |

### 禁忌清单
- ❌ 观点模糊（读了第一段不知立场）
- ❌ 纯描述无判断
- ❌ 理论堆砌不走心
- ❌ 结尾口号化

---

## 6. 诗歌写作

**受众画像**：诗歌读者、自我表达
**核心目的**：意象创造、情感浓缩、语言突破

### 风格参数
| 要素 | 要求 |
|------|------|
| 行 | 断裂、跳跃、留白 |
| 意象 | 具体→抽象，感官→意义 |
| 节奏 | 内在音乐性 |
| 词汇 | 去陈词，每个词都在工作 |
| 结构 | 非线性，意象接力 |
| 密度 | 极高信息/情感密度 |

### 禁忌清单
- ❌ 散文分行
- ❌ 陈腐意象（"心海""泪雨"）
- ❌ 直说情感不转化意象
- ❌ 解释性语言

---

## 7. 随笔写作

**受众画像**：泛阅读者、自我对话
**核心目的**：感受分享、思考散步、日常诗意

### 风格参数
| 要素 | 要求 |
|------|------|
| 视角 | 显性"我"在场 |
| 开头 | 日常细节入场 |
| 结构 | 散点式自由联想 |
| 节奏 | 松散但有关联 |
| 词汇 | 口语化但精致 |
| 结尾 | 不一定要有"结论"，轻着陆 |

### 禁忌清单
- ❌ 说教腔（"我们应该……"）
- ❌ 结构过紧失去闲适感
- ❌ 过于抽象不落地
- ❌ 强行升华

---

## 8. 日记写作

**受众画像**：自我（私密写作）
**核心目的**：记录、反思、情感释放

### 风格参数
| 要素 | 要求 |
|------|------|
| 视角 | 纯"我"视角 |
| 结构 | 无结构意识 |
| 语言 | 最自然口语 |
| 情感 | 允许未经修饰的情绪 |
| 逻辑 | 可以不连贯 |

### 禁忌清单
- ❌ 过度修饰（失去日记本真）
- ❌ 用第三人称写自己
- ❌ 考虑"如果有人看到"

---

## 9. 小说创作（网文/纯文学）

**受众画像**：故事消费者
**核心目的**：代入、悬念、情感体验

### 风格参数
| 要素 | 要求 |
|------|------|
| 推进 | 对话+行动 驱动 |
| 段落 | 短段（网文）/ 中段（纯文学） |
| 感官 | 五感词汇高频 |
| 节奏 | 张弛交替 |
| 视角 | 限知视角为主 |

### 详见
用户专用：`chinese-novelist-dragon` skill

## 10. 工作汇报/述职

**受众画像**：上级领导、考核部门
**核心目的**：成果展示、问题分析、计划呈现

### 风格参数
| 要素 | 要求 |
|------|------|
| 结构 | 成果-问题-计划 三段式 |
| 数据 | 量化优先，定性辅助 |
| 语气 | 务实、客观、有担当 |
| 句长 | 中句清晰表述 |
| 问题表述 | "不足/有待加强/仍存在" |

### 禁忌清单
- ❌ 成绩浮夸（"极大地""前所未有"）
- ❌ 问题回避或甩锅
- ❌ 计划空洞无具体举措
- ❌ 第三人称（"该同志"）

---

## 11. 演讲稿/发言稿

**受众画像**：现场听众
**核心目的**：说服、激励、共鸣

### 风格参数
| 要素 | 要求 |
|------|------|
| 开头 | 情境切入（"今天站在这里……") |
| 正文 | 故事/金句/数据交替 |
| 节奏 | 口语韵律感 |
| 句长 | 短中句，适合朗读 |
| 结尾 | 高光收束，行动号召 |

### 禁忌清单
- ❌ 长难句（听众无法跟踪）
- ❌ 书面语太重
- ❌ 没有故事只有道理

---
